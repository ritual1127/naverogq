# 실제 도면 받는 곳

인터뷰(08-26 ~ 08-28) 때 학생과 선생님께 **이름을 지우고** 받은 도면을 여기에 둡니다.
[P04](../plan/문제점/P04-표본도면.md) — 지금 정확도 100%는 우리가 직접 만든 합성 도면
18장 기준이고, 도면을 만든 사람과 검사 규칙을 만든 사람이 같습니다. 발표에서
"실제 도면 정확도는?"을 물으면 그 숫자로는 답이 안 됩니다.

## 도면 파일은 저장소에 올리지 않습니다

남의 도면입니다. `.gitignore`가 이 폴더의 도면 파일을 막고 있고, 여기 있는
`README.md`와 `labels.json`만 올라갑니다. **`-f`로 억지로 넣지 않습니다.**

받을 때 확인할 것 — 표제란에 이름·학번이 남아 있지 않은지. 남아 있으면
**우리가 지우지 말고 준 사람에게 다시 부탁합니다.** 우리가 고치면 원본이 아니게 됩니다.

## 파일 이름

`A01.dxf` `A02.dxf` … 순서대로. 누구 것인지는 파일 이름에 적지 않습니다.
누가 줬는지는 [`docs/interviews.md`](../docs/interviews.md)의 그 사람 칸에
"도면 파일 받음 — A01" 로 적습니다.

## 라벨 붙이기

**사람이 눈으로 보고 정답을 답니다.** CADLens 결과를 정답으로 쓰면 100%가 나오고
아무 의미가 없습니다. 도면 한 장에서 사람이 찾은 결함의 코드를 배열로 적습니다.

```json
{
  "A01.dxf": ["EX_DIM_MISSING", "EX_NO_FIT"],
  "A02.dxf": []
}
```

결함이 하나도 없으면 빈 배열입니다. 빈 배열도 측정에 씁니다 — 멀쩡한 도면을
틀렸다고 하는지 보는 것이 정확도(precision)입니다.

다 붙였으면 이렇게 잽니다.

```
python bench.py 실제도면/labels.json
```

라벨이 비어 있거나 적힌 이름의 파일이 없으면 **정확도 대신 `FAIL` 이 뜨고 종료 코드가 1**
입니다([P09](../plan/문제점/P09-빈측정100.md)). 0장에 100%가 찍히던 것을 08-26에 막았습니다.

나온 숫자는 [`docs/accuracy.md`](../docs/accuracy.md)에 **합성 도면 표와 나란히** 남깁니다.
합성 도면 표를 지우지 않습니다. 둘의 차이가 우리가 공개할 것입니다.
