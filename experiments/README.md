# 탐색 기록 (probe scripts)

Autodesk Inventor COM API에는 쓸 만한 공식 문서가 거의 없습니다. `.idw` 안에서
치수·공차·표면거칠기 기호를 어떤 객체로 어떻게 꺼내는지 알아내려면 **직접 열어보고
찍어보는 수밖에 없었습니다.** 이 폴더가 그 과정입니다.

정리해서 지우지 않고 남겨둔 이유는, 이게 `inventor.py`가 지금 모습이 된 근거이기
때문입니다. 어떤 API가 되고 어떤 게 안 되는지 하나씩 확인한 기록입니다.

| 파일 | 무엇을 알아냈나 |
|---|---|
| `probe1~7` | Inventor COM 연결, 문서 열기, 시트/뷰 순회의 기본 구조 |
| `probe8~13` | 치수 객체(`GeneralDimensions`)와 공차 타입 판별 |
| `probe14~17` | 표면거칠기·기하공차 기호를 `Sheet.Sketches`가 아니라 시트 주석에서 꺼내야 한다는 것 |
| `probe18~19` | `olefile`로 `.idw` OLE 구조를 직접 열어 본 시도 (실패 — Inventor 경유가 답) |
| `probe20~23` | DXF 내보내기 좌표계와 시트 좌표계의 배율 관계 확인 |

`probe20~23`의 결론이 특히 중요합니다. **시트 센티미터 → 내보낸 DXF 밀리미터가
정확히 ×10**이라는 것을 알려진 원 12개로 0.000mm까지 검증했고, 그래서 도면 위
빨간 화살표가 "대충 그 근처"가 아니라 **실제로 그 구멍을 가리킵니다.**

## 그 외

- `make_dxf_fixture.py` — 테스트용 DXF 픽스처 생성. `test_rules.py`가 CAD 없이도
  돌 수 있는 이유입니다.
- `dump_api.py` — 실행 중인 서버의 `/api/health`·분석 응답을 그대로 덤프. 프론트엔드
  작업할 때 실제 응답 구조를 보려고 만들었습니다.

이 스크립트들은 제품 코드가 아닙니다. 실행하려면 Inventor와 실제 CAD 파일이
필요하고, 경로가 하드코딩된 것도 있습니다.
