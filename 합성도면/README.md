# 합성도면 — 코드로 찍은 기준 도면 100장

| | |
|---|---|
| 무엇 | `make_drawings.py` 가 만든 DXF 100장과 [`labels.json`](labels.json) |
| 만든 날 | 2026-08-30 |
| 어디에 쓰나 | `python bench.py 합성도면/labels.json` — 검사 24개의 검출률·정확도 측정 |
| **사람이 그린 도면인가** | **아니다.** 전부 코드가 그린 것이다 |

## 먼저 읽을 것 — 이건 실제 수험생 도면이 아니다

공개문제(동력전달장치 · 드릴지그 · 바이스 · 기어박스)의 **형식**을 본떴다 —
A3 도면틀 · 표제란 · 부품란 · 제3각법 기호 · 정면/평면/우측면 + 단면도 A-A ·
중심선 · 끼워맞춤(H7 · js5 · g6 · h6 · N9 · K7 · js6 · H8) · 표면거칠기 w/x/y/z ·
데이텀 A·B 와 기하공차(⊥ ◎ ∥) · 주서 5줄.

**형식만 같고 형상은 아니다.** 실제 과제 조립도에서 필요한 투상도를 고른 것이
아니라, 사각형과 원을 규칙대로 배치한 것이다. 그래서 이 100장으로 잰 숫자는
**"우리 검사가 우리가 만든 결함을 잡는가"** 이지 **"실제 수험생 도면에서 몇 %인가"**
가 아니다. 뒤엣것은 실제 도면이 와야 잴 수 있고 [P04](../plan/문제점/P04-표본도면.md) 로 열려 있다.

기준 도면(`*_ok.dxf`)은 우리 검사 24개에서 지적이 0건이다.
**그건 우리 검사 기준 만점이지 실기 채점 100점이 아니다.** 투상도 선택과
배열 30점은 AI와 사람이 보는 것이고 여기서 보증하지 않는다.

## 무엇이 들어 있나

100장 = 6가지 조합(부품 세트 × 치수) × 17가지 상태(정상 1 + 결함 16).

| 파일 이름 | 넣은 결함 | 잡혀야 하는 코드 |
|---|---|---|
| `*_ok` | 없음 | (지적 없음) |
| `*_none` | 표면거칠기 기호를 통째로 뺌 | `DQ_NO_SURFACE_SYMBOL` |
| `*_no_fcf` | 기하공차를 통째로 뺌 | `DQ_NO_GEOMETRIC_TOL` |
| `*_no_dims` | 치수를 하나도 안 넣음 | `EX_NO_DIMS` |
| `*_undimensioned` | 정면도 큰 구멍만 치수 없음 | `EX_DIM_MISSING` |
| `*_no_fit` | 끼워맞춤 기호 없음 | `EX_NO_FIT` · `EX_TOL_FEW` |
| `*_few` | 거칠기 기호 2개뿐 | `EX_SURFACE_FEW` |
| `*_uniform` | 거칠기가 한 종류뿐 | `EX_SURFACE_UNIFORM` |
| `*_empty` | 값이 빈 거칠기 기호 | `EX_SURFACE_EMPTY` |
| `*_no_datum` | 기하공차에 데이텀 없음 | `EX_FCF_NO_DATUM` |
| `*_no_tolval` | 기하공차 값이 빔 | `EX_FCF_NO_VALUE` |
| `*_one_fcf` | 기하공차 1개뿐 | `EX_FCF_FEW` |
| `*_no_notes` | 주서 없음 | `EX_NO_NOTES` · `EX_NO_HEAT` |
| `*_no_chamfer` | 주서에서 모떼기 줄 뺌 | `EX_NOTE_ITEM` |
| `*_no_heat` | 주서에서 열처리 줄 뺌 | `EX_NO_HEAT` |
| `*_no_center` | 중심선 없음 | `EX_NO_CENTERLINE` |
| `*_no_title` | 표제란·부품란·도면틀 없음 | `EX_NO_TITLEBLOCK` |

**못 만든 결함도 적어 둔다.** 척도 오류(`DQ_SCALE`)와 제1각법(`DQ_PROJECTION`)은
우리 파서가 DXF 안의 척도·각법 정보를 읽는 경로로만 잡히는데, 합성 DXF 에
그 값을 심는 방법이 실제 CAD 와 달라 **정직하게 뺐다.** 08-29 인터뷰에서 나온
"뷰 척도 2:1" 문제도 여기 속한다([발전 계획](../docs/roadmap.md) 3번).

## 다시 만들려면

```bash
python make_drawings.py --out 합성도면 --count 100
python bench.py 합성도면/labels.json
```

씨앗이 고정이라 몇 번을 돌려도 같은 도면이 나온다.
