# MVP 범위표

W3(09-01~09-07) 워크샵 산출물입니다. 남은 8주 동안 CADLens에서 **무엇을 안 만들지** 정한 문서입니다.

---

## 핵심 행동 한 문장

> **도면을 올려 검사 결과를 보고 고친다.**

[팀 목표 1장](../plan/w1/팀목표.md)의 미션 문장을 이 한 문장으로 좁혔습니다. 이 문장에
안 걸리는 기능은 남은 8주 동안 안 만듭니다.

> **원래 미션 문장** (2026-08-30 확정) — "전산응용기계제도기능사 실기를 혼자 준비하는
> 수험생이 도면을 제출하기 직전에 겪는, 혼자 볼 때는 무엇을 빠뜨렸는지 짚어 줄 사람이
> 없고 남이 짚어 줘도 그때는 고칠 시간이 없는 문제를, 도면 파일을 올리면 빠진 항목을
> 도면 위에 찍어 주는 웹 검사기로 없앤다." 근거는
> [인터뷰 — 문제 정의 한 문장](interviews.md#문제-정의-한-문장-2026-08-30-확정).

## 이번에 만들 것 (핵심 행동에 걸리는 것)

| 무엇 | 지금 상태 |
|---|---|
| 도면 업로드 (DWG · DXF) | 있음 |
| 규칙 검사 24개 (치수·공차·표면거칠기·기하공차·주서·표제란·재료, 실격 판정 5가지) | 있음 |
| AI 투상도 채점 30점 (Gemini → Workers AI → Mistral → Groq 폴백) | 있음, 편차 측정 중 ([P02](../plan/문제점/P02-AI점수편차.md)) |
| 지적 위치를 도면 위에 표시 + 질문 버튼 3개(왜 감점이야·어디를 눌러·고친 뒤 확인은) | 있음 |
| 브라우저 로컬 재검사 이력 비교 | 있음 |
| 실제 수험생 도면 기준 정확도 재측정 | 진행 중, 표본 2장뿐 ([P04](../plan/문제점/P04-표본도면.md)) |

## 안 만들 것

| 무엇 | 왜 |
|---|---|
| 회원가입 · 로그인 · 계정 | 미성년 이용자가 대부분이라 개인정보를 아예 안 받는 게 원칙이다 ([공개 고지](policy.md)) |
| 채팅 · 댓글 · 게시판 · 프로필 · 친구 기능 | 사용자끼리 만날 곳을 안 만들어 접촉·괴롭힘이 생길 구조 자체를 없앤다 ([공개 고지](policy.md)) |
| Inventor ipt · idw · iam (3D 파싱) | 3D는 새 파싱 모듈이 필요하고, 2D 검사부터 안정시키는 게 먼저다 ([발전 계획](roadmap.md) 4번) |
| 다른 종목(기계설계산업기사 등)으로 확장 | 종목별 공개문제를 3개 회차 이상 확보하기 전에는 코드를 안 건드리기로 했다. 확인 안 된 기준으로 규칙을 만들면 응시자에게 틀린 지적을 하게 된다 ([발전 계획](roadmap.md) 5번) |
| 반 단위 화면 · 학교 단위 계약 | 8주 목표가 아니다. 선생님 채점자 질문 3개도 아직 답을 못 받았다 ([P12](../plan/문제점/P12-선생님답없음.md)) |
| 재질 기입 · 스퍼기어/스프링 요목표 · 표면거칠기 비교표 검사 추가 | 인터뷰에서 나온 요청이지만 표본이 폼 응답 1명뿐이라 검사 항목을 늘리지 않기로 했다 ([발전 계획](roadmap.md) 3번) |
| A4 출력 잘림 · 파일 손상/저장 실패 대응 | 인터뷰 2건(최\*영, 폼 1)에서 나왔지만 출력 설정과 CAD 도구 문제는 DXF 안에 없는 정보라 범위 밖이다 ([발전 계획](roadmap.md) 3번) |
| AI 점수를 최종 확정 점수로 표시 | AI가 매기는 30점은 편차가 있어 항상 "확정 점수 아님"으로 남긴다. 확실하지 않으면 감점 대신 "사람 확인 필요"로 둔다 ([공개 고지](policy.md)) |
| 접속·검사 횟수 외의 사용자 추적(쿠키, 로그인 기반 개인화) | 익명 집계 원칙을 지표가 필요하다고 깨지 않는다 ([발전 계획](roadmap.md) "얼마나 쓰이는지") |
| 도면 자동 수정 | 지적하고 고치는 법만 알려준다. 대신 그려 주면 실기 공부가 안 된다 |

**인터뷰에서 나왔지만 안 만들 것으로 분류한 항목**은 위 표의 아래 세 줄(재질/요목표/비교표,
A4 잘림/저장 실패)입니다. 사용자 말을 다 듣지 않았다는 걸 여기서 설명할 수 있습니다.
