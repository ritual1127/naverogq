# 사용자 인터뷰

CADLens를 쓸 사람에게 직접 물은 것을 그대로 남기는 문서입니다.
우리가 생각한 문제와 실제로 겪는 문제가 다르면, 다른 쪽이 맞습니다.

질문은 [질문지](../plan/w2/08-25_화/질문지.md)를 씁니다. 대상은
[인터뷰 대상표](../plan/w2/08-25_화/인터뷰대상표.md)에 있습니다.
1건에 15분, 5건이 W2 산출물입니다.

## 적는 법

- **직접 인용 3개는 들은 말 그대로** 적습니다. 다듬으면 그 사람 말이 아니라 우리 말이 됩니다.
- **지금 쓰는 대안**은 구체적으로 적습니다. "그냥 확인한다"가 아니라 "친구한테 카톡으로 보내서 봐 달라고 한다".
- **강한 신호**는 이미 돈이나 시간을 쓴 경우입니다. "나오면 써 볼게요"는 신호가 아닙니다.
- 인터뷰가 끝나고 **5분 안에** 채웁니다. 미루면 인용이 요약으로 변합니다.
- 이름은 적지 않습니다. `학생 A`처럼 씁니다.

## 양식

아래를 복사해서 인터뷰마다 하나씩 이어 붙입니다.

```markdown
### N. 대상 — (학년 · 실기 준비 여부)

| | |
|---|---|
| 날짜 | 2026-MM-DD |
| 길이 | 00분 |
| 물어본 사람 | |
| 도면 파일 받음 | 예 / 아니오 |

**직접 인용**
1. "
2. "
3. "

**지금 쓰는 대안**

**강한 신호** — 돈이나 시간을 쓴 적: 있음 / 없음. 무엇에:

**요약 3줄**
1.
2.
3.
```

## 양식 시험 기입 (실제 인터뷰 아님)

칸만 만들고 써 보지 않으면 인터뷰 자리에서 막힙니다. 아래는 **어떻게 채우는지 보여 주는
가짜 예시**이고, 실제로 만난 사람이 아닙니다. 첫 인터뷰가 들어오면 이 절은 지웁니다.

### 0. 대상 — (예시 · 실제 아님)

| | |
|---|---|
| 날짜 | 2026-08-25 |
| 길이 | 15분 |
| 물어본 사람 | (예시) |
| 도면 파일 받음 | 아니오 |

**직접 인용**
1. "(들은 말을 그대로. 다듬지 않는다.)"
2. "(우리 생각과 다른 말이 나오면 그게 제일 중요한 줄이다.)"
3. "(숫자가 나오면 숫자째로 적는다 — 몇 분, 몇 번, 몇 점.)"

**지금 쓰는 대안** — (무엇으로 확인하는지 도구 이름까지)

**강한 신호** — 돈이나 시간을 쓴 적: (있음/없음). 무엇에: (…)

**요약 3줄**
1. (겪은 일)
2. (언제 알았나)
3. (그때 뭘 했나)

## 폼 응답 — 대면 인터뷰와 따로 셉니다

[인터뷰 폼](../인터뷰폼/README.md)(https://cadlens-interview.pages.dev)으로 들어온 답입니다.
**W2 산출물 5건에는 넣지 않습니다.** 직접 인용 3개가 안 나오고, 3초 침묵과 꼬리 질문이
없어 대면 인터뷰와 같은 것으로 셀 수 없습니다. 다만 **문제 크기를 숫자로 말할 수 있는지**
(강의 자가점검 3번)에는 이쪽이 답이 됩니다.

### 폼 1. 특성화고 기계과 2학년 · 기능사 실기 준비 중

| | |
|---|---|
| 날짜 | 2026-08-27 14:16 UTC |
| 방식 | 웹 폼 (대면 아님) |
| 쓰는 것 | AutoCAD (2D) · Inventor (3D) |
| 그려 본 도면 | 1~5장 · 가끔 |
| 도면 파일 | "찾아보고 알려 줄게" — **후속 연락 필요** |

**시간** — 2D 부품도 2~3시간 + 3D 등각투상도 1~2시간 + 출력 5분 안쪽.
실기 제한은 5시간이고 **아슬아슬하게 끝냈다**고 답했다.
제출 전 확인에 **10분 넘게** 쓰고, 틀린 것을 고치는 데 **30분~1시간**이 들었다.

**빠뜨린 것 9개** — A4로 출력해서 잘림 · 모떼기·필렛 주서 · 스퍼기어·스프링 요목표 ·
재질 기입 · 척도 표기 · 투상도 하나 통째 빠뜨림 · 파일 날림·저장 실패 ·
표면거칠기 기호 · 표면거칠기 비교표.

**직접 적은 것** (원문 그대로)

> "표면거칠기 기호를 아예 안 넣음"

**지금 쓰는 대안** — 선생님이 준 목록으로 확인 + 출력해서 종이로 봄 + 친구한테 보여 줌.
셋을 다 하고 10분 넘게 쓴다. 확인해서 실제로 잡아 본 적도 있다.

**강한 신호 — 있음.** 안 틀리려고 인강을 봤고 **1~3시간**을 썼다. 돈은 안 썼다.

**언제 알았나 — "친구가 말해 줌".** 본인 확인으로는 못 찾았다.
깎인 점수는 1~5점이고, **처음이 아니라 두세 번째**다.

**요약 3줄**
1. 3중으로 확인하고 10분 넘게 쓰는데도 자기 도면의 누락은 자기 눈에 안 보인다.
2. 그걸 찾아 준 것은 도구가 아니라 **친구**였고, 그게 두세 번째다.
3. 제일 자주 빠뜨린 것은 **표면거칠기**다 — 고른 항목 9개 중 2개, 직접 적은 칸까지 합치면 3번 나온다.

**우리가 놓친 것** — 이 사람이 고른 9개 중 CADLens가 검사하는 것은 3개뿐이다.
대조는 [발전 계획](roadmap.md)의 "검사 자체가 없는 항목"에 옮겨 적었다.
