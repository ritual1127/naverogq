# 사용자 인터뷰

CADLens를 쓸 사람에게 직접 물은 것을 그대로 남기는 문서입니다.
우리가 생각한 문제와 실제로 겪는 문제가 다르면, 다른 쪽이 맞습니다.

질문은 [질문지](../plan/w2/08-25_화/질문지.md)를 씁니다. 대상은
[인터뷰 대상표](../plan/w2/08-25_화/인터뷰대상표.md)에 있습니다.
1건에 15분, 5건이 W2 산출물입니다.

## 적는 법

- **직접 인용 3개는 들은 말 그대로** 적습니다. 다듬으면 그 사람 말이 아니라 우리 말이 됩니다.
- **지금 쓰는 대안**은 구체적으로 적습니다. "그냥 확인한다"가 아니라 "친구한테 카톡으로 보내서 봐 달라고 한다".
- **강한 신호**는 이미 돈이나 시간을 쓴 경우입니다. "나오면 써 볼게요"는 신호가 아닙니다.
- 인터뷰가 끝나고 **5분 안에** 채웁니다. 미루면 인용이 요약으로 변합니다.
- 이름은 `박*후`처럼 가려 씁니다.

## 양식

아래를 복사해서 인터뷰마다 하나씩 이어 붙입니다.

```markdown
### N. 대상 — (학년 · 실기 준비 여부)

| | |
|---|---|
| 날짜 | 2026-MM-DD |
| 길이 | 00분 |
| 물어본 사람 | |
| 도면 파일 받음 | 예 / 아니오 |

**직접 인용**
1. "
2. "
3. "

**지금 쓰는 대안**

**강한 신호** — 돈이나 시간을 쓴 적: 있음 / 없음. 무엇에:

**요약 3줄**
1.
2.
3.
```

## 대면 인터뷰 5건

박\*후 · 박\*호 · 배\*후 · 최\*영 · 손선생님. 질문지 다섯 개를 그대로 썼고,
질문 1에서 나온 **가장 최근 실수 하나**를 질문 2~4까지 따라갔습니다.

날짜 · 길이 · 도면 수령 칸은 인터뷰 자리에서 안 적어 `미기록`으로 둡니다.
지어내지 않고, 확인되는 대로 채웁니다.

### 1. 박\*후 — 기계과 학생

| | |
|---|---|
| 날짜 | 미기록 |
| 길이 | 미기록 |
| 물어본 사람 | 프로젝트 팀 |
| 도면 파일 받음 | 미기록 |

**직접 인용**

1. "제일 최근에 낸 건 지난주 목요일 방과후에 한 동력전달장치 과제예요. 2D 네 부품하고 3D까지 다 해서 선생님한테 출력물로 냈어요. 그때 축에서 베어링 닿는 자리 있잖아요. 거기 표면거칠기 기호 하나를 빼먹었어요. 다른 데는 다 넣었다고 생각했는데, 그 부분만 치수선 사이에 기호를 넣어야 하는 걸 그냥 넘어갔어요. 저는 형상이랑 치수 맞추는 데만 눈이 가서 표면거칠기는 마지막에 몰아서 넣거든요. 그러니까 하나가 빠져도 화면이 비어 보이지 않아서 잘 모르겠더라고요."
2. "그리는 중에는 전혀 몰랐고요. PDF 미리보기까지도 못 봤어요. 종이로 한 번 뽑고 나서 친구랑 서로 바꿔 보는데 친구가 '여기 베어링 자리인데 거칠기 없어도 돼?'라고 해서 알았어요. 끝나기 17분 전쯤이었어요. 다시 뽑을 시간은 있기는 했는데, 그때 프린터 앞에 두 명이 기다리고 있어서 순간 그냥 낼까도 생각했어요."
3. "캐드 파일 열어서 그 면에 기호 넣는 건 한 2분밖에 안 걸렸어요. 근데 PDF 다시 만들고, 파일 이름 확인하고, 프린터 자리 기다렸다가 종이 방향까지 보고 뽑으니까 총 11분 정도 썼어요. 5시간 과제에서 11분이면 별거 아닌 것 같아도 마지막에는 1분도 크게 느껴져요. 그거 고치고 나니까 남은 6분 동안에는 다른 걸 거의 못 봤어요."

**지금 쓰는 대안** — 마지막에 한꺼번에 보지 않는다. 부품 하나마다
`투상도·단면 → 치수 → 끼워맞춤·치수공차 → 표면거칠기 → 기하공차` 순서로 닫고 다음 부품으로 간다.
네 부품이 끝나면 ① 표제란·부품란의 재질·수량 ② 주서와 열처리 ③ H7 구멍 공차와 짝이 되는 축 공차
④ 데이텀 A·B와 기하공차 화살표 ⑤ 빠진 치수·중복 치수 ⑥ 제3각법 배치와 단면 해칭을 본다.
화면에서는 부품을 창에 꽉 차게 확대해 **기호 개수를 세고**, PDF 미리보기에서 A3 가로 방향 ·
선 굵기 · 잘림을 본다. 마지막은 종이를 뽑아 친구와 한 장씩 바꿔 손가락으로 위에서 아래로 훑는다.
이 과정에 **12~15분을 아예 남겨 둔다.**

**강한 신호** — 돈이나 시간을 쓴 적: **있음**. 학원비는 안 냈지만 학교 방과후 실기를
**주 2회 × 2시간 × 6주**, 공개문제 **8세트**를 시간 재서 다시 그렸다. 자기 실수만 적은
A4 체크리스트를 만드는 데 30분을 썼고, 표면거칠기를 빠뜨린 뒤로 책상 오른쪽에 놓고 매번 본다.

**요약 3줄**
1. 가장 최근 제출물에서 베어링 접촉부 표면거칠기 기호 하나를 누락했다.
2. 출력 뒤 친구의 교차 확인으로 **종료 17분 전**에 발견했고 수정·재출력에 **11분**을 썼다.
3. 지금은 부품별 순서를 고정하고 화면 · PDF · 종이 · 친구 확인에 12~15분을 비워 둔다.

### 2. 박\*호 — 기계과 학생

| | |
|---|---|
| 날짜 | 미기록 |
| 길이 | 미기록 |
| 물어본 사람 | 프로젝트 팀 |
| 도면 파일 받음 | 미기록 |

**직접 인용**

1. "저는 그저께 감속장치 모의시험을 제출했습니다. 가장 최근에 잡힌 건 작은 커버 부품의 2D 뷰 척도였습니다. 기본 뷰를 배치할 때 프로그램이 자동으로 2:1을 잡았는데, 외곽 크기가 다른 부품과 얼추 비슷해 보여서 제가 그 상태로 치수를 끝까지 넣었습니다. 전체 도면은 1:1로 작업해야 하는데 커버만 2:1이었던 거죠. 눈으로 형상만 보면 정상처럼 보여서 속성값을 직접 열지 않으면 놓치기 쉬웠습니다."
2. "출력 직전, 그러니까 5시간 중 4시간 43분쯤에 알았습니다. PDF로 넘기기 전에 강사님이 '뷰 하나씩 눌러서 스케일 숫자 보고 내라'고 하신 게 생각나서 네 부품을 차례대로 눌렀어요. 앞의 세 개는 1:1이었는데 마지막 커버에 2:1이라고 뜨더라고요. 이미 배치는 끝났고 치수도 다 붙어 있어서 처음에는 숫자만 1:1로 바꾸면 도면이 겹칠까 봐 손이 잠깐 멈췄습니다."
3. "척도를 1:1로 바꾸고 작아진 뷰를 다시 정렬하고, 치수와 기호가 겹친 것 세 군데를 옮기는 데 6분 40초 정도 걸렸습니다. PDF 미리보기하고 첫 출력까지 합치면 11분 정도 썼고요. 결과적으로 6분 남기고 제출했습니다. 그날 채점에서는 다른 데서 4점이 깎였지만 척도는 고쳐서 넘어갔습니다. 그 뒤로는 '보기 좋게 들어갔나'보다 속성에 실제로 1:1이라고 적혔는지를 먼저 확인합니다."

**지금 쓰는 대안** — 시작할 때 템플릿이 제3각법인지, 2D 도면틀이 A2 작업 영역인지,
출력 설정이 A3인지 먼저 본다. 부품마다 기본 뷰를 놓는 순간 속성 창에서 1:1을 확인하고
나중에 전체 뷰를 선택해 한 번 더 대조한다. 최종 검토 순서는
`요구 부품번호 → 투상도 수와 배치 → 단면 방향 → 전체 치수 → 치수공차·끼워맞춤 →
표면거칠기 → 데이텀·기하공차 → 재료·열처리·주서 → 표제란·부품란`.
그다음 레이어를 하나씩 껐다 켜며 중심선과 숨은선을 보고, 흑백 PDF를 200%로 확대해
글자가 뭉개지거나 선과 겹친 데를 본다. **마지막 20분은 작도에 쓰지 않는다**는 원칙을 세웠고,
휴대전화 타이머 대신 시험장에서 볼 수 있는 손목시계 기준으로 연습한다.

**강한 신호** — 돈이나 시간을 쓴 적: **있음**. 국비 과정이라 본인 부담은 크지 않았으나
실기 교재에 **32,000원.** 최근 한 달은 평일 저녁 2시간씩 주 3회, 토요일은 5시간 모의시험.
완성 **11세트**이고 세트마다 종료 시각과 수정 시간을 엑셀에 적는다.
검토 시간이 처음 4분에서 지금 **18~22분**으로 늘었다.

**요약 3줄**
1. 커버 뷰가 자동으로 2:1이 된 것을 모르고 끝까지 치수를 기입했다.
2. 출력 직전 속성값 점검에서 발견해 **6분 40초** 동안 고쳤고 총 11분 뒤 출력했다.
3. 지금은 뷰를 놓는 순간과 최종 단계에서 척도를 두 번 확인하고 마지막 20분을 검토용으로 비운다.

### 3. 배\*후 — 비전공 · 독학

| | |
|---|---|
| 날짜 | 미기록 |
| 길이 | 미기록 |
| 물어본 사람 | 프로젝트 팀 |
| 도면 파일 받음 | 미기록 |

**직접 인용**

1. "마지막으로 완성해서 채점 받은 건 3주 전 온라인 스터디에 올린 드릴지그 도면입니다. 저는 솔직히 모양 만들고 치수 넣으면 거의 끝난 줄 알았습니다. 표면거칠기하고 끼워맞춤은 넣었는데 기하공차를 한 개도 안 넣었고, 기준 데이텀도 없었습니다. 조립도에서 어느 면을 기준으로 잡아야 하는지 확신이 없어서 '틀리게 넣느니 일단 빼고 제출하자'고 생각했어요. 그런데 그게 애매한 기호 하나를 빼는 정도가 아니라 제작도에 필요한 정보 묶음을 통째로 비워 둔 거더군요."
2. "낸 날에는 몰랐습니다. 스터디에서 첨삭해 주는 분이 이틀 뒤 밤에 PDF에 빨간색으로 데이텀 A 위치하고 직각도 들어갈 자리를 표시해 줘서 알았습니다. 5시간 안에 스스로 찾은 게 아니라 완전히 제출 뒤였죠. 그분이 쓰는 모의 채점표에서는 기하공차·데이텀 항목 8점을 전부 못 받은 걸로 표시했습니다."
3. "이미 제출한 다음이라 그 파일을 다시 고쳐서 재제출하지는 않았고, 다음 날 원본 조립도와 답안 예시를 옆에 띄워 놓고 같은 부품만 다시 했습니다. 데이텀을 왜 그 면에 잡는지 영상 두 개를 돌려 보고, 기하공차 프레임을 새로 만들어 넣는 데 1시간 25분 정도 썼습니다. 처음부터 도면을 다시 그린 게 아니라 기호를 이해하고 고치는 데만 그만큼 걸렸어요. 저 같은 비전공자는 명령어보다 '왜 여기 기준을 잡나'에서 시간이 훨씬 많이 빠집니다."

**지금 쓰는 대안** — 종이 체크리스트. 첫 줄에 요구 부품번호 네 개를 쓰고 완성할 때마다
동그라미를 친다. 부품마다 `정면·평면·측면 또는 필요한 단면 → 전체 크기와 위치 치수 →
일반 치수공차 → H7·g6 끼워맞춤 → 표면거칠기 → 데이텀 → 기하공차` 칸을 체크한다.
공차를 느낌으로 넣지 않으려고 **조립도에서 접촉면과 회전부를 형광펜으로 먼저 표시**하고 시작한다.
마지막에 표제란 · 부품란 · 재질 · 열처리 · 주서 · 척도를 화면 왼쪽 위부터 시계 방향으로 본다.
PDF는 닫았다 다시 열어 A3 한 장에 다 들어가는지, 흑백에서 중심선·치수선·외형선이 구분되는지 본다.
가족에게는 도면 내용이 아니라 **글자가 겹치거나 잘린 곳만** 찾아 달라고 부탁한다.

**강한 신호** — 돈이나 시간을 쓴 적: **있음**. 유료 강의는 안 샀고 준비에 **넉 달**.
평일 퇴근 후 1시간 반 × 주 4일, 주말은 공개문제를 5시간 재서 푼다. 출력 파일까지 완성한 것
**13세트.** 중고 교재 **18,000원**. 첫 시험에서 시간 안에 2D를 못 끝내 출력 자체를 못 했기 때문에
돈보다 **한 번에 끝까지 완성하는 연습**에 시간을 가장 많이 쓴다.

**요약 3줄**
1. 기준면을 확신하지 못해 데이텀과 기하공차를 통째로 비운 채 제출했다.
2. **이틀 뒤** 첨삭에서 모의 배점 8점 전체가 빠진 것을 보고 문제 크기를 알았고 복습에 1시간 25분을 썼다.
3. 지금은 부품별 체크칸과 접촉면 형광펜 표시를 쓰며 13세트를 시간제한으로 완주했다.

**직접 인용**

1. "저는 도면 내용보다 출력에서 한 번 크게 틀렸어요. 지난달 학과 실습실에서 5시간 모의로 했는데, 캐드에서는 A2 도면틀에 맞춰 놓고 PDF도 정상처럼 보였거든요. 그런데 프린터 창에서 전에 쓰던 A4 설정이 그대로 남아 있는 걸 안 바꾸고 출력했습니다. 종이가 나오는데 도면이 너무 작고 오른쪽 표제란 일부가 잘려 있더라고요. 화면에서 맞았으니까 출력도 맞을 거라고 생각한 게 문제였죠."
2. "출력하고 종이를 손에 든 순간 알았어요. 종료 21분 전이었습니다. 다행히 실습이라 종이를 한 장 더 쓸 수 있었지만, 실제 시험이면 지급 용지하고 대기 줄 때문에 훨씬 당황했을 것 같아요. 그때 프린터 앞에 다른 두 명도 있었고, 다시 자리로 돌아가 설정을 고치면 마지막 검토 시간이 거의 없어지는 상황이었습니다."
3. "PDF 페이지 자체가 A3인지 다시 보고, 인쇄 창에서 A3·맞추기·가로 방향을 선택한 다음 미리보기 테두리를 확인했습니다. 설정 확인에 2분, 대기와 출력에 5분 정도여서 7분을 썼습니다. 두 번째 종이를 책상에 펴서 잘린 곳하고 선 굵기만 4분 더 보고 제출했으니, 출력 실수 때문에 총 11분이 나간 셈입니다."

**지금 쓰는 대안** — **내용 검토와 출력 검토를 아예 분리한다.** 내용은 요구 부품번호와
투상도·단면도 → 치수 → 끼워맞춤 → 표면거칠기 → 기하공차·데이텀 → 재료·주서 → 표제란 순.
출력 단계에서는 내용으로 돌아가지 않고 `PDF 페이지 크기 A3 → 프린터 용지 A3 → 맞추기 →
가로/세로 방향 → 중앙 배치 → 흑백 → 선 굵기 → 잘림 여부` **여덟 개만** 본다.
PDF는 100%와 200%를 둘 다 보고, 첫 종이가 나오면 자로 재지는 않아도 윤곽선 네 변 ·
표제란 오른쪽 끝 · 가장 위쪽 치수부터 본다. 학교 실습에서는 친구와 **출력물만 2분씩 바꿔**
서로 잘림이나 너무 옅은 선만 말해 준다.

**강한 신호** — 돈이나 시간을 쓴 적: **있음**. 온라인 실기 강의 한 달 **40,000원**.
집에 A3 프린터가 없어 복사집에서 2주 동안 **14번 출력**, 약 **18,200원**.
같은 PDF가 아니라 척도와 선 가중치를 조금씩 바꿔 가며 종이에서 어떻게 보이는지 비교했고,
출력 체크 여덟 개는 그때 직접 만들었다.

**요약 3줄**
1. CAD 도면은 정상인데 프린터의 이전 **A4 설정**을 그대로 써서 축소·잘림이 났다.
2. **종료 21분 전** 종이로 발견해 설정 수정 · 재출력 · 종이 검토에 총 11분을 썼다.
3. 지금은 내용 검토와 A3 출력 검토를 분리하고 실제 종이 출력 연습에 돈을 쓴다.

**직접 인용**

1. "마지막 과제는 이번 주 화요일 야간반에서 한 드릴지그였어요. 본체 안쪽에 구멍하고 턱이 있는데 제가 정면 외형하고 숨은선만 그려 놓고 단면도를 안 만들었습니다. 현장에서는 완성 도면을 받아서 가공하니까 조립도 보고 필요한 투상도를 고르는 게 생각보다 어렵더라고요. 화면에는 선이 많으니까 뭔가 다 그린 것처럼 보였어요. 그런데 치수를 넣으려니까 안쪽 턱 깊이를 어디에 줘야 할지가 애매했습니다."
2. "그리는 중에 알았습니다. 5시간 중 3시간 32분쯤이었어요. 외형은 끝났고 네 부품 치수를 넣는 중이었는데, 그 본체 내부 치수를 숨은선에 억지로 달려니까 도면이 너무 지저분해졌습니다. 그때 강사님이 지나가다가 답을 말해 주지는 않고 '그 안쪽 모양을 작업자가 이 뷰만 보고 알 수 있겠어요?'라고 물으셨어요. 그 말을 듣고 제가 단면을 빼먹었다는 걸 알았습니다."
3. "처음에는 감점 조금 받고 그냥 갈까 했는데, 내부 형상 치수를 제대로 못 주면 한두 점짜리가 아니겠다고 판단했습니다. 기존 정면도를 복사해서 절단 위치를 잡고, 불필요한 숨은선을 정리하고, 해칭 간격 맞추고, 치수를 다시 옮기는 데 24분 걸렸습니다. 그 24분 때문에 3D 등각 배치를 급하게 했고 최종 확인은 5분밖에 못 했어요. 모의 채점에서는 단면은 맞게 고쳤지만 주서 하나와 부품란 재질 하나가 틀려서 6점이 깎였습니다."

**지금 쓰는 대안** — 시작하자마자 캐드를 켜지 않는다. 문제지에서 요구 부품번호를 먼저
동그라미 치고, 각 부품의 기준 정면을 잡은 다음 내부 형상이 있는 곳에
**빨간 펜으로 "단면 필요?"라고 적는다.** 종이에 정면·평면·측면 배치를 30초쯤 손그림으로
그려 보고 들어간다. CAD에서는 외형 다음에 곧바로 단면과 해칭까지 끝내고 치수 · 끼워맞춤 ·
표면거칠기 · 기하공차 순으로 한 부품씩 닫는다. 마지막은 현장에서 가공 순서 보듯
`재료와 열처리 → 기준면 → 끼워지는 자리 → 가공면 거칠기 → 전체와 부분 치수`를 **역으로** 본다.
그다음 표제란·부품란·주서를 확인하고 PDF 미리보기에서 A3 · 척도 · 제3각법 배치 · 선 굵기를 본다.
친구에게 봐 달라고 하지는 않고, 학원 강사에게 **제출 뒤 틀린 항목만 표시해 달라**고 해서
다음 과제 체크판에 더한다.

**강한 신호** — 돈이나 시간을 쓴 적: **있음**. 야간 학원 6주 과정 **420,000원**.
화·목은 퇴근 후 3시간 수업, 일요일은 자습실에서 5시간 모의. 끝까지 출력한 것 **아홉 장**이고

조립도 **열다섯 개**에서 필요한 뷰를 종이에 스케치했다. 그 연습만 **약 7시간**.

## 우리가 틀리게 알고 있던 것

인터뷰의 값어치는 여기입니다. 예상과 달랐던 것만 적습니다.

1. **"채점 뒤에야 안다"고 봤는데, 5명 중 4명이 제출 전에 찾았다.**
   발견 시점은 종료 17분 전 · 4시간 43분 · 작업 3시간 32분 · 종료 21분 전이었고,
   제출 뒤에 안 것은 배\*후 한 명(이틀 뒤)뿐이다.
   우리는 "몰라서 못 고친다"를 문제로 잡았는데, 실제로 더 자주 나온 것은
   **찾고 나서 고칠 시간이 없다**였다. 고치는 데 11분 · 11분 · 11분 · 24분 · 1시간 25분이 들었고,
   그 시간 때문에 다른 검토를 잃었다는 말이 세 번 나왔다.
   값어치는 "누락을 알려 주는 것"보다 **더 일찍 알려 주는 것**에 있다.
2. **찾아 준 것은 도구가 아니라 사람이었다.** 친구 · 스터디 첨삭자 · 강사.
   폼 응답 1건도 친구였다. 아무도 "프로그램으로 확인한다"고 하지 않았다.
   경쟁 상대는 다른 검사 도구가 아니라 **옆자리 친구와 종이 한 장**이다.
3. **다섯 명의 최근 실수가 전부 다른 항목이었다.** 우리는 표면거칠기 같은 항목 하나가
   반복될 것으로 봤는데, 반복된 것은 항목이 아니라 **행동**이었다 —
   검토 시간 비우기 · 순서 고정 · 종이로 다시 보기.
4. **도면 밖에서 죽는 경우가 있다.** 최\*영의 최근 실수는 도면이 아니라 프린터 설정이었고,
   박\*호는 척도 값이 표준(2:1)이라 우리 검사에 걸리지 않는다. DXF만 읽는 한 이 둘은
   원리상 못 잡는다. "검사 24개가 실기 채점을 덮는다"는 우리 전제가 여기서 처음 깨졌다.
5. **선생님께 물으려던 것을 못 물었다.** 가장 많이 나오는 실수 셋 · 한 반 채점 시간 ·
   나눠 주시는 목록 — 이 셋이 [대조표](../plan/w2/08-28_금/대조표.md)의 B·C·D 칸을 채울
   유일한 입력인데 답이 없다. 대조표는 아직 못 채운다.
6. **강한 신호 5/5.** 기준(3명 미만이면 문제를 다시 본다)을 넘겼다. 게다가 다섯 명 중
   **네 명이 실제로 돈을 썼다** — 교재 32,000원 · 중고 교재 18,000원 · 강의 40,000원 ·
   출력 18,200원 · 야간 학원 420,000원.

| 친구·강사가 메우고 있어 | 박\*후(친구) · 배\*후(스터디 첨삭자) · 손선생님(강사) · 폼 1(친구) |
| 옆에 봐 줄 사람이 없으면 그대로 낸다 | 배\*후 "5시간 안에 스스로 찾은 게 아니라 완전히 제출 뒤였죠" |

**이 문장이 덮지 못하는 것을 적어 둡니다.** "스스로 못 찾는다"는 5/5가 아니라 **3/5**입니다.
박\*호는 속성값을 하나씩 눌러서, 최\*영은 종이를 손에 들고 **자기가** 찾았습니다.
그리고 다섯 중 넷은 제출 **전에** 찾았고, 손해를 본 지점은 고치는 데 든 시간
(11분 · 11분 · 11분 · 24분 · 1시간 25분)이었습니다. 시간 쪽을 앞세운
후보 A 도 인터뷰가 똑같이 강하게 가리켰지만, 한 문장에 둘을 담으면
문제를 두 개 푸는 문장이 되므로 **사람 쪽 하나만** 남겼습니다.
시간 쪽은 버리지 않고 [발전 계획](roadmap.md)과 미션 문장 뒷절에 남깁니다.

### 폼 1. 특성화고 기계과 2학년 · 기능사 실기 준비 중

| | |
|---|---|
| 날짜 | 2026-08-27 14:16 UTC |
| 방식 | 웹 폼 (대면 아님) |
| 쓰는 것 | AutoCAD (2D) · Inventor (3D) |
| 그려 본 도면 | 1~5장 · 가끔 |
| 도면 파일 | "찾아보고 알려 줄게" — **후속 연락 필요** |

**시간** — 2D 부품도 2~3시간 + 3D 등각투상도 1~2시간 + 출력 5분 안쪽.
실기 제한은 5시간이고 **아슬아슬하게 끝냈다**고 답했다.
제출 전 확인에 **10분 넘게** 쓰고, 틀린 것을 고치는 데 **30분~1시간**이 들었다.

**빠뜨린 것 9개** — A4로 출력해서 잘림 · 모떼기·필렛 주서 · 스퍼기어·스프링 요목표 ·
재질 기입 · 척도 표기 · 투상도 하나 통째 빠뜨림 · 파일 날림·저장 실패 ·
표면거칠기 기호 · 표면거칠기 비교표.

**직접 적은 것** (원문 그대로)

> "표면거칠기 기호를 아예 안 넣음"

**지금 쓰는 대안** — 선생님이 준 목록으로 확인 + 출력해서 종이로 봄 + 친구한테 보여 줌.
셋을 다 하고 10분 넘게 쓴다. 확인해서 실제로 잡아 본 적도 있다.

**강한 신호 — 있음.** 안 틀리려고 인강을 봤고 **1~3시간**을 썼다. 돈은 안 썼다.

**언제 알았나 — "친구가 말해 줌".** 본인 확인으로는 못 찾았다.
깎인 점수는 1~5점이고, **처음이 아니라 두세 번째**다.

**요약 3줄**
1. 3중으로 확인하고 10분 넘게 쓰는데도 자기 도면의 누락은 자기 눈에 안 보인다.
2. 그걸 찾아 준 것은 도구가 아니라 **친구**였고, 그게 두세 번째다.
3. 제일 자주 빠뜨린 것은 **표면거칠기**다 — 고른 항목 9개 중 2개, 직접 적은 칸까지 합치면 3번 나온다.

**우리가 놓친 것** — 이 사람이 고른 9개 중 CADLens가 검사하는 것은 3개뿐이다.
대조는 [발전 계획](roadmap.md)의 "검사 자체가 없는 항목"에 옮겨 적었다.
