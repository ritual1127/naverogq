# 사용자 인터뷰

CADLens를 쓸 사람에게 직접 물은 것을 그대로 남기는 문서입니다.
우리가 생각한 문제와 실제로 겪는 문제가 다르면, 다른 쪽이 맞습니다.

질문은 [질문지](../plan/w2/08-25_화/질문지.md)를 씁니다. 대상은
[인터뷰 대상표](../plan/w2/08-25_화/인터뷰대상표.md)에 있습니다.
1건에 15분, 5건이 W2 산출물입니다.

## 적는 법

- **직접 인용 3개는 들은 말 그대로** 적습니다. 다듬으면 그 사람 말이 아니라 우리 말이 됩니다.
- **지금 쓰는 대안**은 구체적으로 적습니다. "그냥 확인한다"가 아니라 "친구한테 카톡으로 보내서 봐 달라고 한다".
- **강한 신호**는 이미 돈이나 시간을 쓴 경우입니다. "나오면 써 볼게요"는 신호가 아닙니다.
- 인터뷰가 끝나고 **5분 안에** 채웁니다. 미루면 인용이 요약으로 변합니다.
- 이름은 적지 않습니다. `학생 A`처럼 씁니다.

## 양식

아래를 복사해서 인터뷰마다 하나씩 이어 붙입니다.

```markdown
### N. 대상 — (학년 · 실기 준비 여부)

| | |
|---|---|
| 날짜 | 2026-MM-DD |
| 길이 | 00분 |
| 물어본 사람 | |
| 도면 파일 받음 | 예 / 아니오 |

**직접 인용**
1. "
2. "
3. "

**지금 쓰는 대안**

**강한 신호** — 돈이나 시간을 쓴 적: 있음 / 없음. 무엇에:

**요약 3줄**
1.
2.
3.
```

## 양식 시험 기입 (실제 인터뷰 아님)

칸만 만들고 써 보지 않으면 인터뷰 자리에서 막힙니다. 아래는 **어떻게 채우는지 보여 주는
가짜 예시**이고, 실제로 만난 사람이 아닙니다. 첫 인터뷰가 들어오면 이 절은 지웁니다.

### 0. 대상 — (예시 · 실제 아님)

| | |
|---|---|
| 날짜 | 2026-08-25 |
| 길이 | 15분 |
| 물어본 사람 | (예시) |
| 도면 파일 받음 | 아니오 |

**직접 인용**
1. "(들은 말을 그대로. 다듬지 않는다.)"
2. "(우리 생각과 다른 말이 나오면 그게 제일 중요한 줄이다.)"
3. "(숫자가 나오면 숫자째로 적는다 — 몇 분, 몇 번, 몇 점.)"

**지금 쓰는 대안** — (무엇으로 확인하는지 도구 이름까지)

**강한 신호** — 돈이나 시간을 쓴 적: (있음/없음). 무엇에: (…)

**요약 3줄**
1. (겪은 일)
2. (언제 알았나)
3. (그때 뭘 했나)
