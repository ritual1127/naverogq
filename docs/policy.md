## 개인정보 처리

**한 줄로 줄이면 이렇습니다. 회원가입이 없고, 개인정보를 받지 않고, 올린 도면은 검사가 끝나면 서버에서 지웁니다.**

**안 받는 것** — 계정도 로그인도 회원가입도 없습니다. 이름, 이메일, 전화번호, 학교, 수험번호를 묻지 않습니다. 쿠키를 안 씁니다. Google Analytics, 광고 SDK, 오류 수집 도구 같은 남의 추적 코드도 전부 없습니다. 외부 사이트에서 파일을 불러오는 것도 없어서 three.js까지 저희 서버에 직접 올려 뒀습니다.

**세는 것 — 접속 수와 검사 횟수, 그리고 재검사 횟수뿐입니다.** 2026-08-30 부터 화면 아래 "사용 현황"에 나오는 숫자입니다. 몇 명이 들어왔고 도면을 몇 번 검사했는지, 그중 고쳐서 다시 올린 것이 몇 번인지를 저희 서버가 직접 셉니다. 2026-09-05 부터 검사 완료와 재검사도 셉니다. 남의 분석 도구를 붙이지 않았고 쿠키도 여전히 안 씁니다.

| | |
|---|---|
| 무엇을 남기나 | **날짜 · 방문자 값 · 종류 · 횟수**, 이 네 개뿐입니다. 종류는 다섯 가지입니다 — 접속 · 검사 시작 · 예제 검사 · 검사 완료 · **재검사** |
| 재검사는 어떻게 아나 | 같은 파일 이름의 지난 결과가 **내 브라우저 안에** 있을 때 화면이 서버로 `재검사` 라는 종류 이름 하나만 보냅니다. **파일 이름도 점수도 도면 내용도 보내지 않습니다** |
| 방문자 값이 뭔가 | `그 서버만 아는 임의의 값 + 그 주 + IP` 를 해시한 **16자**입니다. IP 원본도, 그 해시를 되돌릴 수 있는 것도 저장하지 않습니다 |
| 왜 주 단위인가 | 저희 목표 지표가 **주간 재검사 사용자 수**여서입니다. 주가 바뀌면 같은 사람이라도 값이 달라져 **주를 넘겨서는 이어 볼 수 없습니다** |
| 안 남기는 것 | 어떤 도면을 올렸는지, 파일 이름, 검사 결과 점수, 브라우저 종류, 어느 페이지에서 왔는지 — 전부 안 남깁니다 |
| 누가 보나 | 아무나 봅니다. 화면 아래와 `/api/stats` 에 그대로 공개합니다. 숨겨 두고 저희만 보는 통계가 아닙니다 |
| 어디에 두나 | 인터뷰 폼이 쓰는 것과 같은 Cloudflare D1 안에 `hits` 표로 둡니다. 인터뷰 답과 섞이지 않습니다 |
| 얼마나 두나 | 지웠다는 기록이 없으면 계속 둡니다. D1 연결이 없으면 서버 안에 두는데, 그때는 서버가 다시 시작될 때 **0부터 다시 셉니다** |

IP 를 아예 안 쓰고 셀 방법은 없습니다. 브라우저에 쿠키를 심는 방법도 있지만, 미성년 이용자가 대부분이라 **브라우저에 아무것도 안 남기는 쪽**을 골랐습니다.

**올린 도면**

| | |
|---|---|
| 뭐에 쓰나 | **그 검사 한 번에만** 씁니다 |
| 얼마나 두나 | **최대 1시간, 최근 20건까지만.** 넘으면 폴더째 지웁니다 |
| 남이 볼 수 있나 | 폴더 이름이 아무렇게나 만든 값이고, 올린 파일을 다시 내려받는 기능 자체가 없습니다 |
| AI 학습에 쓰나 | **안 씁니다.** 사용자 도면으로 어떤 AI도 학습시키지 않습니다 |
| 팔거나 남한테 주나 | 안 합니다 |

**밖으로 나가는 것 — 이건 꼭 알아두세요.** 투상도 30점을 채점할 때 **도면을 그림(PNG)으로 바꿔서 Google Gemini에 보냅니다.** 지금 공개 서버에서 이 기능이 켜져 있습니다. 보내는 건 도면 그림 1장과 파일 종류·투상법·뷰 개수 정도의 요약이고, **원본 DWG나 DXF 파일 자체는 안 보냅니다.** 보낸 뒤로는 Google의 개인정보처리방침과 Gemini 약관을 따르며, 저희가 어떻게 할 수 있는 부분이 아닙니다. 같은 도면을 다시 검사하면 저장해 둔 답을 써서 다시 보내지 않습니다. Gemini가 응답하지 않을 때는 같은 그림이 Cloudflare Workers AI로, 그마저 막히면 Mistral이나 Groq로 갑니다. 보내는 내용과 보내지 않는 것(원본 파일)은 어느 쪽이든 같습니다.

**도면 안에 들어 있는 개인정보 — 주의.** 도면 표제란에 이름을 적었으면 **그 이름이 결과 화면에 그대로 뜹니다.** CADLens가 표제란의 작성자·설계자 칸(`DESIGNER`, `DRAWN BY`, `작성자`, `설계자`)을 읽어서 "파일 정보"에 보여주기 때문입니다. 저희가 따로 모으는 게 아니라 도면 파일 안에 원래 들어 있는 값입니다. **남기기 싫으면 올리기 전에 지우고 올리세요.**

**브라우저에만 저장되는 것** — 아래 4개는 내 브라우저에만 있고 서버로 안 갑니다. `cadcheck.lang`(언어), `cadcheck.theme`(밝은/어두운 화면), `cadcheck.enabled`(켜 둔 검사 항목), `cadcheck.history`(다시 검사해서 비교하려고 남기는 기록 — 파일 이름, 시각, 점수, 지적 항목. 최근 20건까지).

문의나 삭제 요청은 [GitHub 이슈](https://github.com/ritual1127/naverogq/issues)로 남겨 주세요. 최대 1시간만 두기 때문에 대부분은 말씀하실 때쯤 이미 지워져 있습니다.

## AI 생성물 표기

**AI가 만드는 건 90점 중 30점입니다.** 배점이 가장 큰 항목이고, 조건식으로는 채점할 수 없어 AI에 맡긴 부분입니다.

| 채점 항목 | 배점 | 누가 만드나 |
|---|---|---|
| **투상도 선택과 배열** | **30점** | **AI (Gemini · Cloudflare Workers AI · Mistral · Groq)** |
| 치수 / 공차 / 표면거칠기 / 기하공차 / 주서·표제란 / 재료 | 60점 | 규칙 코드 |
| 실격 판정 5가지 | — | 규칙 코드 |

- **투상도 30점과 "AI 총평" 문장이 AI가 만든 결과입니다.** 도면을 그림으로 바꿔 멀티모달 모델에게 채점위원 기준으로 보여주고, 응답은 JSON 스키마로 묶어 받습니다. 나머지 60점과 실격 판정은 규칙 코드가 맡습니다.
- **지적마다 붙는 질문 버튼 세 개의 답도 AI가 만듭니다.** `왜 감점이야?` · `어디를 눌러?` · `고친 뒤 확인은?` 세 가지이고, 채점할 때 답까지 함께 만들어 저장해 둡니다. 버튼을 눌러도 AI를 새로 부르지 않습니다.
- 화면에서 AI가 매긴 항목에는 **보라색 `AI` 표시**를 붙이고, 총평 상자에도 **AI가 쓴 문장**이라고 적어 둡니다. 화면 위쪽에 AI가 켜졌는지도 나옵니다.
- **AI 점수는 매번 똑같이 안 나옵니다.** 같은 도면을 다시 올려도 점수가 달라질 수 있습니다. 그래서 AI한테 "확실하지 않으면 감점하지 말고 참고로만 남겨라"라고 지시해 뒀고, 이 지시문도 코드에 그대로 공개돼 있습니다.
- **AI 채점기는 네 곳입니다.** Gemini를 먼저 쓰고, 막히면 Cloudflare Workers AI, Mistral, Groq 순으로 넘어갑니다. 한 곳의 할당량이 끊겨도 30점 채점이 멈추지 않게 하려는 것이고, 네 경로 모두 같은 지시문과 같은 응답 형식을 씁니다.
- **키가 아예 없으면** 30점이 "사람 확인 필요"로 뜨고, AI가 꺼져 있다는 것도 화면에 그대로 나옵니다. 없는데 있는 척하지 않습니다.

**코드와 문서를 쓸 때도 AI를 썼습니다.** Claude Code(Claude Opus 5 / Sonnet 5 / Sonnet 4.8), GPT-5.6 Sol, Gemini를 썼습니다. 사람이 한 건 뭘 만들지 정하기, 검사 항목 고르고 KS 규격과 대조하기, 배점 정하기, 실제 도면으로 돌려보며 오류 찾기, 기준 도면 만들기, 마지막에 읽어보고 고칠지 결정하기입니다. AI가 한 건 코드 초안, 코드 정리, 문서와 번역 초안이고 **전부 사람이 확인한 다음에 넣었습니다.**

**AI가 만들지 않은 것** — 검사 규칙 24개의 판정 부분(`exam.py`, `dwg.py`)은 실행할 때 AI를 부르지 않는 순수 규칙 코드입니다. 배점표는 공개된 채점 기준을 보고 사람이 정했고, 정확도 숫자는 `bench.py`로 실제로 잰 값입니다. 로고와 화면 디자인도 직접 만들었습니다.

## 미성년자 안전

**주로 쓰는 사람이 특성화고 학생을 포함한 미성년자라는 걸 전제로 만들었습니다.**

| 걱정되는 것 | CADLens는 어떻게 했나 |
|---|---|
| 개인정보 수집 | **회원가입도 로그인도 없습니다.** 이름·나이·학교·연락처를 묻는 칸 자체가 없습니다 |
| 행동 추적 | **남의 추적 코드가 없습니다.** 쿠키, 분석 도구, 광고 SDK 전부 안 씁니다. 저희가 세는 것은 접속 수와 검사 횟수뿐이고 IP 는 주 단위로 해시해 원본을 저장하지 않습니다 |
| 결제 | **없습니다.** 전부 무료고 결제 화면이 아예 없습니다 |
| 광고 | **없습니다.** 배너도 외부 광고 코드도 한 줄 없습니다 |
| 유해한 내용 | 다루는 게 기계 도면뿐입니다. 이미지나 글을 마음대로 만들어내는 기능이 없습니다 |
| 사용자끼리 접촉 | **채팅·댓글·게시판·프로필·친구 기능이 전부 없습니다.** 사용자끼리 만날 곳이 아예 없어서 괴롭힘이나 접근이 생길 구조가 아닙니다 |
| 외부 링크 | 화면에서 나가는 링크는 프로젝트 GitHub 저장소 하나뿐입니다 |

**AI가 안전한 이유** — AI한테 도면 그림 1장을 주고 투상도 배열만 채점하라고 역할을 고정했습니다. 학생이 AI한테 아무 말이나 보낼 수 있는 입력칸이 없습니다. 지적마다 붙는 질문 버튼도 **미리 정해 둔 세 가지뿐이고, 답도 채점할 때 함께 만들어 저장해 둔 것**이라 버튼을 눌러도 AI를 새로 부르지 않습니다. 답변도 정해진 형식(`severity`, `title`, `detail`, `fix`, `deduct`)으로만 받아서, 형식을 벗어난 아무 말이 화면에 뜨지 않습니다. AI가 형식을 안 지키거나 답변을 거부하면 그 결과를 버리고 "사람 확인 필요"로 처리하고, AI가 매기는 감점은 30점을 넘을 수 없게 코드에서 막아 뒀습니다.

**학생을 보호하려고 넣은 표시** — 결과 화면에 "제출 전 확인용 보조 도구고, 최종 제출 전에는 공식 기준을 봐야 한다"는 안내를 항상 띄웁니다. AI가 채점한 항목에는 AI 표시를 붙여 확정 점수가 아니라는 걸 알 수 있게 했고, 확실하지 않은 항목은 감점하지 않고 "사람 확인 필요"로 남깁니다. **틀린 지적으로 학생을 엉뚱한 방향으로 보내지 않는 것**을 제일 중요하게 봤습니다.

**보호자와 선생님께** — 학생이 올린 도면은 서버에 최대 1시간 있다가 지워지고, AI 학습에 쓰이지 않습니다. 투상도 채점 때 도면 그림이 AI로 가지만(위 `개인정보 처리` 참고), 원본 도면 파일과 학생 정보는 보내지 않습니다. 다만 도면 표제란에 학생 이름이 있으면 결과 화면에 뜨니, 수업에서 다 같이 쓰실 때는 **이름을 지우고 올리라고** 안내해 주세요. 걱정되는 점은 [GitHub 이슈](https://github.com/ritual1127/naverogq/issues)로 알려주시면 확인하겠습니다.

## 저작권

- **사용자가 올린 도면** — 저작권은 그린 사람 것입니다. 검사하려고 잠깐 처리할 뿐 소유권이나 사용권을 주장하지 않고, 학습에 쓰거나 다시 배포하거나 팔지 않고, 최대 1시간 뒤에 지웁니다.
- **시험 문제와 채점 기준** — KS 제도 규격, Q-Net이 공개한 [공개문제](https://www.q-net.or.kr/cst006.do?artlSeq=5198906&brdId=Q006&code=1204&gSite=Q&id=cst00602), 공개된 채점 기준만 보고 만들었습니다. **한국산업인력공단의 비공개 채점표를 베끼거나 본 적이 없습니다.** 배점은 `exam.py` 맨 위에 근거와 같이 적어 뒀고, 공개문제 파일을 저장소에 다시 올리지 않았습니다. **CADLens는 공식 채점이 아니고 한국산업인력공단·Q-Net과 아무 관계가 없습니다.**
- **예제 도면** — 저장소에 넣은 예제와 정확도 측정용 도면은 저희가 직접 만들었거나 개인정보를 지운 것입니다. 남의 도면을 함부로 넣지 않았습니다.
- **상표** — `AutoCAD`와 `Inventor`는 Autodesk의 상표, `Q-Net`은 한국산업인력공단의 서비스입니다. 뭘 지원하는지 설명하려고 이름을 쓴 것뿐이고 각 회사와 관계가 없습니다.
- **폰트** — 홈 화면 3D 글자는 Segoe UI Black의 글자 모양을 미리 좌표로 바꿔 쓴 것이고, **폰트 파일 자체는 저장소에 안 넣었습니다.**
- **남의 프로그램** — **LibreDWG(GPL-3.0)** 는 별도 프로그램으로 실행만 하고 코드를 가져다 붙이지 않아서 저희 MIT 코드에 GPL이 옮겨붙지 않습니다. **PyMuPDF(AGPL-3.0)** 는 저희가 소스를 전부 공개하고 있어서 조건을 지키고 있고, 소스를 안 열고 파는 경우엔 상용 라이선스가 필요합니다. 자세한 건 [`../NOTICE.md`](../NOTICE.md)에 있습니다.

**주의사항** — CADLens는 마지막에 확인하는 걸 도와주는 보조 도구입니다. 도면의 기능이 맞는지, 실제로 가공할 수 있는지, 그 회차의 특별 지시사항까지는 대신 판단할 수 없습니다. 제출 전에는 꼭 그 회차의 공개문제와 지급 자료, 감독위원 지시사항을 같이 확인하세요.
