# Inventor — 실기에서 어떻게 쓰이고, CADLens는 어디까지 읽는가

기준일 2026-09-08. 이 문서는 "인벤터 파일을 그대로 받게 해 달라"는 요구에 답하기 위해
**실기 요구사항 · 파일 형식 · 서버에서 읽는 방법 네 가지 · 우리가 고른 길**을 한자리에
정리한 것입니다. 확인한 것과 확인 못 한 것을 나눠서 적습니다.

---

## 1. 실기에서 Inventor가 놓인 자리

전산응용기계제도기능사 실기는 **5시간** 동안 2D 과제도면을 해독해 3D CAD로 모델링하고,
그 모델에서 **2D 부품도**와 **3D 렌더링 등각투상도** 두 장을 만들어 **출력해서** 냅니다.
2D는 AutoCAD·ZwCAD, 3D는 Inventor·SolidWorks를 주로 씁니다.
**제출은 출력물이고 파일로는 내지 않습니다.**

그래서 CADLens는 시험장 도구가 아니라 **연습·제출 직전 점검 도구**입니다. 학생 PC에 있는
Inventor 파일을 우리가 읽을 수 있으면 그만큼 점검 범위가 넓어집니다.

### 요구사항에서 검사로 옮길 수 있는 것

| 요구사항 | 출처 | CADLens 검사 |
|---|---|---|
| 부품도는 **A2 용지**에 제도, 척도 **1:1**, **제3각법** | 공개문제 요구사항 | `EX_SHEET_SIZE` · `EX_SCALE_NOT_ONE` · `DQ_PROJECTION` |
| 출력은 지급된 **A3(420×297)** 용지에 흑백 | 공개문제 · 나무위키 | A3 도면 영역은 오작이 아니라 경고 |
| 3D 등각투상도는 척도 **NS**, 부품 1개당 등각축 2개, 음영·렌더링 | 공개문제 요구사항 | 척도 NS 는 통과. **등각축·음영은 미구현** |
| 3D 등각투상도 **부품란 비고에 질량(g, 소수점 첫째자리 반올림)** | 공개문제 요구사항 (2018년부터) | `EX_NO_MASS` |
| 재료 기호를 부품란에 기입 | 채점 항목 '재료 선택과 처리' | `EX_NO_MATERIAL` |
| 도면 범위 밖 요소가 출력에 섞이지 않게 | 수험자 유의사항 | **범위 밖** — 출력 설정은 DXF에 없다 |

## 2. Inventor 파일 형식

| 확장자 | 무엇 | CADLens |
|---|---|---|
| `.ipt` | 부품 (3D) | 못 읽음 — 도면으로 만든 뒤 내보내라고 안내 |
| `.iam` | 조립품 (3D) | 못 읽음 — 같음 |
| `.idw` | 도면 (2D) | 못 읽음 — DWG/DXF 로 내보내라고 안내 |
| `.ipn` | 프레젠테이션 | 못 읽음 |
| `.dwg` (Inventor 저장) | 도면 | **읽음** (서버의 LibreDWG 로 DXF 변환) |
| `.dxf` (Inventor 내보내기) | 도면 | **읽음** — 지금 실기 도면 표본이 이 경로다 |

`.ipt` 는 OLE2 컨테이너 안에 자체 형식이 들어 있고, **버전이 올라갈 때마다 형식이 바뀝니다.**
공개 규격이 아니라서 서버에서 직접 파싱하는 것은 유지보수가 감당이 안 됩니다.

## 3. 서버에서 Inventor 파일을 읽는 방법 — 네 가지 비교

| 방법 | 되는 것 | 걸리는 것 | 판단 |
|---|---|---|---|
| **Inventor COM 자동화** (`idw2dxf.py`) | idw → DXF 완전 변환. 원본 그대로 | Windows + Inventor 설치 필요. 서버(Linux/Docker)에서는 불가. Inventor는 자기보다 **새 버전이 저장한 파일을 못 연다** | **채택** — 도면이 여러 장인 사람이 자기 PC에서 한 번 돌리는 용도 |
| **APS Design Automation for Inventor** | 클라우드에서 Inventor를 돌려 변환·내보내기 | 유료(클라우드 크레딧), Autodesk 계정, 도면이 오토데스크 서버로 나감 | 보류 — 미성년 사용자 도면을 외부로 더 보내게 된다 |
| **APS Model Derivative** | ipt·iam 등 70여 형식을 SVF/OBJ/STEP 등으로 변환 | 무료 티어가 없고, 우리가 필요한 것은 **도면(idw)** 인데 idw 지원은 확인 못 함 | 보류 |
| **오픈소스 InventorLoader** (FreeCAD) | ipt 일부를 읽음 | **iam·idw 미지원**, 버전마다 깨짐 | 안 씀 |

### 우리가 고른 길

1. **기본은 사용자가 Inventor에서 내보낸다.** `파일 > 내보내기 > DWG/DXF`.
   3D 파일(ipt·iam)은 먼저 도면(.idw)을 만들어야 합니다 — CADLens가 채점하는 것은
   3D 모델이 아니라 도면이기 때문입니다.
2. **서버는 Inventor 파일을 받으면 이유와 방법을 알려 줍니다.** 예전에는
   "지원하지 않는 형식입니다"로 끝났습니다. 지금은 확장자별로 무슨 파일인지 알아보고
   내보내는 절차를 알려 줍니다(`check.inventor_help`).
3. **여러 장이면 `idw2dxf.py`** 로 폴더째 변환합니다. 파일 이름은 `A01.dxf`처럼 새로
   붙고, 어떤 idw가 어떤 번호가 됐는지는 변환 기록 CSV에만 남습니다.

**개인정보 관점에서도 이 길이 낫습니다.** 변환이 사용자 PC에서 끝나므로 도면 원본이
외부 클라우드로 나가지 않습니다. 지금 밖으로 나가는 것은 AI 채점용 PNG 1장뿐입니다.

## 4. Inventor가 내보낸 DXF에서 실제로 읽히는 것 (측정)

표본은 실기 연습 도면 2장(`1본체.dxf` · `3축.dxf`)입니다.

| 무엇 | 어디에 들어 있나 | 지금 |
|---|---|---|
| 표제란 · 부품란 문자 | **블록 안** (`_walk`로 들어가야 보임) | 읽음 |
| 척도 · 각법 · 재질 | 표제란 칸마다 **문자가 따로** (`척도` 옆에 `1:1`) | 읽음 — 좌표로 라벨과 값을 짝지음 |
| 기하공차 | **GDT 전용 글꼴** `AIGDT`로 찍은 알파벳 한 글자 | 읽음 ([P17](../plan/문제점/P17-GDT글꼴기하공차.md)) |
| 끼워맞춤 | 치수 문자가 `Ø<>H7` 형식 (`<>`가 측정값 자리) | 읽음 |
| 도면 크기 | 윤곽선이 블록 안이라 사각형으로 안 잡힘 → `$LIMMIN/$LIMMAX` | 읽음 (A0~A4 판별) |
| 뷰 척도 | 뷰 이름표 문자 `E-E ( 1 : 1 )` · `C ( 5 : 1 )` | 읽음 — 상세도 확대는 정상으로 봄 |
| 뷰 경계·개수 | 순수 DXF에는 뷰 정보가 없음 | 도형 뭉치로 **추정** (`_cluster_views`) |
| 3D 모델 형상 | DXF에 없음 | **못 함** |

## 5. 남은 것 (아직 안 한 것)

- **3D 등각투상도 채점** — 등각축 2개, 음영·렌더링 여부는 DXF 문자·도형으로 판정할
  방법을 아직 못 찾았습니다. 렌더링 이미지가 도면에 래스터로 박히면 DXF에는
  이미지 참조만 남습니다.
- **질량 값의 옳고 옳지 않음** — 지금은 **적혀 있는지**만 봅니다. 실제 모델 부피 ×
  밀도와 대조하려면 3D 모델(STEP 등)이 필요합니다.
- **뷰 속성 척도** — 이름표에 척도를 안 띄운 뷰는 척도를 알 수 없습니다.
- **`.idw` 직접 업로드** — 위 표의 이유로 서버에서는 안 합니다. 필요하면
  APS Design Automation 을 다시 검토해야 하는데, 도면이 외부로 나가는 문제가 먼저입니다.
