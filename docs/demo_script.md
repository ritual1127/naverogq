## ② 시연 — 120초 · 한 도면으로 끝까지

**말보다 화면이 먼저 움직입니다.** 클릭하면서 설명하지 말고, 클릭한 다음에 설명하세요.

| 시각 | 화면에서 하는 것 | 나레이션 |
|---|---|---|
| 0:30~0:50 | 브라우저에서 CADLens 를 열고 도면 파일을 **드래그해서 놓는다** | "CADLens 입니다. **도면을 올려 검사 결과를 보고 고치는** 웹 도구입니다." |
| 0:50~1:20 | 결과 화면. 위에서 아래로 천천히 스크롤 — 자동 채점 점수 → 채점 항목 7개 → 지적사항 목록 | "90점 만점으로 채점합니다. 치수·공차·표면거칠기·기하공차·주서·재료 **60점은 규칙 코드**가, 투상도 선택과 배열 **30점은 AI**가 봅니다. 실격 조건 다섯 가지도 따로 봅니다." |

| 1:45~2:00 | 그 지적의 **`왜 감점이야?`** 질문 버튼 클릭 → 답 펼침 | "왜 깎였는지, 어디를 눌러 고치는지, 고친 뒤 뭘 확인하는지는 채점할 때 같이 만들어 둔 답입니다." |

**꼭 들어가야 하는 장면은 마지막 15초입니다.** 검사 결과만 보여주면 검사기고,
고쳐서 점수가 오르는 게 보여야 학습 도구입니다.

### 촬영 전에 해 둘 것

- **캐시를 데워 둡니다.** 고치기 전·후 파일을 각각 한 번씩 미리 검사해 두면 AI 답이 저장돼
  두 번째부터 빠르고 **점수도 안 튑니다.** 시연 중 점수가 튀면 설명이 꼬입니다.
- **배포 서버로 찍습니다.** 무료 플랜은 접속이 없으면 잠들므로 촬영 직전에 한 번 열어 깨웁니다.
- 브라우저 북마크바·확장 아이콘·알림을 끕니다. 창은 1920×1080 으로 맞춥니다.
- 도면 표제란에 이름이 있으면 **결과 화면에 그대로 뜹니다.** 시연 도면은 이름을 지우고 씁니다.

말이 남거나 모자랍니다.

### CapCut 에서 실제로 할 것

1. **대기 시간 컷** — 검사 한 번이 20~30초 걸립니다(AI 호출 때문). 진행 화면은 2초만 남기고
   잘라 붙입니다. 자른 자리에 `속도 2배` 대신 **점프 컷**이 자연스럽습니다.
2. **마우스 강조** — 마커를 클릭하는 순간은 확대(`키프레임`으로 1.0 → 1.3배)해서
   번호가 보이게 합니다. 번호가 안 보이면 시연이 무의미합니다.
3. **자막은 짧게** — 한 줄 12자 안팎, 두 줄까지. 나레이션을 그대로 받아쓰지 말고
   숫자와 이름만 자막으로 냅니다(`90점`, `규칙 60 + AI 30`, `재검사 비교`).
4. **배경음악은 -30dB 이하** 또는 아예 없이. 말이 안 들리면 3분이 통째로 날아갑니다.
   저작권 있는 곡을 쓰면 유튜브에서 막힐 수 있으니 CapCut 무료 음원만 씁니다.
5. **화면 전환 효과 금지.** 컷으로만 붙입니다. 전환 효과는 초를 잡아먹고 심사에서
   내용이 없어 보이게 만듭니다.
6. **내보내기** 1080p · 30fps · 고화질. 워터마크 없이 나가는지 확인합니다.

### 유튜브에 올릴 때

- 공개 또는 **일부 공개(링크가 있는 사용자)**. 비공개는 운영진이 못 봅니다.
- 제목 예 — `CADLens — 도면을 올리면 채점 근거까지 (전국마이스터고 스타프로젝트 W4)`
- 1080p 화질 처리가 끝난 뒤 주소를 냅니다. 올린 직후에는 360p 로만 보입니다.
- 팀 페이지 4주차 제출 칸에 **주소만** 넣습니다. 파일은 올리지 않습니다.
