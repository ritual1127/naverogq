### CapCut 에서 실제로 할 것

1. **대기 시간 컷** — 검사 한 번이 20~30초 걸립니다(AI 호출 때문). 진행 화면은 2초만 남기고
   잘라 붙입니다. 자른 자리에 `속도 2배` 대신 **점프 컷**이 자연스럽습니다.
2. **마우스 강조** — 마커를 클릭하는 순간은 확대(`키프레임`으로 1.0 → 1.3배)해서
   번호가 보이게 합니다. 번호가 안 보이면 시연이 무의미합니다.
3. **자막은 짧게** — 한 줄 12자 안팎, 두 줄까지. 나레이션을 그대로 받아쓰지 말고
   숫자와 이름만 자막으로 냅니다(`90점`, `규칙 60 + AI 30`, `재검사 비교`).
4. **배경음악은 -30dB 이하** 또는 아예 없이. 말이 안 들리면 3분이 통째로 날아갑니다.
   저작권 있는 곡을 쓰면 유튜브에서 막힐 수 있으니 CapCut 무료 음원만 씁니다.
5. **화면 전환 효과 금지.** 컷으로만 붙입니다. 전환 효과는 초를 잡아먹고 심사에서
   내용이 없어 보이게 만듭니다.
6. **내보내기** 1080p · 30fps · 고화질. 워터마크 없이 나가는지 확인합니다.

### 유튜브에 올릴 때

- 공개 또는 **일부 공개(링크가 있는 사용자)**. 비공개는 운영진이 못 봅니다.
- 제목 예 — `CADLens — 도면을 올리면 채점 근거까지 (전국마이스터고 스타프로젝트 W4)`
- 1080p 화질 처리가 끝난 뒤 주소를 냅니다. 올린 직후에는 360p 로만 보입니다.
- 팀 페이지 4주차 제출 칸에 **주소만** 넣습니다. 파일은 올리지 않습니다.

# CapCut 작업 순서

## 0. 준비 — 촬영 (편집보다 이게 오래 걸립니다)

**녹화 도구** — OBS Studio 또는 Windows `Win+G` 게임바.
OBS 면 `디스플레이 캡처` 말고 **`창 캡처`로 브라우저 창만** 잡습니다. 알림이 떠도 안 찍힙니다.

| 설정 | 값 |
|---|---|
| 해상도 | 1920×1080 (브라우저 창도 이 크기로) |
| 프레임 | 30fps |
| 커서 | 켬 (클릭을 보여줘야 함) |
| 소리 | **끔.** 나레이션은 따로 녹음 |

**절별로 나눠 찍습니다.** 한 번에 완주하려다 마지막에 틀리면 처음부터 다시입니다.
아래 여덟 개를 각각 따로 찍어 폴더 하나에 모읍니다.

| 파일 | 대본 어디 | 목표 길이 |
|---|---|---|
| `A_문제.mp4` | ① | 30초 (정지 화면이라 길게 찍어 두고 자름) |
| `B1_업로드.mp4` | 2-1 | 찍히는 대로 (대기 포함 40초쯤) |
| `B2_결과.mp4` | 2-2 | 40초 |
| `B3_마커.mp4` | 2-3 | 30초 |
| `B4_질문.mp4` | 2-4 | 20초 |
| `B5_고치기.mp4` | 2-5 | 20초 |
| `B6_재검사.mp4` | 2-6 | 찍히는 대로 |
| `demo/C1_지금위치.png` `demo/C2_막힌것.png` | ③ | 판 두 장 — 이미 만들어 뒀다. 고칠 일이 있으면 `docs/demo/make_boards.py` 를 고쳐 다시 돌린다 |

**나레이션 녹음** — 화면과 따로, 조용한 방에서 휴대폰으로. 절별로 끊어 녹음하면
한 문장 틀렸을 때 그 절만 다시 합니다. 마이크와 입 사이 한 뼘, 정면이 아니라 살짝 옆으로.

## 1. 프로젝트 만들기

1. CapCut 열고 `새 프로젝트`
2. 화면 비율 **16:9** 확인
3. `가져오기` 로 위 파일 전부 한 번에 올림

## 2. 소리부터 깔기

**순서가 중요합니다. 나레이션을 먼저 깔고 화면을 거기 맞춰 자릅니다.**

1. 나레이션 오디오를 타임라인 맨 아래 트랙에 통으로 놓는다
2. 절 사이 빈 곳(숨 쉬는 자리)을 보면서 **어디가 몇 초인지 파악**한다
3. 이 시점에서 전체 길이가 2분 30초를 넘으면 **문장을 뺀다.** 화면을 붙이고 나서 빼면 두 배로 일이다

## 3. 화면 붙이기

1. `B1` 을 나레이션 0:30 자리에 놓는다
2. **대기 구간 자르기** — 재생 헤드를 대기 시작 2초 뒤에 두고 `Ctrl+B`(분할),
   결과가 뜨기 직전에 또 `Ctrl+B`, 가운데 조각을 지운다
3. `B2`~`B6` 를 순서대로 이어 붙인다. 사이에 **전환 효과를 넣지 않는다**
4. 각 조각 끝을 잡아 늘이거나 줄여 나레이션 문장과 맞춘다

**클립이 나레이션보다 짧으면** 속도를 0.5배로 늘리는 것보다 **그 장면을 다시 찍는 게 낫습니다.**
느려진 마우스는 티가 납니다.

## 4. 강조 — 마커 확대

2-3 에서 마커를 클릭한 순간 번호가 잘 보이게 합니다.

1. `B3` 클립을 고르고 클릭하는 시점에 재생 헤드를 둔다
2. 오른쪽 `기본` 탭 → `크기` 옆 **키프레임(다이아몬드) 아이콘** — 크기 100% 로 점 하나
3. 1초 뒤로 이동 → 크기 **130%**, `위치` 를 마커 쪽으로 옮김 → 점이 하나 더 생긴다
4. 재생해서 부드럽게 커지는지 확인

재검사 비교 상자(2-6)에도 같은 걸 한 번 더 합니다. **이 두 군데만** 하고 다른 데는 하지 않습니다.

## 5. 자막

`텍스트` → `기본 텍스트`. **나레이션을 받아쓰지 않습니다.** 아래 여섯 개만 넣습니다.

| 시각 | 자막 | 비고 |
|---|---|---|
| 0:04~0:12 | 인용 1 (두 줄) | 가운데, 큰 글자 |
| 0:12~0:20 | 인용 2 + 출처 | 출처는 작게 |
| 0:50~0:56 | `90점 만점 = 규칙 60 + AI 30` | 아래쪽 |
| 1:23~1:30 | `지적 위치를 도면 위에 표시` | 아래쪽 |
| 2:19~2:26 | `재검사 — 지난번과 비교` | 아래쪽 |
| 2:45~3:00 | 판 2 글자 (판 이미지에 이미 있으면 생략) | — |

글꼴은 굵은 고딕 하나로 통일, 흰 글자에 **검은 테두리나 그림자**를 줍니다. 도면이 흰 배경이라
테두리가 없으면 안 보입니다. 한 줄 12자 안팎.

## 6. 소리 다듬기

1. 나레이션 클립 → `오디오` → **`음량 정규화`** 또는 볼륨을 0dB 근처로
2. 배경음악을 넣는다면 **CapCut 무료 음원만.** 유튜브에서 저작권으로 막히면 제출이 날아간다
3. 배경음악 볼륨은 **-30dB 이하.** 말이 묻히면 3분이 통째로 날아간다
4. 절 사이 잡음은 그 구간만 `Ctrl+B` 로 잘라 음소거

## 7. 내보내기

| 항목 | 값 |
|---|---|
| 해상도 | 1080p |
| 프레임 | 30fps |
| 형식 | mp4 |

내보낸 파일을 **다른 기기(휴대폰)에서 한 번 재생**합니다. 본인 헤드폰으로만 확인하면
말이 작은 걸 못 잡습니다.

## 8. 유튜브

1. 업로드 → 공개 범위 **`공개`** 또는 **`일부 공개(링크가 있는 사용자)`**. 비공개는 운영진이 못 봅니다
2. 아동용 여부는 **아동용이 아니라고** 고릅니다
3. 제목 예 — `CADLens — 도면을 올리면 채점 근거까지 (마이스터고 스타프로젝트 W4)`
4. 설명란에 저장소 주소 `https://github.com/ritual1127/naverogq` 를 넣습니다
5. **1080p 처리가 끝난 뒤** 주소를 냅니다. 올린 직후에는 낮은 화질로만 보입니다
6. 팀 페이지 → 주차별 산출물 → **4주차 제출** → `데모 영상 (YouTube 주소)` 칸에 주소만
