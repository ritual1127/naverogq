# 왜 만들었나

구미전자공업고등학교에서 기계제도를 배우는 학생입니다. 2학년 때 이 과목을 들으면서
CADLens를 만들기 시작했습니다.

도면을 그릴 때는 다 완성했다고 생각했는데, 나중에 확인해 보면 치수가 하나 빠져 있거나
공차와 표면거칠기 기호를 빼먹는 일이 자주 있었습니다. 작은 기호 하나 때문에 점수가
깎이거나 실격될 수도 있지만, 복잡한 도면에서 직접 찾는 것은 생각보다 어려웠습니다.

선생님이나 친구에게 매번 확인을 부탁하지 않고 혼자서도 도면을 검사할 수 있으면
좋겠다고 생각해서 만들게 되었습니다.

처음에는 DXF 파일만 분석할 수 있었지만, 학교에서 주로 쓰는 파일이 DWG라서 DWG도
올릴 수 있도록 기능을 추가했습니다. 실제 도면을 넣어 보면서 미리보기가 제대로 나오는지,
표시된 문제 번호와 설명이 맞게 연결되는지 계속 확인하고 수정했습니다.

시험 도면을 내기 전에 놓친 부분을 한 번 더 찾는 데 도움이 되었으면 합니다.
