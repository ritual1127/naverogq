# 데모데이 발표자료 — 슬라이드 8장 · 3분

09-08(화) 밤 12시까지 유튜브에 올릴 **3분 영상**용입니다. 09-09 데모데이의 5분 발표에도
같은 장을 씁니다. 그림은 이 폴더에 PNG 로 다 들어 있습니다(1920×1080).

```
python docs/demo/make_slides.py    # S1 ~ S6
python docs/demo/make_boards.py    # C1 · C2 (③절 판)
```

**운영진이 담으라고 한 네 가지가 어디에 있는지** — 무엇을 만드는지 한 문장은 S1,
동작하는 화면은 S4 와 화면 녹화 구간, 8주 목표 대비 위치는 C1, 막힌 것 하나는 C2 입니다.

**슬라이드보다 실제 화면이 낫다고 했습니다.** 그래서 가운데 60초는 슬라이드를 띄우지 말고
**CADLens 화면을 그대로 녹화해서** 넣습니다. 슬라이드는 앞뒤를 잡아 주는 용도입니다.

## 장마다 할 말

낭독용입니다. 그대로 읽으면 됩니다. 슬라이드에 이 문장을 적지 마세요 — 화면에는 이미
큰 글자만 있고, 아래 말은 입으로 합니다.

**1. 표지 (12초)**

> CADLens 입니다. 도면 파일을 올리면 빠뜨린 것을 도면 위에 번호로 찍어 주는 웹 검사기입니다.
> 전산응용기계제도기능사 실기를 준비하는 수험생이 씁니다.

**2. 문제 (33초)**

> 실기 시험은 5시간입니다. 저희가 직접 만난 다섯 명 중 세 명은 빠뜨린 것을 자기가 아니라
> 남이 찾아 줘서 알았습니다. 친구, 첨삭해 주는 사람, 강사였습니다.
> 고치는 데 11분에서 1시간 25분이 들었고, 그 시간 때문에 남은 검토를 잃었습니다.
> 혼자 준비하면 찾아 줄 사람이 없습니다.

**3. 무엇을 만들었나 (20초)**

> 도면 한 장을 90점으로 채점합니다. 60점은 규칙 코드가 봅니다. 치수, 공차, 표면거칠기,
> 기하공차, 주서, 표제란입니다. 나머지 30점, 투상도를 잘 골랐는지는 조건식으로 못 적어서
> AI가 봅니다. 확실하지 않으면 감점하지 않고 사람 확인 필요로 남깁니다.

**4. 화면 녹화 (60초) — 말보다 화면이 먼저 움직입니다**

| 언제 | 화면 | 말 |
|---|---|---|
| 0~5초 | 도면 파일을 검사 상자로 **끌어다 놓는다** | (말 없음. 손이 먼저) |
| 5~20초 | 점수와 지적 목록이 뜬다 | "올리면 몇 초 안에 점수와 지적이 나옵니다" |
| 20~40초 | **도면 미리보기로 이동. 번호 마커 하나를 눌러 확대** | "여기가 저희가 다른 점입니다. 지적을 글로만 주지 않고 도면 위 그 자리에 번호로 찍습니다" |
| 40~50초 | 질문 버튼 `왜 감점이야?` 를 누른다 | "왜 깎였는지, 어디를 고쳐야 하는지도 같이 나옵니다" |
| 50~60초 | 고친 파일을 올려 **재검사 비교**가 뜬다 | "고쳐서 다시 올리면 전과 비교해서 보여줍니다" |

**녹화 전에 확인할 것** — 같은 도면을 한 번 미리 검사해 두세요. 두 번째부터는 저장된 AI
답을 써서 빠르고 **점수도 안 튑니다.** 시연 중에 점수가 튀면 설명이 꼬입니다.
표제란에 이름이 있는 도면은 쓰지 마세요. 결과 화면에 그대로 뜹니다.

**5. 고치기 전후 (15초)**

> 지적대로 고치면 점수가 오릅니다. 왼쪽이 고치기 전 41점에 오작, 오른쪽이 고친 뒤 55점입니다.
> 지적은 6건에서 2건으로 줄었고 검사는 1초가 안 걸립니다.

**6. 어떻게 도나 (15초)**

> 올리면 도면을 읽고, 규칙 60점과 AI 30점을 매기고, 결과를 도면 위에 얹습니다.
> 밖으로 나가는 것은 AI 채점 때 보내는 도면 그림 한 장뿐이고 원본 파일은 나가지 않습니다.
> 회원가입도 쿠키도 없고, 올린 도면은 최대 1시간만 두고 지웁니다.

**7. 이번 주에 찾은 것 (15초)**

> 이번 주에 가지고 있던 도면 9장을 검사했더니 9장이 전부 오작으로 나왔습니다.
> 실기 도면은 기하공차 기호를 전용 글꼴로 알파벳 한 글자를 찍어 만드는데,
> 파일에 남는 글자는 그냥 b 라서 저희가 못 읽고 있었습니다. 고쳤습니다.
> 합성 도면 100장 숫자는 그대로였습니다. 넉 달 동안 안 보이던 것입니다.

**8. 지금 위치와 막힌 것 (10초)**

> 8주 중 3주가 지났습니다. 저 100%는 저희가 만든 합성 도면 숫자입니다.
> 실제 수험생 도면은 두 장뿐이라 현장 정확도를 아직 못 쟀습니다.
> **학생 도면을 동의받아 모으는 방법을 멘토님과 다른 팀에 여쭙고 싶습니다.**

## 그림을 바꾸고 싶으면

- 글자만 고칠 때는 `make_slides.py` 안의 해당 함수에서 문자열만 고치고 다시 돌립니다.
- **S4 의 도면 그림 두 칸은 파일 이름만 맞으면 무엇이든 들어갑니다.** 지금은 DXF 를
  그대로 그린 미리보기라 주서 글자가 네모로 나옵니다. **실제 CADLens 결과 화면을
  캡처해서** `도면_시연_고치기전.png` · `도면_시연_고친뒤.png` 로 덮어쓰고 다시 돌리면
  훨씬 낫습니다. 운영진도 슬라이드보다 실제 화면이 낫다고 했습니다.
- 시연 도면 두 벌은 `python docs/demo/make_demo_pair.py` 로 언제든 다시 만듭니다.
