## 슬라이드 4장

**01 · 0:00–0:16** — 우리 얘기라 따옴표가 없습니다.
```
다 그린 줄 알았습니다
─────
치수 하나, 표면거칠기 하나가
계속 빠져 있었습니다
```

**02 · 0:16–0:30** — 인터뷰라 따옴표가 있습니다.
```
저희만 그런 게 아니었습니다
─────
"친구가 '여기 베어링 자리인데
 거칠기 없어도 돼?'라고 해서 알았어요."
 메카트로닉스과 2학년
```

**03 · 2:30–2:45** — 워크샵 필수: 지금 안 되는 것 1가지.
```
아직 못 쟀습니다
─────
검출률 100% 는 우리가 만든
합성 도면 100장에서 나온 숫자입니다
```

**04 · 2:45–3:00** — 워크샵 필수: 4주 뒤 만들 숫자.
```
4주 뒤 만들 숫자
─────
주간 재검사 사용자  0명 → 20명
고쳐서 다시 올린 사람 수입니다
```

장에는 **머리글 한 줄과 본문 두 줄**뿐입니다. 숫자와 설명은 슬라이드가 아니라 **말이 옮깁니다.**

## 대본

**① 문제**

> **(장우영)** 저희가 겪은 일입니다. 다 그렸다고 생각했는데 치수 하나, 표면거칠기 하나가 계속 빠졌습니다.
> **(김승준)** 혼자 찾기가 어려워서 매번 선생님이나 친구한테 확인을 부탁했습니다.
> **(안대열)** 다섯 명을 만났더니 실수는 다 달랐는데 알게 된 방법이 같았습니다.
> **(박지완)** 다섯 중 셋이 남이 찾아 줘서 알았습니다. 혼자 준비하면 그 사람이 없습니다.

**③ 다음**

> **(안대열)** 검출률 100% 는 저희가 만든 합성 도면 100장에서 나온 숫자입니다.
> **(박지완)** 받은 실기 도면이 두 장뿐이라 현장 정확도는 아직 못 쟀습니다.
> **(장우영)** 남은 4주에 만들 숫자는 하나입니다. 주간 재검사 사용자 수입니다.
> **(김승준)** 고쳐서 다시 올린 사람입니다. 지금 0명이고 4주 뒤 주 20명을 만들겠습니다.

- 02 의 인용은 **소리 내어 읽지 않습니다.** 보는 사람이 눈으로 읽습니다.
- 안대열 ①줄은 `같았습니다` 앞에서, 박지완 ③줄은 `두 장뿐이라` 에서 한 박자 쉽니다.
- 숫자는 소리로는 한글로 말합니다 — "영 명", "스무 명", "백 장".
- 마지막 말 뒤에 **1초를 두고** 자릅니다. 여기서 영상이 끝납니다.

## 녹음

- **네 명이 각자 자기 차례만 따로 녹음합니다.** 한 명이 틀려도 그 사람만 다시 합니다.
- 같은 방, 같은 마이크, 마이크와 입 사이 한 뼘. 사람이 바뀔 때 소리 크기가 튀면 편집으로도 안 붙습니다.
- 이어 붙일 때 사람 사이에 **0.4초쯤** 둡니다.
- ③ 마지막 차례는 팀에서 제일 또박또박 읽는 사람이 합니다. 영상의 마지막 문장입니다.

## 지키는 것

- **우리 말과 남의 말을 섞지 않습니다** — 01·03·04 는 따옴표 없음, 02 만 있음.
- 인용은 **원문 그대로**, **이름과 학교는 넣지 않습니다.**
- 워크샵이 영상에서 금지한 것 — **팀 소개 · 기술 스택 나열 · 로드맵 그림.** 넷 다 없습니다.
- 워크샵 필수 두 가지가 ③ 에 있습니다 — **안 되는 것 1가지**(03), **4주 뒤 만들 숫자**(04).
- 누가 어느 장을 말하는지는 **슬라이드에 넣지 않습니다.** 영상에 그대로 찍힙니다.
- **"도면을 동의받아 모으는 방법"** 을 묻는 것은 영상이 아니라 **09-09 라이브 5분 발표**에서 합니다.
