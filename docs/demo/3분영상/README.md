# 3분 데모 영상 — 데모데이 ② (2026-10-07)

W8 강의 "데모데이 ② 진행" — 3분 데모 영상 최종본을 유튜브(공개 또는 일부 공개)에 올리고 팀 페이지 8주차 칸에
주소를 낸다. **전날까지**, 참가자 전원이 미리 본다.

`CADLens_3분_데모.mp4`(1920×1080 60fps, -16 LUFS, 3분 안)는 저장소에 올리지 않는다(`.gitignore`) — 아래로 다시 만든다.

| 구간 | 화면 | 목소리 |
|---|---|---|
| 문제 · 소개 | 발표 도우미 10분판 1~4장(표지, 인터뷰 인용, 5명, CADLens 소개) | 김승준 |
| 시연 | 32초 영상(올리기 → 번호 → 수정 예시) · 지적 읽기 · 고쳐서 다시 올리기 · 신고와 언어 | 네 사람 → 박지완 |
| 숫자 | 10분판 9 · 10 · 12 · 13장(속도, 실제 도면 23장, 공개 첫 주, 북극성) | 박지완 · 안대열 · 장우영 |
| 마무리 | 10분판 19장(감사합니다) | 김승준 |

목소리는 모두 **AI 합성**이다 — 팀원이 7월에 녹음한 소개 음성을 Qwen3-TTS 가 본떠 읽었다(만든 법은
[`../시연영상/README.md`](../시연영상/README.md#목소리-voice)). 목소리가 나오는 동안 오른쪽 위에 "○○ 목소리 · AI 음성"을
띄운다(대회 AI 사용 공개). 32초 영상은 자막에 이미 같은 표시가 있다.

## 만드는 법

```bash
# 1. 목소리 — 대사 lines.json 을 줄마다 5개씩 합성하고, 다듬어서 하나씩 고른다(GPU · 약 30분)
#    참고 녹음과 그 글(qrefs/)은 저장소에 없다. 합성 환경은 ../시연영상/README.md
LINES=lines.json OUT=v3cand K=5 python ../시연영상/voice/qgen.py
LINES=lines.json IN=v3cand OUT=v3proc python ../시연영상/voice/qpick.py   # → v3proc/picks.json
#    고른 파일을 voice/<키>.wav 로 복사한다
# 2. 잇기 — 발표 도우미를 띄워 장을 찍고, 영상 · 목소리 · 표시를 ffmpeg 로 잇는다(약 3분)
node build.js
```

- 대사는 숫자를 한글로 적는다("십칠 분") — 합성기가 숫자를 잘못 읽지 않게. 그래서 받아쓰기 오류율이 0 이 안 될 수
  있어, `qpick.py` 는 오류율이 가장 낮은 것들 중에서 사람다움 · 닮음 · 빠르기로 고르고 받아쓰기를 같이 찍는다.
- 시연 장면에 목소리를 놓는 시각은 `../시연영상/cap2/<장면>/manifest.json` 의 누른 때에서 잡는다(`build.js` 의 `scenes`).
  목소리가 영상보다 길면 마지막 화면에서 멈춰 기다린다.
- 2026-10-06: 이 PC 의 Smart App Control 이 지난번 uv 가상환경의 `python.exe` 를 막았고, 임시 폴더 정리로 그 환경의
  파일 일부(cffi · certifi · transformers)가 지워져 있었다. 보안 설정은 건드리지 않고, 같은 버전을
  `uv pip install --target C:\Users\smile\tts311\site` 로 다시 깔아 uv 의 기본 파이썬에 `PYTHONPATH` 로 붙여 돌렸다.
