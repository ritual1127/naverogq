# PPT 생성 AI 에게 그대로 붙여 넣는 파일

아래 `---` 부터 끝까지를 통째로 복사해서 PPT 생성 AI 에 붙여 넣으면 된다.
저장소 링크나 스크립트 이야기는 일부러 안 넣었다. 그것만으로 슬라이드가 나와야 한다.

---

다음 내용으로 발표용 슬라이드 9장을 만들어 주세요. 그중 5장은 영상 자리라 글자가 없습니다.

## 발표 정보

- 발표 제목: CADLens — 도면을 올리면 빠진 것을 도면 위에 찍어 줍니다
- 발표자: 네이놈 팀 (고등학생 4명, 전국마이스터고 스타프로젝트)
- 길이: 3분 (슬라이드 낭독 80초 + 제품 화면 녹화 50초 + 여유)
- 자리: 데모데이. 참가 30팀이 차례로 발표하고 멘토가 총평을 준다
- 목적: 무엇을 만들었는지 보여주고, **막혀 있는 것 하나를 물어 피드백을 받는 것**

## 디자인 요구

- 16:9, 어두운 배경. 배경 `#0c1119`, 상자 `#141b25`, 선 `#26303f`
- 글자 흰색 `#e9eff7`, 강조 파랑 `#3aa9ff`, 좋은 결과 초록 `#2ed9a0`, 문제 주황 `#f0a020`
- 한국어 고딕 계열. 제목은 아주 크게, 숫자는 더 크게
- **한 장에 글자 다섯 줄 안쪽.** 문장이 아니라 조각으로 적는다
- 애니메이션·전환 효과 없음. 3분에서 시간만 먹는다
- 각 장 왼쪽 위에 작게 `CADLens` 를 넣고 그 아래 회색으로
  `전산응용기계제도기능사 실기 도면 자동 검사`
- 아래 '발표자 노트'는 슬라이드 본문에 넣지 말고 **노트 칸**에 넣어 주세요

## 2장 — 사용자 인터뷰에서 나온 말 (12초)

제목
```
화면에서는 멀쩡해 보입니다
```

본문 — 인용 세 개를 따옴표 상자로 크게. 출처는 작게 오른쪽 아래
```
"표면거칠기는 마지막에 몰아서 넣거든요.
 하나가 빠져도 화면이 비어 보이지 않아서 잘 모르겠더라고요."
                                        — 메카트로닉스과 2학년

"눈으로 형상만 보면 정상처럼 보여서
 속성값을 직접 열지 않으면 놓치기 쉬웠습니다."
                                        — 메카트로닉스과 2학년

"화면에는 선이 많으니까 다 그린 것처럼 보였어요."
                                        — 기계제도 선생님
```

발표자 노트
> 직접 만난 다섯 명입니다. 실수는 다 달랐는데 말이 겹쳤습니다. 화면에서는 멀쩡해 보였다는 것입니다.

주의 — 인용은 원문 그대로, **이름과 학교는 넣지 않는다.**

## 4장 — 무엇을 만들었나 (10초)

제목
```
도면 한 장을 100점으로 채점합니다
```

본문 — 두 칸으로 나눠서
```
규칙 코드 70점              AI 30점
검사 40개                   투상도 선택과 배열
실격 판정 6가지              조건식으로 못 적는 부분
AI 를 부르지 않는다          확실하지 않으면 사람 확인
```

아래에 강조 띠 한 줄
```
지적은 도면 위 그 자리에 번호로 찍습니다
"화면에서는 멀쩡해 보인다" — 그래서 화면 위에 찍습니다
```

발표자 노트
> 그 자리를 대신하려고 만들었습니다. 100점 중 70점은 규칙 코드가, 투상도 30점은 AI가 봅니다.

```
실기 도면 두 장은 기하공차가 눈으로 보이는데도 못 찾았습니다
```

## 9장 — 막힌 것 하나 (17초, 마지막 장)

제목 — 주황색으로
```
막힌 것 하나
```

본문
```
저 100%는 우리가 만든 도면에서 나온 숫자입니다
실제 수험생 도면은 두 장뿐이라
현장 정확도는 아직 못 쟀습니다
```

아래에 파란 강조 상자로 크게
```

인터뷰 5건은 다 받았습니다. 도면은 아직 못 받았습니다
```

발표자 노트
> 저 100%는 저희가 만든 합성 도면 숫자입니다. 실제 수험생 도면은 두 장뿐이라 현장 정확도를 못 쟀습니다. 인터뷰는 다 받았는데 도면은 못 받았습니다. 모으는 방법을 여쭙고 싶습니다.
