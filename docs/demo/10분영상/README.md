# 10분 발표 영상 — 2차 제출 · 본선 (2026-10-18)

2차 제출물 다섯 중 "10분 이내 발표 영상"이다. 녹화할 날(10-09)이 지나도록 영상이 없어, 평가 마지막 날 박지완이 AI 도구로
만들기로 했다. 발표 도우미 10분판([`presenter/talk10.js`](../../../presenter/talk10.js)) 19장과 대본을 그대로 쓴다.

`CADLens_10분_발표.mp4`(1920×1080 60fps · H.264 · -16.0 LUFS · **6분 24초** · 58MB)는 저장소에 올리지 않는다(`.gitignore`) — 아래로 다시 만든다.
대본은 10분판이지만 합성 목소리가 사람이 소리 내어 읽는 어림(4.1 ~ 5.2자/초)보다 빨라(약 6.6음절/초 — 팀원 실제 말 빠르기와 같은 높이) 6분대에 끝난다.

**10-18 확인** — 완성본 소리를 다시 받아써 자막 73줄과 나란히 놓아 줄마다 대본대로 들리는지 봤고, 자막 시작 시각은 실제 말 시작과
0.04초 안으로 맞았다(무음 검출). 장면 18곳을 뽑아 장 순서 · 목소리 표시 · 겹쳐 넘기기를 눈으로 봤다. 2.2초 넘는 무음은 시연 장면 안의
화면 동작(답 열기 · 재검사 · 신고 창)과 시연에서 숫자 장으로 넘어가는 자리 — 다섯 곳뿐이다.
**유튜브 — https://youtu.be/oqJvQP71Elc** (10-18 박지완이 올림). 주소는 [KPI 리포트 ⑥](../../../plan/w8/W8_KPI리포트.md#-2차-제출물-체크)과 팀 페이지 8주차에 적는다.

목소리는 모두 **AI 합성**이다 — 팀원이 7월에 남긴 소개 음성(각 30초 안팎)에서 한 문장을 참고로 Qwen3-TTS 가 본떠 읽었다
(만든 법은 [`../시연영상/README.md`](../시연영상/README.md#목소리-voice)). 목소리가 나오는 동안 오른쪽 위에 "○○ 목소리 · AI 음성"을
띄운다(대회 AI 사용 공개). 32초 영상은 자막에 이미 같은 표시가 있다.

**10-18 에 고친 숫자** — 10분판의 북극성 · 아직 안 된 것 · 본선까지 · 팀 소개 네 장은 10-18 13:35 원자료로 고쳤다. 나머지 장은 그날 일어난 일이다.

## 만드는 법

```bash
# 1. 목소리 — lines.json 을 줄마다 4개씩 합성하고(GPU · 약 80분), 다듬어서 하나씩 고른다
#    참고 음성(qrefs/ — 소개 음성에서 ../시연영상/voice/ref_text.json 의 문장만 자른 것)은 저장소에 없다
LINES=lines.json OUT=qcand K=4 python ../시연영상/voice/qgen.py
LINES=lines.json IN=qcand OUT=qproc python pick.py            # → qproc/picks.json, 고른 파일을 voice/<키>.wav 로
# 2. 잇기 — 발표 도우미를 띄워 장을 찍고, 영상 · 목소리 · 표시를 ffmpeg 로 잇는다
node build.js slides       # 장 사진만 build/ 에 — 미리 보기
node build.js              # CADLens_10분_발표.mp4 · .srt · chapters.txt · thumb.jpg
```

- `lines.json` 은 합성용 글이다 — 숫자 · 영어를 읽는 소리대로 적는다("십칠 분", "캐드렌즈", "에이아이"). 화면에 내는 글은 `subs.json`.
  한 줄에 문장이 둘이면 `a` · `b` 로 나눠 합성하고 0.35초 띄워 잇는다(줄 사이 0.7초, 장 처음 0.8초 · 끝 1.2초, 그래프 · 숫자 장은 끝 1.6초).
  마지막 줄만 "감사합니다"를 따로 합성하면 0.5초로 잘려 어색해서 앞 문장과 한 줄(`19_2`)로 합성했다.
- 고른 후보는 `picks.json` 이다(줄 키 → 후보 파일). `18_1b` 는 오류율로 다시 골랐다 — 처음 고른 `_0` 은 "안대열이"가 "안대열의"로 들렸다.
  받아쓰기로 다시 들어 본 것 중 "박지완이 → 박지환이", "본선까지 → 본성까지", "거칠기 → 거칠게"는 네 후보가 모두 같아 발음이 아니라 받아쓰기 쪽으로 봤다.
- `pick.py` 는 `../시연영상/voice/qpick.py` 와 같다. 다만 그때 쓴 기준 파일이 남아 있지 않아, 빠르기 기준은
  [`../시연영상/README.md`](../시연영상/README.md) 의 실측 표(문장 하나 말하는 빠르기)를 쓰고 억양 폭은 소개 음성 전체에서 다시 잰다.
  받아쓰기 오류율은 합성용 글과 화면 글(숫자) 중 낮은 쪽으로 본다.
- 시연 장면(32초 · 지적 읽기 · 다시 올리기 · 신고)은 [`../시연영상/`](../시연영상/README.md) 의 `capture.js` · `capture2.js` · `render.js` 가 만든
  `presenter/video/*.mp4` 를 쓴다. 장면에 목소리를 놓는 시각은 `../시연영상/cap2/<장면>/manifest.json` 의 누른 때에서 잡는다.
- 장 사이는 0.3초 겹쳐 넘긴다(그림 `xfade` · 소리 `acrossfade`). 장 끝과 시작은 말이 없는 자리라 말이 겹치지 않는다.
- 자막 `CADLens_10분_발표.srt` 는 화면 글 그대로다 — 유튜브 스튜디오 「자막 → 파일 업로드」로 올리면 켜고 끌 수 있다.
  챕터 `chapters.txt` 는 유튜브 설명란에 그대로 붙인다(00:00 부터).
