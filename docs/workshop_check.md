# 워크샵 반영 점검 — W1 ~ W8 에서 배운 것이 제품에 들어갔나

데모데이 ②(10-07) 마무리에서 진행자가 "점수가 나빠졌던 거의 유일한 이유는 … 워크샵에서 배웠던 것을
프로덕트에 반영하지 않은 부분"이라고 했습니다([기록](demoday2.md)). 그래서 [W1 ~ W8 강의](https://meister.itshin.com/workshop/w1/)를
처음부터 다시 읽고, **제품(공개 사이트 · 지표 · README)에 닿는 줄만** 골라 지금 상태를 한 줄씩 확인했습니다.
팀 문서로 끝나는 산출물(미션 문장 · 역할 분담 등)은 주차별 제출본에 있으므로 뺐습니다.

2026-10-07 밤 기준 (10-09 에 W6 FIX 04, 10-10 에 W6 FIX 01 을 ✅ 로 고침) · ✅ 들어감 · 🔺 반쯤 · ❌ 안 들어감 · ⬜ 아직 할 때가 아님
