# 인터뷰 폼

W2 사용자 인터뷰를 **웹으로도 받기 위한 설문**입니다. 만나서 하는 인터뷰가 원래 계획이고
([질문지](../plan/w2/08-25_화/질문지.md)), 이건 못 만날 때나 만나기 전에 미리 받는 용입니다.

- 답하는 곳 — https://cadlens-interview.pages.dev
- 통계 — 같은 주소 `/api/answer?key=...` (열쇠는 저장소에 없습니다)

## 글로 받으면 잃는 것

대면 인터뷰의 **3초 침묵**과 **꼬리 질문**이 없습니다. "보통 그냥 확인해요" 같은 답이
나와도 그 자리에서 "그러면 지난번엔 어떻게 했어?"로 되물을 수 없습니다.
그래서 이 폼은 대면 인터뷰를 대신하지 않습니다.

## 무엇을 묻나

고르는 질문 26개 + 적는 칸 4개(**87%가 객관식**). 3분쯤 걸립니다.

| 절 | 무엇 |
|---|---|
| A | 학년 · 기능사 진행 상태 · 쓰는 2D/3D 프로그램 · 그려 본 장수 · 빈도 |
| B | 2D 부품도 · 3D 등각투상도 · 출력에 걸리는 시간, 시간 모자란 적 |
| C | 빠뜨리거나 틀린 것 30개 (도면 기본 · 치수/공차 · 기호 · 투상/표기 · 사고) |
| D | 제일 최근 사건 — 언제 알았나 · 그때 뭘 했나 · 걸린 시간 · 깎인 점수 · 처음인가 |
| E | 지금 확인하는 방법 · 확인에 쓰는 시간 · 실제로 잡아 봤나 |
| F | 안 틀리려고 써 본 것 · 쓴 시간 · 쓴 돈 |
| G | KS 규격집에서 자주 찾는 것 · 제일 오래 걸리는 작업 · 제일 짜증 나는 순간 · 선생님 지적 한마디 |
| H | 도면 파일을 줄 수 있는지 · 하고 싶은 말 |

C의 선택지는 지어낸 것이 아니라 **실기 오작·미완성 기준**과 `exam.py` 의 검사 24개에서
뽑았습니다. 오작은 도면 크기 불일치 · 각법/척도 불일치 · 끼워맞춤공차·기하공차·표면거칠기
기호 전체 누락 · 조립 상태로 제도이고, 미완성은 부품도나 렌더링 등각투상도 미제출 ·
출력 10분 초과 · 투상도 누락입니다.

F의 질문은 강의가 반드시 넣으라고 한 것입니다. **이미 시간이나 돈을 쓴 사람**만
강한 신호로 셉니다. "나오면 써 볼게요"는 신호가 아닙니다.

## 고르는 칸은 전부 필수

억지 답을 막으려고 빠져나갈 선택지를 둡니다 — `빠뜨린 적 없음` · `아무것도 안 함` ·
`안 써 봄` · `잘 모르겠어` · `모름`. **없는 것을 있다고 고르게 하면 그 답은 쓸모가 없습니다.**

## 어떻게 만들어졌나

Cloudflare Pages + Functions + D1.

```
public/index.html        폼 (정적)
public/og.png            링크 미리보기 그림 1200×630
functions/api/answer.js  POST 저장 · GET 통계
schema.sql               D1 테이블
wrangler.toml            D1 바인딩
```

답 하나가 `answers` 한 줄이고, **고른 것은 `picks` 로 펼쳐서** 넣습니다. 그래야 답이
1000건 쌓여도 통계가 `GROUP BY` 한 번입니다. 직접 적은 것은 세지 않으므로 `notes` 에
따로 둡니다. 통계 화면은 답 개수와 상관없이 **SQL 6번**이고, 한 사람씩 보기는 20명씩
쪽으로 나눕니다.

1000건(`picks` 31,840줄)을 넣고 재 봤을 때 통계 화면 **207~739ms**, 복사용 글 **133ms**
였습니다. 재고 나서 지웠습니다.

## 통계 화면

- 위 숫자 다섯 — 받은 답 · **강한 신호** · 낸 뒤에야 알았다 % · 확인 아예 안 함 % · 도면 준다고 함
- 항목마다 막대 — 많은 순, 건수와 %, 분모는 그 항목에 답한 사람 수
- 직접 적은 것은 세지 않고 **원문 그대로** 나열
- **전체 지표 복사** 버튼 — AI에 그대로 붙여넣는 글. `&format=md` 로도 볼 수 있고 `&format=json` 은 원문

## 주소 뿌리기

만들어 두고 주소를 안 뿌려서 08-27까지 **0건**이었습니다([P10](../plan/문제점/P10-인터뷰0건.md)).
복사해 쓸 글은 [`뿌릴글.md`](뿌릴글.md) 에 있습니다 — 단톡용 · 개인 DM용 · 선생님께.

## 배포

```bash
cd 인터뷰폼
npx wrangler d1 execute cadlens-interview --remote --file schema.sql   # 처음 한 번
npx wrangler pages deploy --branch main --commit-dirty=true
```

`--project-name` 을 바꾸면 주소가 바뀝니다. 바꾸지 않습니다.

## 열쇠

통계는 `ADMIN_KEY` 를 아는 사람만 봅니다. **이 값은 저장소에 넣지 않습니다.**
Cloudflare Pages 비밀값으로만 있습니다.

```bash
npx wrangler pages secret put ADMIN_KEY --project-name cadlens-interview
```
