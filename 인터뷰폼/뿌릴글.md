# 폼 주소 뿌릴 때 쓰는 글

폼을 만들어 두고 주소를 아무 데도 안 뿌려서 **08-27까지 답이 0건**이었습니다
([P10](../plan/문제점/P10-인터뷰0건.md)). 만드는 것과 돌리는 것은 다른 일이라
여기 그대로 복사해 쓸 글을 둡니다.

주소 — **https://cadlens-interview.pages.dev**

## 보내기 전에 확인할 것

- **가족과 친한 친구에게는 보내지 않습니다.** 강의가 명시한 제외 대상입니다.
  우리 팀원 4명도 뺍니다 ([대상표 기준](../plan/w2/08-25_화/인터뷰대상표.md)).
- 한 반에만 뿌리지 않습니다. 같은 수업 들은 얘기만 나옵니다.
- **폼은 대면 인터뷰를 대신하지 않습니다.** 3초 침묵과 꼬리 질문이 없습니다.
  약속이 잡힌 사람에게는 폼 대신 만나서 [질문지](../plan/w2/08-25_화/질문지.md)로 합니다.
- 답은 익명입니다. 폼이 이름·학번을 안 받습니다. 그렇게 말해도 거짓이 아닙니다.

## 1. 반 단톡·학과 단톡

```
기계제도 도면 그리면서 뭐 빠뜨린 적 있는 사람 있어?

우리 팀이 도면 자동 검사 만드는 중인데, 실제로 뭘 자주 빠뜨리는지 몰라서 설문 돌려.
거의 다 누르는 거고 3분이면 끝나. 이름·학번 안 받아.

https://cadlens-interview.pages.dev

답 많을수록 우리가 엉뚱한 거 만들 확률이 줄어들어. 부탁 좀!
```

## 2. 개인 DM (한 명씩 보낼 때)

```
야 혹시 3분만. 기계제도 도면 그릴 때 뭐 빠뜨렸었는지 물어보는 설문이야.
누르는 거 위주고 이름 안 받아. 우리 팀 프로젝트에 쓸 거야.

https://cadlens-interview.pages.dev

(도면 파일도 하나 줄 수 있으면 좋은데, 이름이랑 학번은 지우고 보내 줘)
```

## 3. 선생님께

```
안녕하세요 선생님, ○학년 ○반 ○○○입니다.

저희 팀이 기계제도 도면을 자동으로 검사해 주는 프로그램을 만들고 있는데,
학생들이 실제로 무엇을 자주 빠뜨리는지를 저희 짐작이 아니라 직접 물어서
확인하려고 설문을 만들었습니다.

https://cadlens-interview.pages.dev

3분 정도 걸리고 이름은 받지 않습니다. 혹시 실습 시간에 학생들에게
한 번 알려 주실 수 있을까요?

그리고 따로 15~20분 정도 여쭤보고 싶은 것이 있습니다. 채점하실 때 제일 먼저
무엇을 보시는지, 30명 도면을 어떻게 확인하시는지 같은 것들입니다.
편하신 시간 알려 주시면 찾아뵙겠습니다.
```
