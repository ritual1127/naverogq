# 일반기계기사 — 도입 리스크

## 리스크 목록

| 리스크 | 영향 | 대응 |
|---|---|---|
| 공개문제 확보 실패 | 요구사항 확정 불가, 도입 중단 | Q-Net 접수 전 확보 여부 우선 확인 |
| 오작 조건 오판 | 사용자가 맞는 도면을 틀리게 고침 | 원문 미확인 조건은 오작 대신 경고로 표시 |
| 배점 추측 노출 | 사용자에게 잘못된 확신 제공 | 배점 대신 항목 충족 여부만 표시 |
| 회차별 요구사항 변동 | 특정 회차에만 맞는 검사 규칙이 됨 | 3개 회차 이상 대조 후 확정 |

## 리스크별 조기 경보 신호

각 리스크가 실제로 현실화되고 있다는 신호를 미리 정해 두면, 문제가 커지기 전에
대응을 시작할 수 있다.

| 리스크 | 조기 경보 신호 |
|---|---|
| 공개문제 확보 실패 | Q-Net 게시판에 이 종목 최근 공개문제가 1개 회차 미만으로 존재 |
| 오작 조건 오판 | 검증 단계에서 실제 합격 도면이 오작으로 판정됨 |
| 배점 추측 노출 | 사용자 문의에 "왜 이 점수가 나왔나요"가 반복됨 |
| 회차별 요구사항 변동 | 확보한 회차 간 도면 크기·척도 값이 서로 다름 |

## 리스크 대응의 우선순위

리스크는 영향도와 발생 가능성을 함께 봐야 한다. 이 종목의 경우 "공개문제 확보
실패"가 발생하면 이후 모든 작업이 멈추므로 영향도가 가장 크고, 착수 전 1주 안에
확인 가능하므로 가장 먼저 점검해야 한다. 반대로 "회차별 요구사항 변동"은 3개
회차를 다 확보한 뒤에야 판단할 수 있어 발견 시점이 늦다는 특징이 있다.
