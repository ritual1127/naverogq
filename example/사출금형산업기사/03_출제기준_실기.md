# 사출금형산업기사 — 실기 출제기준

## 실기 시험 개요

| 항목 | 내용 |
|---|---|
| 실기 과목 | 사출금형설계 실무 |
| 검정 방법 | 작업형 |
| 시험 시간 | 확인 필요 (프레스금형산업기사 기준 약 4시간) |
| 합격 기준 | 100점 만점에 60점 이상 |

## 확인된 사실

- 한국산업인력공단이 시행하는 금형·공작기계 분야 산업기사 등급 국가기술자격이다.
- 출제기준 파일은 Q-Net 고객지원 자료실에서 내려받을 수 있다.

## CADLens가 관여할 수 있는 범위

이 종목의 실기 결과물 중 CADLens가 읽을 수 있는 것은 **CAD 파일(DWG/DXF)** 뿐입니다.
필답형 답안, 수기 계산, 실물 가공물은 검사할 수 없습니다.

현재 파이프라인은 다음과 같습니다.

```
DWG/DXF 업로드
  → dwg.py       파일 변환·파싱 (ezdxf, 필요시 dwg2dxf)
  → exam.py      판정 함수 8개 실행
  → exam.py      채점 루브릭 적용, 오작 판정
  → ai_review.py AI 검토(투상도 배열 등 자동 판정이 어려운 항목)
```

이 파이프라인에서 종목에 종속된 부분은 `exam.py`의 상수(도면 크기, 척도 목록, 최소
기호 개수)와 루브릭 배점입니다. 그 외는 KS 제도 규칙이라 종목이 바뀌어도 유효합니다.

## 검사 대상 판정

| 실기 구성요소 | CADLens 검사 | 사유 |
|---|---|---|
| CAD 도면 파일 | 가능 | 현재 파이프라인 그대로 |
| 3D 모델 파일 | 조건부 가능 | 3D 파싱 모듈 신규 개발 필요 (현재 없음) |
| 필답형 답안 | 불가 | 도면 파일 없음 |
| 실물 작업 | 불가 | 도면 파일 없음 |

## 파이프라인 각 단계의 종목 의존도

- `dwg.py` — 파일 포맷 변환 단계. 종목과 무관하게 DWG/DXF를 열 수 있으면 그대로
  동작한다. 이 종목 도입에서 손댈 필요가 없는 유일한 단계다.
- `exam.py` — KS 규칙 기반 판정. 대부분 종목 무관, 재질 사전만 종목별로 다를 수
  있다.
- `exam.py` — 종목 의존도가 가장 높다. 도면 크기, 척도 목록, 최소 기호 개수,
  오작 조건, 루브릭 배점이 모두 이 파일의 상수에 있다.
- `ai_review.py` — 투상도 배열처럼 규칙만으로 판정하기 어려운 항목을 다룬다.
  프롬프트에 종목 이름과 도면 성격을 반영해야 정확도가 유지된다.

## 검사 범위를 사용자에게 어떻게 알릴 것인가

이 종목 도입 후에도 CADLens가 실기 전체를 채점하는 것으로 오해하지 않도록,
결과 화면에 "이 검사는 CAD 도면 제출물만 확인합니다"라는 안내가 필요하다.
특히 필답형이 있는 종목(일반기계기사 등)에서는 이 안내가 없으면 사용자가 실제
합격 여부와 CADLens 결과를 혼동할 수 있다.
