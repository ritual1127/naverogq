# 사출금형산업기사

CADLens 확장 대상 종목 중 하나. 조사 배경과 5개 종목 비교는
[`../README.md`](../README.md)와 [`../00_종합비교표.md`](../00_종합비교표.md)에 있습니다.
응시 규모는 [`../96_응시자_통계.md`](../96_응시자_통계.md)를 보세요.

| 항목 | 값 |
|---|---|
| 규칙 재사용 추정 | 약 55% |
| 신규 개발 부담 | 대 (신규 3건) |
| 핵심 난관 | 빼기구배 · 파팅라인 · 냉각회로 검사 |
| 도입 순서 | 3순위 |

**공통 KS 규칙은 맞지만 금형 전용 검사가 새로 필요해서** 재사용률이 낮습니다.
일반기계기사와 원인이 다르므로 대응도 다릅니다. 공통 규칙으로 먼저 열고,
금형 전용 검사는 나중에 얹는 순서를 권고합니다.

판단에 필요한 01~09 축이 채워져 있어, 도입 여부는 지금 결정할 수 있습니다.
