# 일반기계기사 — 도입 전 체크리스트

## 착수 전 확인

- [ ] 공개문제 3개 회차 확보
- [ ] 도면 크기·투상법·척도 확정
- [ ] 오작 조건을 공개문제 원문에서 확인
- [ ] 채점 배점 비공개 사실을 서비스 화면에 안내할 문구 준비

## 코드 변경 전 확인

- [ ] `exam.py` 상수 분리(`SPECS` 딕셔너리) 완료
- [ ] 기존 기능사 동작이 회귀 테스트로 보장됨

## 배포 전 확인

- [ ] 실제 합격/불합격 도면으로 검증
- [ ] 점수 없이 항목 충족 여부만 표시하는지 확인
- [ ] "확정된 채점기준이 아님" 안내 문구 노출

## 이 체크리스트를 건너뛰면 생기는 일

세 구간(착수 전 / 코드 변경 전 / 배포 전) 중 하나라도 건너뛰면 구체적으로
어떤 문제가 생기는지 정리한다.

| 건너뛴 구간 | 실제로 생기는 문제 |
|---|---|
| 착수 전 | 요구사항이 틀린 채로 코드를 짜서 처음부터 다시 해야 함 |
| 코드 변경 전 | 기존 기능사 검사가 조용히 망가진 채로 배포될 수 있음 |
| 배포 전 | 검증 안 된 검사 결과를 사용자가 진짜 채점 기준으로 오해함 |

## 체크리스트 소유자

이 체크리스트는 문서를 작성한 담당자가 아니라, 실제로 코드를 배포하는 사람이
마지막에 다시 확인한다. 문서 작성자와 배포자가 같은 사람이더라도, 작성 시점과
배포 시점 사이에 요구사항이 바뀌었을 수 있으므로 배포 직전에 한 번 더 훑는다.
