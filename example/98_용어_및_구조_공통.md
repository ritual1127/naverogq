## 검사 파이프라인

```
DWG/DXF 업로드
  → dwg.py       파일 변환·파싱 (ezdxf, 필요시 dwg2dxf/ODA)
  → ai_review.py AI 검토 (투상도 배열 등 자동 판정이 어려운 항목)
  → exam.py      판정 함수 8개 실행 → findings, 루브릭 채점,
                 오작(DQ) 판정 → scorecard
```
