# 용어 및 코드 구조 (공통)

[`공통/41_용어집.md`](공통/41_용어집.md)는 이 문서를 요약 참조합니다. 여기서는
전체 구조를 한 번에 봅니다.

## 검사 파이프라인

```
DWG/DXF 업로드
  → dwg.py       파일 변환·파싱 (ezdxf, 필요시 dwg2dxf/ODA)
  → ai_review.py AI 검토 (투상도 배열 등 자동 판정이 어려운 항목)
  → exam.py      판정 함수 8개 실행 → findings, 루브릭 채점,
                 오작(DQ) 판정 → scorecard
```

## 종목별로 바뀌는 것 / 바뀌지 않는 것

| 구분 | 예시 | 종목별로 |
|---|---|---|
| 판정 함수 본문 (`_dimensions` 등 8개) | 치수 상/하한 역전 판정 | 바뀌지 않음 — KS/물리 법칙 |
| 오작 판정 (`_disqualifiers`) | 오작 판정 조건식 | 바뀌지 않음 |
| 임계값 상수 | 도면 크기, 최소 기호 개수, 표준 척도 목록 | 종목마다 다름 |
| 재질 사전 | `_material` 의 재질·열처리 키워드 | 금형 계열은 확장 필요 |
| 루브릭 배점 | RUBRIC의 점수 | 공식 비공개, 종목마다 추정만 가능 |

이 분리가 [`99_도입_로드맵.md`](99_도입_로드맵.md) 0단계(구조 정리)의 근거입니다.
