# 일반기계기사 — 실기 과제 구성

## 과제 개요

필답형에서 기계요소설계 계산 문제를 풀고, 작업형에서 CAD로 도면을 작성한다.

## 제출물 구성

Q-Net 공개문제를 받아 아래 표를 채웁니다. 회차마다 달라질 수 있으므로 최소 3개 회차를
비교한 뒤 확정합니다.

| 제출물 | 파일 형식 | CADLens 검사 가능 | 비고 |
|---|---|---|---|
| 2D 도면 | DWG / DXF | 가능 | 현재 파이프라인 |
| 3D 모델 | 확인 필요 | 조건부 | 3D 파싱 모듈 신규 개발 필요 (현재 없음) |
| 출력물 | 종이 | 불가 | — |

## 도면 요구사항 대조

`exam.py`는 현재 아래 값을 전산응용기계제도기능사 기준으로 고정하고 있습니다.

| 상수 | 현재 값 | 일반기계기사 기준 |
|---|---|---|
| `REQUIRED_SHEET` | A3 (420 × 297 mm) | 확인 필요 |
| `REQUIRED_THIRD_ANGLE` | True (제3각법) | 확인 필요 |
| `STANDARD_SCALES` | 1:1, 1:2, 1:5, 2:1 등 | 확인 필요 |
| `MIN_SURFACE_SYMBOLS` | 3 | 확인 필요 |
| `MIN_FCF` | 1 | 확인 필요 |

이 표를 채우는 것이 이 종목 도입의 첫 작업입니다. 값만 바뀌고 로직은 그대로이므로
난이도는 낮습니다.

## 시간 배분 참고

시험 시간은 확인 필요 (작업형은 CAD 도면작업)입니다. CADLens를 연습 도구로 쓴다면 실제 시험과 같은 시간 안에
도면을 그리고, 제출 전 검사를 돌려 누락 항목을 확인하는 사용 방식이 됩니다.

## 요구사항을 확정하는 절차

1. Q-Net 공개문제 게시판에서 이 종목의 최근 공개문제를 최소 3개 회차 내려받는다.
2. 각 회차의 요구사항 문구(도면 크기, 척도, 투상법, 제출 파일 수)를 위 대조표
   형식으로 옮긴다.
3. 3개 회차의 값이 동일하면 그 값을 채택한다. 다르면 가장 최근 회차 또는 가장
   보수적인(엄격한) 값을 채택하고, 그 이유를 이 문서에 남긴다.
4. 확정된 값을 `exam.py`의 종목별 `SPECS` 딕셔너리에 입력한다.

이 절차 없이 하나의 회차만 보고 값을 확정하면, 다른 회차에서 요구사항이 다를 때
정상적인 도면을 오작으로 잘못 판정하게 된다.

## 제출물 형식이 불확실할 때의 기본 태도

파일 형식이나 3D 모델 포함 여부가 확인되지 않은 상태에서는, CADLens가 처리할 수
있는 최소 범위(2D DWG/DXF)만 먼저 지원하고 3D 관련 기능은 비활성으로 둔다.
확인되지 않은 기능을 미리 켜 두면, 사용자가 3D 모델을 올렸을 때 검사가 조용히
아무 것도 하지 않으면서도 정상 완료된 것처럼 보이는 상황이 생길 수 있다.
