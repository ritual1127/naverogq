# 일반기계기사

CADLens 확장 대상 종목 중 하나. 조사 배경과 5개 종목 비교는
[`../README.md`](../README.md)와 [`../00_종합비교표.md`](../00_종합비교표.md)에 있습니다.
응시 규모는 [`../96_응시자_통계.md`](../96_응시자_통계.md)를 보세요.

| 항목 | 값 |
|---|---|
| 규칙 재사용 추정 | 약 60% |
| 신규 개발 부담 | 소 (신규 3건) |
| 핵심 난관 | 필답형(기계요소설계)은 검사 대상 밖 |
| 도입 순서 | 2순위 |

재사용률 60%는 **규칙이 안 맞아서가 아닙니다.** 실기에 필답형이 있어
CADLens가 실기 전체를 다루지 못하기 때문입니다. 작업형에 한정하면 규칙은
그대로 쓸 수 있고, 개발 부담도 5개 종목 중 가장 작습니다.

도입하더라도 **"작업형만 검사한다"는 안내가 반드시 필요합니다.**
안내 없이 붙이면 응시자가 필답형까지 점검된 것으로 오해합니다.
