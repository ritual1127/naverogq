# 일반기계기사 — 개요

## 종목 정보

| 항목 | 내용 |
|---|---|
| 종목명 | 일반기계기사 |
| 등급 | 기사 |
| 직무 분야 | 기계 / 기계장비설비·설치 |
| 시행 기관 | 한국산업인력공단 |
| 실기 과목 | 기계설계실무 |
| 실기 방식 | 필답형 + 작업형(CAD) |
| 실기 시간 | 확인 필요 (작업형은 CAD 도면작업) |
| 합격 기준 | 100점 만점에 60점 이상 |

## 확인된 사실

- 실기는 필답형(기계요소설계)과 작업형(CAD)으로 구성된다.
- 현행 출제기준의 적용 기간은 2024.1.1.~2026.12.31.이다.
- 합격 기준은 100점 만점에 60점 이상이다.

## 이 종목을 검토하는 이유

CADLens는 현재 전산응용기계제도기능사 실기 도면만 검사합니다. 검사 로직의 뼈대는
`dwg.py`의 도면 파싱과 `exam.py`의 판정 함수 8개·채점 루브릭이며, 두 파일 모두 특정 종목에
종속된 상수(도면 크기, 최소 기호 개수 등)를 제외하면 KS 제도 규칙 일반을 다룹니다.

일반기계기사는 CAD로 기계도면을 작성해 제출하는 작업형 실기를 치르므로, 같은 검사 로직이
적용될 여지가 있습니다. 이 폴더의 문서들은 그 여지가 실제로 얼마나 되는지를 항목별로
따져 본 결과입니다.

## 결론 요약

- 기존 규칙 재사용 추정치: **약 60%**
- 판단: **작업형 한정 도입 가능**

근거는 `07_CADLens_규칙_매핑.md`와 `08_추가개발_필요항목.md`에 있습니다.

## 유사 종목과의 위치 비교

5개 검토 대상 종목 안에서 일반기계기사의 재사용률(약 60%)이 어디쯤인지가 도입
순서를 정하는 근거입니다. 재사용률이 높을수록 임계값(도면 크기, 최소 기호 개수)만
바꿔서 열 수 있고, 낮을수록 새 검사 로직을 먼저 만들어야 이 종목을 지원할 수
있습니다. 재사용률이 낮다고 해서 코드 품질이 나쁜 게 아니라, 단지 그 종목의
도면 성격(조립도 중심, 금형 전용 요소 등)이 기능사 기준 도면과 다르기 때문입니다.

## 이 판단이 바뀔 수 있는 조건

이 문서의 판단은 공개된 정보와 현재 코드베이스만으로 내린 잠정 결론입니다.
아래 중 하나라도 사실과 다르게 확인되면 재사용률과 판단을 다시 계산해야 합니다.

- 실기 시험시간이나 채점 방식이 문서 작성 시점 이후 개편된 경우
- 공개문제에서 확인한 도면 요구사항이 실제 회차와 다른 경우
- `dwg.py`/`exam.py`가 이 검토 이후 구조 변경을 거친 경우(0단계 리팩터링 포함)

만들어야 할 부분의 크기를 가늠한 뒤, `09_도입타당성_결론.md`에서 최종 판단과
다음 단계를 확인하는 순서를 권장합니다.
