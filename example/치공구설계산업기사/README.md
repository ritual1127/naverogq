이 종목은 기계설계산업기사로 통합되어 별도로 시행되지 않습니다.
**별도 종목으로 넣지 않습니다.** 넣으면 이미 통합된 시험이 따로 존재하는 것처럼
보이게 됩니다. 해당 응시자는 기계설계산업기사 지원으로 그대로 흡수됩니다.
