# 치공구설계산업기사

CADLens 확장 대상 종목 중 하나. 조사 배경과 5개 종목 비교는
[`../README.md`](../README.md)와 [`../00_종합비교표.md`](../00_종합비교표.md)에 있습니다.
응시 규모는 [`../96_응시자_통계.md`](../96_응시자_통계.md)를 보세요.

| 항목 | 값 |
|---|---|
| 규칙 재사용 추정 | — (별도 산정 안 함) |
| 신규 개발 부담 | 소 (신규 2건) |
| 핵심 난관 | 기계설계산업기사로 **통합된 종목** |
| 도입 순서 | **제외** |

이 종목은 기계설계산업기사로 통합되어 별도로 시행되지 않습니다.
**별도 종목으로 넣지 않습니다.** 넣으면 이미 통합된 시험이 따로 존재하는 것처럼
보이게 됩니다. 해당 응시자는 기계설계산업기사 지원으로 그대로 흡수됩니다.

그래도 조사 기록을 지우지 않는 이유는, **통합됐다는 사실 자체가 근거**이기 때문입니다.
확인하지 않고 뺐다면 왜 뺐는지 설명할 수 없습니다. 조사 과정에서 정리한 도입 실무
문서(일정·리스크·용어집·테스트 계획)는 다른 종목 도입에도 그대로 쓰이므로
[`../공통/`](../공통/)에 남겼습니다.
