# 치공구설계산업기사 — 용어집

## CADLens 코드베이스 용어

| 용어 | 의미 |
|---|---|
| facts | `dwg.py`가 DXF 에서 추출한 구조화 데이터 |
| findings | `exam.py`의 판정 함수가 반환하는 지적사항 목록 |
| severity | 지적사항 등급: `error`(오류) / `warn`(경고) / `info`(참고) |
| 오작(DQ) | `exam.py`에서 즉시 불합격 처리되는 조건 |
| 루브릭 | `exam.py`의 채점 항목·배점 정의(`RUBRIC`) |

## 종목 용어

| 용어 | 의미 |
|---|---|
| 치공구설계산업기사 | 이 문서가 다루는 종목명 |
| 작업형 | CAD 등 실습 도구로 결과물을 만드는 실기 방식 |
| 필답형 | 서술·계산형 답안을 작성하는 실기 방식 |

## 용어를 통일해야 하는 이유

4명이 나눠 47개 문서를 검토하다 보면 같은 개념을 다른 말로 부르기 쉽다.
예를 들어 "오작"을 누군가는 "실격"으로, 누군가는 "즉시 불합격"으로 쓰면 이후
검색이나 교차 참조가 어려워진다. 이 문서에 없는 용어를 새로 쓰게 되면, 만든
사람이 이 표에 추가하고 담당 팀원에게 공유한다.

## 종목별로 뜻이 달라지는 용어 주의

"부품도"라는 단어도 종목에 따라 가리키는 범위가 다를 수 있다. 기계설계산업기사의
부품도는 조립도에서 분리된 단일 부품 도면을 뜻하지만, 금형 계열 종목에서는
"부품도"가 코어·캐비티 같은 금형 구성 부품을 가리킬 수도, 성형되는 제품 자체를
가리킬 수도 있다. 이런 중의성이 있는 용어는 이 표에 "이 종목에서의 의미"를
별도로 적어 둔다.
