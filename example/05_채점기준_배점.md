# 일반기계기사 — 채점기준 및 배점

## 공식 배점표에 관하여

**한국산업인력공단은 실기 채점 항목별 세부 배점을 공개하지 않습니다.** 따라서 이
문서는 공식 배점표가 아니며, 공개된 정보(합격 기준 100점 만점에 60점 이상)와 공개문제의 요구사항에서
역산한 추정입니다. 이 점을 서비스 화면에도 반드시 표시해야 합니다.

## CADLens 현행 루브릭 (전산응용기계제도기능사 기준)

`exam.py`의 `RUBRIC` 상수입니다.

| 코드 | 항목 | 배점 | 판정 방식 |
|---|---|---|---|
| PROJECTION_LAYOUT | 투상도 선택과 배열 | 30점 | AI 검토 |
| DIMENSIONS | 치수 기입 | 15점 | 자동 |
| TOLERANCE | 끼워맞춤 공차·치수공차 | 10점 | 자동 |
| SURFACE | 표면거칠기 | 10점 | 자동 |
| GEOMETRIC | 형상(기하)공차 | 10점 | 자동 |
| NOTES_TITLE | 주서·표제란·부품란 | 8점 | 자동 |
| MATERIAL | 재료 선택과 처리 | 7점 | 자동 |

합계 90점이며, 나머지는 오작 감점 등으로 처리됩니다. 이 중 `PROJECTION_LAYOUT`만
AI 검토(`ai_review.py`)로 판정하고 나머지 6개 항목은 도면 데이터로 자동 판정합니다.

## 일반기계기사에 적용할 때

| 항목 | 이 종목에서의 예상 비중 | 조정 방향 |
|---|---|---|
| 투상도 선택과 배열 | 확인 필요 | 부품 수·조립도 여부에 따라 변동 |
| 치수 기입 | 확인 필요 | 로직 그대로, 배점만 조정 |
| 끼워맞춤·치수공차 | 확인 필요 | 로직 그대로, 배점만 조정 |
| 표면거칠기 | 확인 필요 | 로직 그대로, 배점만 조정 |
| 기하공차 | 확인 필요 | 로직 그대로, 배점만 조정 |
| 주서·표제란 | 확인 필요 | 필수 문구 목록 재작성 |
| 재료·처리 | 확인 필요 | 재질명 사전 확장 |

배점을 확정할 수 없으므로, 도입 시에는 **점수 대신 항목별 충족/미충족 목록**만
보여주는 방식이 안전합니다. 근거 없는 점수를 표시하면 응시자에게 잘못된 확신을 줍니다.

## 권고

1차 도입에서는 점수를 내지 않습니다. "빠진 항목 N개"만 제시합니다.
공식 배점 근거를 확보한 뒤에 점수 기능을 켭니다.

## 배점을 추정하려는 시도가 왜 위험한가

공개문제 문구나 커뮤니티 후기에서 "투상도가 배점이 크다더라" 같은 정보를 얻을 수는
있지만, 이는 응시자 개인의 경험이지 공식 수치가 아닙니다. 이런 정보를 근거로 배점을
매기면, 실제로는 다른 항목이 감점의 대부분을 차지하는데도 CADLens가 사용자에게
잘못된 우선순위를 제시하게 됩니다. 배점 대신 "충족/미충족"만 보여주는 방식은 이
위험을 원천적으로 피합니다.

## 항목 충족 표시로 전환했을 때의 사용자 경험

점수 대신 아래와 같은 형식을 검토합니다.

```
[✓] 치수 기입 — 누락 없음
[✗] 표면거칠기 — 기호 2곳 값 비어 있음
[✓] 기하공차 — 데이텀 지정 확인
[?] 투상도 배열 — AI 검토 결과 확인 필요
```

이 방식은 "몇 점을 받는다"는 확신을 주지 않으면서도, 어디를 고쳐야 하는지는
명확하게 전달합니다. 배점이 공개되기 전까지는 이 형식을 기본값으로 유지합니다.
