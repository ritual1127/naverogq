# 프레스금형산업기사

CADLens 확장 대상 종목 중 하나. 조사 배경과 5개 종목 비교는
[`../README.md`](../README.md)와 [`../00_종합비교표.md`](../00_종합비교표.md)에 있습니다.
응시 규모는 [`../96_응시자_통계.md`](../96_응시자_통계.md)를 보세요.

| 항목 | 값 |
|---|---|
| 규칙 재사용 추정 | 약 50% — 5개 종목 중 가장 낮음 |
| 신규 개발 부담 | 대 (신규 3건) |
| 핵심 난관 | 다이-펀치 클리어런스 · 스트립 레이아웃 |
| 도입 순서 | 4순위 (마지막) |

클리어런스 검사는 **두 부품도를 함께 읽어 치수를 비교**해야 합니다.
현재 `exam.py`는 파일 하나를 독립적으로 검사하므로, 이 요구는 구조 변경을
동반합니다. 5개 종목 중 난이도가 가장 높아 마지막으로 둡니다.
