# 사출금형산업기사 — 검증용 샘플 요구사항

## 필요한 샘플

검사 규칙을 실제로 검증하려면 아래 샘플이 필요하다.

| 샘플 | 용도 | 확보 방법 |
|---|---|---|
| 합격 처리된 실제 도면 | 오탐(false positive) 확인 | 응시자 협조 또는 학원 자료 |
| 불합격 처리된 실제 도면(사유 포함) | 미탐(false negative) 확인 | 위와 동일 |
| Q-Net 공개문제 도면 | 요구사항 기준선 확보 | Q-Net 공식 다운로드 |
| 의도적 결함 도면(자체 제작) | 특정 검사 코드 단위 테스트 | 팀 자체 제작 |

## 원칙

검증 없이 배포하지 않는다. 최소 합격 도면 1개, 불합격 도면 1개는 확보한 뒤
검사 결과가 실제 판정과 일치하는지 확인한다.

## 샘플 확보가 어려울 때의 대안

실제 채점 사유가 딸린 합격/불합격 도면은 응시자 개인정보가 섞여 있어 구하기
어려울 수 있다. 이 경우 차선책은 다음과 같다.

1. Q-Net 공개문제의 모범답안(제공되는 경우)을 합격 기준선으로 삼는다.
2. 팀이 직접 그 공개문제를 풀어 도면을 만들고, 이를 기준선과 비교한다.
3. 의도적 결함 도면을 여러 개 만들어, 각 결함이 CADLens에서 올바른 코드로
   잡히는지 단위 검증한다. 이 방법은 실제 합격/불합격 판정을 대체하지는
   못하지만, 로직 자체의 정확성은 검증할 수 있다.

## 샘플 관리 방법

확보한 샘플은 개인정보(응시자 이름, 수험번호 등)를 제거한 뒤 저장한다. 파일명은
`43_샘플요구사항.md`가 아니라 별도 비공개 저장소에 두고, 이 문서에는 접근 경로만
기록한다. 도면 원본을 이 저장소(공개 문서 폴더)에 직접 넣지 않는다.
