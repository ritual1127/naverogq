# 치공구설계산업기사 — 담당자 메모

## 이 파일의 용도

이 문서를 담당한 팀원이 조사 중 발견한 내용, 막힌 부분, 다음 담당자에게
넘길 정보를 자유 형식으로 남기는 곳이다.

## 작성 예시

```
- 2026-08-XX / 이름: Q-Net에서 출제기준 PDF 찾음, 링크는 42_참고링크.md에 추가함
- 2026-08-XX / 이름: 공개문제에서 도면 크기 문구 못 찾음, 학원 카페에서 확인 시도 중
```

## 현재 메모

(아직 없음 — 담당자가 작성)

## 무엇을 메모할 가치가 있는가

"별다른 문제 없었음"은 메모할 필요가 없다. 다음에 해당하는 것만 남긴다.

- 문서에 적힌 추정이 실제 자료와 달랐던 경우 (어디서, 무엇이 달랐는지)
- 자료를 찾다가 막혀서 다음 담당자가 이어받아야 하는 경우
- 이 종목만의 특이사항이라 다른 종목 문서를 쓸 때도 참고할 만한 경우

## 담당자가 바뀔 때

중간에 담당자가 바뀌면, 이전 담당자는 이 메모란에 "여기까지 확인했고, 다음은
이걸 확인하면 된다"를 남기고 넘긴다. 구두로만 전달하면 팀 전체가 진행 상황을
알 수 없으므로, 반드시 이 파일에 기록한 뒤 인수인계한다.
