# 일반기계기사 — 도입 작업 일정표

## 단계별 일정 (초안)

| 주차 | 작업 | 산출물 |
|---|---|---|
| 1주 | 공개문제 확보, 요구사항 확정 | `04_실기_과제구성.md` 완성 |
| 2주 | `exam.py` 상수 분리, 이 종목 설정값 입력 | 코드 변경 |
| 3주 | 검사 규칙 검증(실제 도면 대입) | 검증 로그 |
| 4주 | 항목별 충족/미충족 표시 기능 공개 | 배포 |

점수 표시 기능은 이 일정에 포함하지 않는다. 배점 확인 이후 별도 일정으로 진행한다.

## 일정이 밀릴 때의 우선순위

4개 작업 모두를 정해진 주차 안에 끝내지 못할 경우, 순서를 뒤로 미루는 게 아니라
범위를 줄인다. 1주(요구사항 확정)는 절대 건너뛸 수 없다 — 이후 모든 단계가
여기에 의존하기 때문이다. 반면 3주(검증)는 실제 도면을 더 적게 확보한 상태로
축소해서 진행할 수 있고, 4주(공개)는 배점 없이 항목 표시만 하는 최소 범위로
줄여서라도 일정 안에 끝내는 편이 전체 지연보다 낫다.

## 각 단계 산출물의 검수 기준

| 단계 | 산출물이 "완료"로 인정되는 조건 |
|---|---|
| 1주 | 공개문제 3개 회차의 요구사항이 표로 정리되고 서로 대조됨 |
| 2주 | 기존 기능사 테스트가 모두 통과한 채로 이 종목 설정값이 추가됨 |
| 3주 | 합격/불합격 실제 도면 각 1개 이상으로 검사 결과가 검증됨 |
| 4주 | "확정된 배점이 아님" 안내 문구가 화면에 노출된 채로 배포됨 |
