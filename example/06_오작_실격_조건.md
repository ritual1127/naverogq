# 일반기계기사 — 오작·실격 조건

## CADLens 현행 오작 판정

`exam.py`의 `CHECKS` 중 `DQ_` 접두사 항목이 오작(즉시 불합격) 판정입니다.

| 코드 | 조건 |
|---|---|
| `DQ_NO_SURFACE_SYMBOL` | 표면거칠기 기호가 아예 없음 |
| `DQ_NO_GEOMETRIC_TOL` | 기하공차 기호가 아예 없음 |
| `DQ_PROJECTION` | 투상법이 제3각법이 아님 |
| `DQ_SHEET_SIZE` | 도면 크기가 요구와 다름 |
| `DQ_SCALE` | 비표준 척도 사용 |

## 주의

오작 판정은 사용자에게 "불합격"을 통보하는 것과 같습니다. 근거가 불확실한 상태로
오작을 띄우면 응시자가 멀쩡한 도면을 고치게 만듭니다.

**공개문제 원문에서 해당 문구를 확인하지 못한 조건은 오작으로 올리지 않습니다.**
경고(warn)로만 표시합니다. 이는 현재 기능사 구현에서도 지켜야 할 원칙입니다.

## 오작과 경고를 가르는 기준

오작(error 등급 중에서도 즉시 불합격)은 "요구사항 문구에 명시적으로 있는 조건만"
해당합니다. 반면 다음과 같은 것들은 아무리 도면 품질이 나빠 보여도 오작이 아니라
경고(warn) 또는 참고(info)로 다뤄야 합니다.

- 이 검토 문서 작성자가 "보통 이렇게 하지 않나" 하고 추측한 관행
- 다른 종목(예: 기능사)의 오작 조건을 그대로 옮겨온 것
- 공개문제 요구사항에는 없지만 KS 규격 일반론상 바람직한 것

## 오작 판정이 잘못됐을 때의 피해 경로

```
CADLens가 A 조건을 오작으로 잘못 판정
  → 사용자가 실제로는 문제 없는 도면을 "오작"으로 인식
  → 존재하지 않는 문제를 고치려고 시간을 씀
  → 실제 시험에서는 감점 없는 부분에 시간을 낭비
```

이 경로가 실제로 발생하면 검사기가 없는 것보다 나쁜 결과를 만듭니다. 오작 조건을
확정할 때 가장 보수적으로 접근해야 하는 이유입니다.
