# 공통 — 종목이 달라도 같은 문서

이 폴더의 27개 문서는 **5개 종목에서 내용이 같습니다.** 근거가 KS 제도 규격과
CADLens 코드 구조이고, 둘 다 종목에 따라 달라지지 않기 때문입니다.

종목마다 실제로 다른 것은 `01`~`09`(개요 · 출제기준 · 채점기준 · 규칙 매핑 ·
도입 타당성)이며, 그쪽은 각 종목 폴더에 있습니다. 5종목 × 27개를 각각 복사해 두면
같은 문장이 135번 반복되고, 규격 하나가 바뀔 때 고쳐야 할 자리가 5배로 늘어납니다.
그래서 한 부만 둡니다.

문서 안에서 `../<종목>/05_채점기준_배점.md` 처럼 적힌 참조는 읽는 사람이 보고 있는
종목 폴더의 해당 문서를 가리킵니다.

## 번호대별 의미

| 번호대 | 내용 |
|---|---|
| 10~15 | KS 표준(치수 · 공차 · 표면거칠기 · 기하공차 · 도면 일반) 적용 |
| 27~31 | 오작(DQ) 조건 개별 분석 |
| 32~38 | 채점 루브릭 7개 항목 개별 분석 |
| 39~47 | 일정 · 리스크 · 용어집 · 테스트 계획 등 도입 실무 |

## 16~26번이 없는 이유

조사 초기에 이 번호대에 검사 함수별 분석 문서 11개를 썼습니다. 그런데 그 문서들이
근거로 삼은 것은 3D 모델 검사기(`check_sketches`, `check_holes`, `check_walls`,
`check_interference` 등)였고, **CADLens에는 그런 코드가 없습니다.** 지금 있는 것은
2D 도면 판정 함수 8개(`_disqualifiers`, `_dimensions`, `_tolerance`, `_surface`,
`_geometric`, `_notes`, `_material`, `_projection`)입니다.

없는 코드를 설명하는 문서를 고쳐서 남기는 것보다 **빼는 쪽이 맞다고 판단했습니다.**
검토 문서의 값어치는 실제 코드와 대조된다는 데 있고, 대조 대상이 없으면 남겨 둘
이유가 없습니다. 번호를 당겨 메우지 않은 것은 다른 문서가 참조하는 번호를 흔들지
않기 위해서입니다.

실제로 구현된 2D 검사가 어느 항목에 걸리는지는 각 종목의
`07_CADLens_규칙_매핑.md`와 이 폴더의 `32`~`38`(루브릭)에 있습니다.
