# CADLens

[![Tests](https://github.com/ritual1127/naverogq/actions/workflows/tests.yml/badge.svg)](https://github.com/ritual1127/naverogq/actions/workflows/tests.yml)
[![Docker smoke test](https://github.com/ritual1127/naverogq/actions/workflows/docker-smoke.yml/badge.svg)](https://github.com/ritual1127/naverogq/actions/workflows/docker-smoke.yml)

CADLens는 전산응용기계제도기능사 실기 도면을 스스로 점검할 수 있는 서비스입니다.

수험생이 DWG 또는 DXF 도면을 올리면 빠진 항목과 잘못된 부분을 찾고, 문제 위치를 도면 위에 번호로 표시합니다. 각 지적사항에는 잘못된 이유와 고치는 방법을 함께 보여줍니다.

[CADLens 바로가기](https://naverogq.onrender.com)

## 전산응용기계제도기능사란?

전산응용기계제도기능사는 CAD를 사용해 기계 부품과 조립품의 도면을 작성하는 능력을 평가하는 국가기술자격입니다.

한국산업인력공단 Q-Net은 이 자격을 제품 개발, 설계, 생산에 필요한 도면과 모델 파일을 산업표준에 맞게 작성하는 직무로 설명합니다.

실기에서는 단순히 부품 모양을 그리는 것만으로 끝나지 않습니다. 다른 사람이 도면만 보고도 부품을 정확하게 만들 수 있도록 크기, 공차, 재료, 가공 방법과 표면 상태를 알맞게 표시해야 합니다.

공식 시험 내용과 공개문제는 [Q-Net 전산응용기계제도기능사 공개문제](https://www.q-net.or.kr/cst006.do?artlSeq=5198906&brdId=Q006&code=1204&gSite=Q&id=cst00602)에서 확인할 수 있습니다.

## 실기 도면에서 확인해야 할 내용

### 투상도

- 부품 모양을 충분히 설명할 수 있는 정면도, 평면도, 측면도가 있는지 확인합니다.
- 필요한 곳에 단면도와 상세도를 사용합니다.
- 제3각법과 도면의 투상법 표시가 서로 맞는지 확인합니다.
- 확대하거나 축소한 뷰에는 척도를 표시합니다.

### 치수

- 부품을 만들 때 필요한 길이, 지름, 반지름과 각도를 빠짐없이 표시합니다.
- 같은 크기의 구멍이 여러 개면 개수와 지름을 함께 표시합니다.
- 치수가 서로 겹치거나 같은 내용을 반복하지 않도록 정리합니다.
- 원과 구멍에는 중심선 또는 중심마크를 표시합니다.

### 끼워맞춤과 치수공차

- 축과 구멍이 결합되는 곳에는 H7, h6, js5 같은 끼워맞춤 표시를 사용합니다.
- 실제 기능에 중요한 치수에는 허용할 수 있는 오차 범위를 표시합니다.
- 공차의 위쪽 값과 아래쪽 값이 바르게 입력됐는지 확인합니다.

### 표면거칠기

- 가공할 면에 표면거칠기 기호와 값을 표시합니다.
- 끼워맞춤면, 접촉면, 일반 가공면의 다듬질 정도를 구분합니다.
- 기호만 있고 거칠기 값이 비어 있지 않은지 확인합니다.

### 기하공차와 데이텀

- 부품의 기준이 되는 면과 축에 데이텀 A, B, C를 표시합니다.
- 필요한 곳에 직각도, 평행도, 동심도, 위치도 등을 표시합니다.
- 기하공차 기호에 공차값과 기준 데이텀이 들어 있는지 확인합니다.

### 주서와 표제란

- 일반공차, 모떼기, 라운드, 열처리와 표면처리 내용을 적습니다.
- 표제란에 품명, 재료, 척도와 필요한 정보를 입력합니다.
- 도면 크기와 윤곽선이 요구 조건에 맞는지 확인합니다.

## 수험생이 자주 놓치는 부분

- 도면 모양은 완성했지만 치수가 빠진 경우
- 구멍에 지름 치수나 중심마크가 없는 경우
- 끼워맞춤 공차를 표시하지 않은 경우
- 표면거칠기 기호만 넣고 값을 적지 않은 경우
- 기하공차에 데이텀이 없는 경우
- 단면도와 상세도에 이름이나 척도가 없는 경우
- 주서의 일반공차, 모떼기 또는 열처리 문구가 빠진 경우
- 표제란과 도면 크기를 마지막에 확인하지 않은 경우

작은 누락 하나는 화면에서 찾기 어렵고, 출력한 뒤에도 지나치기 쉽습니다. CADLens는 이런 실수를 제출 전에 한 번 더 확인하도록 돕습니다.

## CADLens 검사 내용

CADLens는 24개 검사 항목을 사용합니다.

- 치수 누락과 치수 없는 원·구멍
- 끼워맞춤 공차와 치수공차
- 표면거칠기 기호와 값
- 기하공차와 데이텀
- 주서, 표제란과 도면 양식
- 재료, 열처리와 표면처리
- 투상도 개수, 이름, 척도와 배치
- 도면 크기, 투상법과 비표준 척도

검사 결과는 실격, 오류, 경고, 참고로 나누어 보여줍니다. 문제 번호를 누르면 도면의 지적 위치와 설명을 함께 확인할 수 있습니다.

검사 항목이 어느 KS 규격과 채점 기준에서 나왔는지는 [검사 항목과 근거](docs/rule_standards.md)에 항목별로 정리해 두었습니다.

## 검사 정확도

지적이 맞는지를 숫자로 확인할 수 있어야 한다고 보고, 정답이 붙은 기준 도면으로 매번 측정합니다.

| 항목 | 결과 |
|---|---|
| 기준 도면 | 18장 (결함 유형별 합성 도면) |
| 완전 일치 | 18장 |
| 검출률 | 100.0% (결함 17건 중 17건 검출) |
| 오탐 | 0건 |

기준 도면은 결함을 하나씩 심어 만든 합성 도면입니다. 실제 수험생 도면에서의 정확도와는 다르며, 아직 남아 있는 약점도 함께 공개합니다. 측정 방법, 한계, 측정으로 잡아낸 문제는 [검사 정확도](docs/accuracy.md)에 있습니다. `python bench.py`로 누구나 다시 돌려볼 수 있고, GitHub Actions에서 커밋마다 자동으로 검증합니다.

## 실격 가능성이 큰 항목

CADLens는 다음 항목을 점수와 별도로 먼저 확인합니다.

- 표면거칠기 기호가 전혀 없는 도면
- 기하공차 기호가 전혀 없는 도면
- 요구한 투상법과 다른 도면
- 요구한 도면 크기와 다른 도면
- 표준에 맞지 않는 척도를 사용한 도면

실제 판정은 해당 회차의 공개문제와 시험 지시사항을 우선합니다.

## 지원 파일

- DWG
- DXF

한국어, 영어, 일본어, 중국어 화면을 지원합니다. 밝은 화면과 어두운 화면을 모두 지원하며, 처음 방문하면 운영체제 설정을 따릅니다.

앞으로 ipt, idw, iam 파일등을 지원하기 위해 노력하겠습니다

## 제출 이후 개선 내역

대회 제출 이후에도 실제 도면으로 확인하면서 고친 내용입니다. 무엇을 왜 고쳤는지 남겨 둡니다.

### 검사 정확도

측정할 수 없으면 개선했다고 말할 수 없다고 보고, 정답이 붙은 기준 도면으로 매번 재는 구조를 먼저 만들었습니다.

- `bench.py` 추가 — 결함을 하나씩 심은 기준 도면 18장을 실제 분석 경로로 통과시켜 검출률과 오탐을 측정합니다. `python bench.py`로 누구나 재현할 수 있고, 실제 도면에 정답을 붙여 넣으면 그대로 측정됩니다.
- 측정을 붙이자마자 **DXF 경로의 구조적 오탐**이 드러나 함께 고쳤습니다.

| 고친 문제 | 원인 | 조치 |
|---|---|---|
| 모든 DXF가 "표면거칠기 기호 없음"으로 실격 | DXF에서 거칠기 기호를 추출하지 않고 개수를 항상 0으로 둠 | 문자에서 `√`, `Ra/Rz/Ry` 값, 다듬질 기호를 인식 |
| 모든 DXF가 "기하공차 없음"으로 실격 | 기하공차를 추출하지 않음 | `TOLERANCE` 엔티티와 GDT 문자열에서 공차값·데이텀 파싱 |
| 모든 DXF가 "중심선 없음" | 중심선을 세지 않음 | 레이어·선종류로 집계 |
| 모든 DXF가 "투상도 0개" | 투상도를 Inventor 블록 이름으로만 판별 | 판별 불가일 때는 "없음"이 아니라 검사를 생략 |
| 모든 DXF가 "표제란 없음" | 표제란을 블록 속성으로만 인식 | 윤곽선과 표제란 문자로도 인식 |
| 문자가 하나라도 있으면 "주서 있음" | 도면의 모든 문자를 주서로 취급 | 주서다운 문자만 주서로 취급 |
| 축 표시 문자 `X`/`Y`/`Z`를 다듬질 기호로 오인 | 대소문자를 구분하지 않음 | 기호 없이는 소문자만 인정. 실격 도면을 통과시키던 오류라 위험도가 가장 컸습니다 |
| **표면거칠기 기호의 원을 "치수 없는 구멍"으로 지적** | 도면의 모든 원을 구멍 후보로 취급 | 거칠기 기호(∇)의 원은 두 변에 **내접**하고 실제 구멍은 중심선이 **관통**한다는 차이로 판별 |

마지막 항목은 처음에 "기호 근처에 문자가 있으면 제외"로 고쳤다가, 문자가 없는 `∇` 기호에서 그대로 재발했습니다. 문자 위치가 아니라 기하로 판별하도록 다시 고쳤습니다.

### 검사 결과 활용

- **재검사 비교** — 같은 파일을 고쳐서 다시 올리면 지난 결과와 비교해 `고쳐짐 / 그대로 / 새로 생김`과 점수 변화를 보여 줍니다. 한 번 검사하고 끝나던 흐름을 `검사 → 수정 → 재검사`로 바꿉니다. 결과는 브라우저에만 저장되며 서버로 전송하지 않습니다.
- **지적 위치로 이동** — 지적사항의 번호를 누르면 도면 미리보기가 그 위치로 확대됩니다.
- **미리보기 조작** — 드래그 이동, 휠 확대, 확대·축소·맞춤 버튼을 추가했습니다.
- 결과 화면에서 지적사항을 채점 항목보다 먼저 보여 주도록 순서를 바꿨습니다.

### 문서와 검증

- [검사 항목과 근거](docs/rule_standards.md) — 검사 코드 24개가 각각 어느 KS 규격과 채점 기준에서 나왔는지, 코드 어디에 구현되어 있는지 정리했습니다.
- [검사 정확도](docs/accuracy.md) — 측정 방법, 결과, **한계와 남은 약점**을 함께 공개합니다.
- GitHub Actions에 테스트와 정확도 벤치마크를 추가해 커밋마다 자동 검증합니다.

### 화면

- 화면 전체를 다시 디자인하고 **어두운 화면**을 추가했습니다. 색은 모두 토큰으로 정리해 두 화면이 같은 규칙을 공유하며, 본문·보조 문자와 강조 색의 명암비를 확인했습니다.
- 홈 화면의 3D 워드마크는 폰트에서 글자 외곽선을 추출해 실제로 압출한 입체입니다.
- 브라우저 탭 아이콘이 나오지 않던 문제를 고쳤습니다.

## 활용 대상

- 전산응용기계제도기능사 실기를 준비하는 학생
- 학교와 직업훈련기관의 기계제도 수업
- CAD 도면을 처음 배우는 학습자
- 제출 전에 도면 누락을 빠르게 확인하려는 사용자

## 주의사항

CADLens는 수험생의 최종 확인을 돕는 보조 도구입니다. 도면의 기능, 가공 가능성, 과제별 특별 지시사항까지 모두 대신 판단할 수는 없습니다.

최종 제출 전에는 반드시 해당 시험 회차의 공개문제, 지급 자료와 감독위원의 지시사항을 함께 확인해야 합니다.
