# CADLens
CADLens는 전산응용기계제도기능사 실기 도면을 스스로 점검할 수 있는 서비스입니다.

수험생이 DWG 또는 DXF 도면을 올리면 빠진 항목과 잘못된 부분을 찾고, 문제 위치를 도면 위에 번호로 표시합니다. 각 지적사항에는 잘못된 이유와 고치는 방법을 함께 보여줍니다.

[CADLens 바로가기](https://naverogq.onrender.com)

## 전산응용기계제도기능사란?

전산응용기계제도기능사는 CAD를 사용해 기계 부품과 조립품의 도면을 작성하는 능력을 평가하는 국가기술자격입니다.

한국산업인력공단 Q-Net은 이 자격을 제품 개발, 설계, 생산에 필요한 도면과 모델 파일을 산업표준에 맞게 작성하는 직무로 설명합니다.

실기에서는 단순히 부품 모양을 그리는 것만으로 끝나지 않습니다. 다른 사람이 도면만 보고도 부품을 정확하게 만들 수 있도록 크기, 공차, 재료, 가공 방법과 표면 상태를 알맞게 표시해야 합니다.

공식 시험 내용과 공개문제는 [Q-Net 전산응용기계제도기능사 공개문제](https://www.q-net.or.kr/cst006.do?artlSeq=5198906&brdId=Q006&code=1204&gSite=Q&id=cst00602)에서 확인할 수 있습니다.

## 실기 도면에서 확인해야 할 내용

### 투상도

- 부품 모양을 충분히 설명할 수 있는 정면도, 평면도, 측면도가 있는지 확인합니다.
- 필요한 곳에 단면도와 상세도를 사용합니다.
- 제3각법과 도면의 투상법 표시가 서로 맞는지 확인합니다.
- 확대하거나 축소한 뷰에는 척도를 표시합니다.

### 치수

- 부품을 만들 때 필요한 길이, 지름, 반지름과 각도를 빠짐없이 표시합니다.
- 같은 크기의 구멍이 여러 개면 개수와 지름을 함께 표시합니다.
- 치수가 서로 겹치거나 같은 내용을 반복하지 않도록 정리합니다.
- 원과 구멍에는 중심선 또는 중심마크를 표시합니다.

### 끼워맞춤과 치수공차

- 축과 구멍이 결합되는 곳에는 H7, h6, js5 같은 끼워맞춤 표시를 사용합니다.
- 실제 기능에 중요한 치수에는 허용할 수 있는 오차 범위를 표시합니다.
- 공차의 위쪽 값과 아래쪽 값이 바르게 입력됐는지 확인합니다.

### 표면거칠기

- 가공할 면에 표면거칠기 기호와 값을 표시합니다.
- 끼워맞춤면, 접촉면, 일반 가공면의 다듬질 정도를 구분합니다.
- 기호만 있고 거칠기 값이 비어 있지 않은지 확인합니다.

### 기하공차와 데이텀

- 부품의 기준이 되는 면과 축에 데이텀 A, B, C를 표시합니다.
- 필요한 곳에 직각도, 평행도, 동심도, 위치도 등을 표시합니다.
- 기하공차 기호에 공차값과 기준 데이텀이 들어 있는지 확인합니다.

### 주서와 표제란

- 일반공차, 모떼기, 라운드, 열처리와 표면처리 내용을 적습니다.
- 표제란에 품명, 재료, 척도와 필요한 정보를 입력합니다.
- 도면 크기와 윤곽선이 요구 조건에 맞는지 확인합니다.

## 수험생이 자주 놓치는 부분

- 도면 모양은 완성했지만 치수가 빠진 경우
- 구멍에 지름 치수나 중심마크가 없는 경우
- 끼워맞춤 공차를 표시하지 않은 경우
- 표면거칠기 기호만 넣고 값을 적지 않은 경우
- 기하공차에 데이텀이 없는 경우
- 단면도와 상세도에 이름이나 척도가 없는 경우
- 주서의 일반공차, 모떼기 또는 열처리 문구가 빠진 경우
- 표제란과 도면 크기를 마지막에 확인하지 않은 경우

작은 누락 하나는 화면에서 찾기 어렵고, 출력한 뒤에도 지나치기 쉽습니다. CADLens는 이런 실수를 제출 전에 한 번 더 확인하도록 돕습니다.

## CADLens 검사 내용

CADLens는 24개 검사 항목을 사용합니다.

- 치수 누락과 치수 없는 원·구멍
- 끼워맞춤 공차와 치수공차
- 표면거칠기 기호와 값
- 기하공차와 데이텀
- 주서, 표제란과 도면 양식
- 재료, 열처리와 표면처리
- 투상도 개수, 이름, 척도와 배치
- 도면 크기, 투상법과 비표준 척도

검사 결과는 실격, 오류, 경고, 참고로 나누어 보여줍니다. 문제 번호를 누르면 도면의 지적 위치와 설명을 함께 확인할 수 있습니다.

검사 항목이 어느 KS 규격과 채점 기준에서 나왔는지는 [검사 항목과 근거](docs/rule_standards.md)에 항목별로 정리해 두었습니다.

## 검사가 맞는지 확인한 방법

"잘 맞는다"고 말하려면 확인할 방법이 있어야 한다고 생각했습니다. 그래서 **답을 미리 정해 둔 연습용 도면**을 만들었습니다. 예를 들어 "치수를 일부러 빼놓은 도면"을 넣고, CADLens가 그걸 정확히 찾아내는지 봅니다.

| | |
|---|---|
| 연습용 도면 | 18장 (실수 유형별로 한 가지씩) |
| 정확히 맞힌 도면 | 18장 |
| 찾아야 할 문제를 찾은 비율 | 100% (17건 중 17건) |
| 없는 문제를 있다고 한 경우 | 0건 |

다만 이 도면들은 저희가 직접 만든 것이라 실제 수험생 도면보다 단순합니다. **이 100%가 실제 시험 도면에서도 100%라는 뜻은 아닙니다.** 어떻게 쟀는지와 아직 부족한 점은 [검사 정확도](docs/accuracy.md)에 솔직하게 적어 두었습니다.

## 실격 가능성이 큰 항목

CADLens는 다음 항목을 점수와 별도로 먼저 확인합니다.

- 표면거칠기 기호가 전혀 없는 도면
- 기하공차 기호가 전혀 없는 도면
- 요구한 투상법과 다른 도면
- 요구한 도면 크기와 다른 도면
- 표준에 맞지 않는 척도를 사용한 도면

실제 판정은 해당 회차의 공개문제와 시험 지시사항을 우선합니다.

## 지원 파일

- DWG
- DXF

한국어, 영어, 일본어, 중국어 화면을 지원합니다. 밝은 화면과 어두운 화면을 모두 지원하며, 처음 방문하면 운영체제 설정을 따릅니다.

## 제출한 뒤에 고친 것

제출하고 나서도 실제 도면을 계속 넣어 보면서 잘못된 부분을 찾아 고쳤습니다. 무엇이 문제였고 어떻게 바꿨는지 남겨 둡니다.

### 잘못 지적하던 문제들을 찾아서 고쳤습니다

위에서 만든 연습용 도면으로 확인해 보니, **DXF 도면은 거의 무조건 실격으로 나오고 있었습니다.** 도면에는 분명히 있는 내용을 CADLens가 읽지 못하고 "없다"고 판단하고 있었습니다.

| 잘못 나오던 것 | 왜 그랬나 |
|---|---|
| 모든 DXF가 "표면거칠기 기호 없음"으로 실격 | 도면에서 거칠기 기호를 읽지 못했습니다 |
| 모든 DXF가 "기하공차 없음"으로 실격 | 기하공차 기호를 읽지 못했습니다 |
| 모든 DXF가 "중심선 없음" | 중심선을 세지 못했습니다 |
| 모든 DXF가 "투상도 0개" | 투상도를 알아보지 못했습니다 |
| 모든 DXF가 "표제란 없음" | 표제란을 알아보지 못했습니다 |
| 글자가 하나만 있어도 "주서 있음" | 도면의 모든 글자를 주서로 착각했습니다 |

전부 읽을 수 있게 고쳤고, 알 수 없는 항목은 "없다"고 단정하지 않고 검사를 건너뛰도록 바꿨습니다.

### 특히 위험했던 두 가지

**1. 실격인 도면을 통과시키던 문제**

도면에 방향 표시로 쓰는 `X`, `Y`, `Z` 같은 글자를 CADLens가 표면거칠기 기호로 착각했습니다. 그래서 거칠기 기호가 하나도 없는(= 실격인) 도면인데도 "기호가 있다"고 통과시켰습니다. 잘못 지적하는 것보다 **실격을 놓치는 쪽이 더 위험**해서 우선 고쳤습니다.

**2. 표면거칠기 기호에 "치수를 넣으세요"라고 하던 문제**

표면거칠기 기호(∇)에도 동그라미가 들어갑니다. CADLens가 그 동그라미를 구멍으로 착각해서 "치수가 빠졌다"고 지적했습니다.

처음에는 "기호 옆에 글자가 있으면 넘어가자"로 고쳤는데, 글자가 없는 기호에서 똑같은 문제가 다시 나왔습니다. 그래서 **모양의 차이**로 구분하도록 다시 고쳤습니다. 기호의 동그라미는 기호를 이루는 두 선에 딱 붙어 있고, 진짜 구멍은 중심선이 한가운데를 가로지릅니다.

### 새로 추가한 기능

- **다시 검사해서 비교하기** — 도면을 고쳐서 같은 이름으로 다시 올리면, 지난번과 비교해서 `고쳐짐 / 그대로 / 새로 생김`과 점수 변화를 보여 줍니다. 한 번 검사하고 끝나는 게 아니라 `검사 → 고치기 → 다시 검사`를 반복할 수 있습니다. 비교 기록은 사용자 브라우저에만 저장되고 서버로 보내지 않습니다.
- **지적한 곳으로 바로 이동** — 지적사항의 번호를 누르면 도면에서 그 위치가 확대됩니다.
- **도면 확대·이동** — 미리보기를 마우스로 끌어서 움직이고, 휠로 확대할 수 있습니다.
- 결과 화면에서 지적사항을 채점 항목보다 먼저 보여 주도록 순서를 바꿨습니다. 수험생이 가장 먼저 볼 내용이라고 생각했습니다.

### 화면

- 화면을 새로 만들고 **어두운 화면**을 추가했습니다. 처음 들어오면 사용자 기기 설정을 따라가고, 오른쪽 위 버튼으로 바꿀 수 있습니다.
- 홈 화면의 CADLens 글자를 입체로 만들어 돌아가게 했습니다.
- 브라우저 탭에 아이콘이 안 나오던 문제를 고쳤습니다.

### 검사 근거 정리

- [검사 항목과 근거](docs/rule_standards.md) — 검사 항목 24개가 각각 어느 KS 규격과 채점 기준에서 나왔는지 정리했습니다.
- 코드를 고칠 때마다 위의 연습용 도면 검사가 자동으로 돌아가서, 고치다가 다른 걸 망가뜨리면 바로 알 수 있게 했습니다.

## 활용 대상

- 전산응용기계제도기능사 실기를 준비하는 학생
- 학교와 직업훈련기관의 기계제도 수업
- CAD 도면을 처음 배우는 학습자
- 제출 전에 도면 누락을 빠르게 확인하려는 사용자

## 주의사항

CADLens는 수험생의 최종 확인을 돕는 보조 도구입니다. 도면의 기능, 가공 가능성, 과제별 특별 지시사항까지 모두 대신 판단할 수는 없습니다.

최종 제출 전에는 반드시 해당 시험 회차의 공개문제, 지급 자료와 감독위원의 지시사항을 함께 확인해야 합니다.
