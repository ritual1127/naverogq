# AI 정확도 — 교사 판정과 대조 (본선 11-11 전)

운영진 회신(10-20)에 "본선 전까지 AI 지적을 교사 판정과 대조해 고치겠다"고 적었다. 그 계획과 진행을 여기에 둔다.
대상은 투상도 선택과 배열 30점(AI) 하나다 — 나머지 70점은 규칙 코드라 [검사 정확도](../docs/accuracy.md)에서 따로 잰다.

## 무엇을 재나

| 지표 | 뜻 | 계산 |
|---|---|---|
| 지적 정밀도 | AI 지적 중 선생님이 맞다고 한 비율 | 맞음 ÷ (맞음 + 틀림), 애매는 따로 |
| 점수 차 | AI 가 선생님보다 후한지 박한지 | AI 점수 − 선생님 점수의 평균 · 절대값 평균 · ±3점 안 비율 |
| 감점 여부 일치 | 둘 다 감점했거나 둘 다 30점 | 일치한 도면 ÷ 전체 |
| 놓친 것 | AI 가 못 본 문제 | 선생님이 「놓친 것」을 적은 도면 수 |
| 지적 종류별 정밀도 | 어느 판정을 고쳐야 하나 | 종류마다 맞음 ÷ (맞음 + 틀림) |

계산은 [`ai_teacher_compare.py`](../ai_teacher_compare.py), 시험은 `test_rules.py::test_teacher_compare_metrics`.

## 어떻게

1. **키트를 만든다** — `python ai_teacher_kit.py` 가 실제 도면 23장(`실제도면/labels.json`)을 공개 서버와 같은
   `ai_review.judge()` 로 채점해 HTML 한 장(`실제도면/교사대조/`)으로 만든다. 도면마다 그림 · AI 점수 · 지적이 있고,
   지적마다 맞음 / 틀림 / 애매와 메모, 선생님 점수, 「AI 가 놓친 것」 칸이 있다. 「결과 저장」을 누르면 JSON 이 내려받아진다.
2. **선생님께 드린다** — 파일로만 드린다. 수험생 도면이 들어 있어 저장소 · 공개 링크에 올리지 않는다(`.gitignore`).
   인터뷰에서 도면을 준 선생님께 먼저 부탁하고([`docs/interviews.md`](../docs/interviews.md)), 두 분이면 서로 다른 판단도 본다.
3. **센다** — `python ai_teacher_compare.py 실제도면/교사대조/ai_results_<id>.json 결과.json …`. 키트 id 가 다르면 섞지 않는다.
4. **고친다** — 정밀도가 낮은 지적 종류부터 지시문을 고치고, 같은 23장으로 다시 재서 전후를 비교한다. 고친 판으로 키트를
   다시 만들어 한 번 더 받는다.
5. **공개한다** — 숫자와 표를 [검사 정확도](../docs/accuracy.md)에 「교사 대조」 절로 남기고, 발표에도 그 숫자만 쓴다.

## 먼저 볼 것 — 10-20 밤에 이미 보인 것

- **정면도 감점이 습관처럼 붙었다.** 10장 모두에 「정면도 선택 부적절 4 ~ 5점」, 여러 장의 근거가 "정면도" 한 낱말이었다.
  근거 없는 감점은 점수에서 빼게 고쳐 10/10 → 4/10 이 됐다([P45](문제점/P45-AI정면도감점근거없음.md)). 남은 4장이 맞는지가 첫 확인 대상이다.
- **감점과 근거가 어긋난 지적** — 예제 sample_body 의 단면 1점 감점 detail 이 "제대로 표기됨"이다.
- **같은 도면 점수 차** — 두 번 매기면 평균 1.2점(최대 5점) 다르다([P44](문제점/P44-AI응답시간흔들림.md) 측정과 같은 날). 선생님 점수와의 차가 이보다 작으면 모델 탓보다 흔들림 탓이다.

## 한계

- 23장 대부분이 한 학생의 작업 중간 도면이다([검사 정확도](../docs/accuracy.md) 「정답을 어떻게 달았나」). 여러 학생의 완성 도면이 더 필요하다.
- 선생님 한 분의 판단은 정답이 아니라 한 사람의 채점이다. 두 분 이상이면 서로의 일치도도 같이 적는다.
