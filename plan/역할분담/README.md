# 역할 분담

누가 언제 무엇을 맡았고 실제로 무엇을 했는지 남기는 폴더입니다.

## 어떻게 정했나

- 담당자는 **무작위로 배정**합니다. 사람마다 잘하는 것만 계속 맡으면 한 사람만 늘고 나머지는 8주 동안 배우는 게 없습니다.
- 네 명을 섞은 묶음을 반복해 쓰기 때문에 **건수는 고르게** 나뉩니다.
- 회의 · 데모데이 참석 · 합의가 필요한 일은 배정하지 않고 `전원`으로 둡니다.
- 배정받은 사람이 도저히 못 하는 일이면 **그날 안에 바꾸고, 누구와 바꿨는지 이 폴더에 적습니다.** 조용히 남이 대신 하면 기록이 거짓이 됩니다.
- 08-18 ~ 08-22 는 이미 지난 날이라 무작위 배정이 아니라 **실제로 한 사람**을 적었습니다.

## 적는 법

1. 그날 일이 끝나면 본인 파일에서 그 줄의 달성 칸을 고칩니다 (`⬜` → `✅` · `🔺` · `❌`).
2. **실제로 한 일** 칸에 무엇을 했는지 한 줄 적습니다. 계획과 달라졌으면 달라진 대로 적습니다.
3. 남과 바꿨으면 두 사람 파일 모두에 적습니다.
4. 못 한 것은 지우지 않습니다. `❌`로 남기고 이유를 적습니다. 다 `✅`인 기록은 아무도 믿지 않습니다.
