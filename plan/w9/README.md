## 이번 주 규칙

[계획표의 "매일 지킬 것"](../10-19까지.md#매일-지킬-것)과 같다. 이번 주에 특히 —

- 코드는 **10-16 저녁**에 멈춘다. 그 뒤 커밋은 문서만 한다.
- 공개 사이트에서 팀이 검사하지 않는다. 해야 하면 [계획표의 기록](../10-19까지.md#팀이-공개-사이트를-연-기록)에 적는다.
- 실기 준비반에 다시 써 보라고 권하지 않는다(10-18 까지).

## 이번 주 메모

- **10-15 — 산출물 "실기반에서 가장 많이 멈춘 곳 하나를 고친 것과 그 전후"는 비었다.** 고치기는 10-15 저녁까지였는데 고칠 곳을 고를
  기록(10-12 실기반 사람별 기록 · 10-13 고를 곳)이 끝내 저장소에 오지 않았다([P34](../문제점/P34-고칠곳근거없음.md)). 10-16 마지막 배포에는
  검색 확인 태그만 싣는다.
- **10-15 — Build Filters 가 걸렸다는 기록이 없다**(10-08 ~ 10 ❌ 뒤로 없음). 아래 규칙의 "그 뒤 커밋은 문서만"은 문서 푸시가 서버를
  다시 띄우지 않는다는 데 기대고 있다. 10-16 마지막 배포 전에 박지완이 Render 대시보드에서 본다([10-15 메모](10-15_목/계획.md#메모)).
- **10-16 — 마지막 배포는 `39bc4df` 다.** 이 커밋이 10-18 평가 때 돈다. Build Filters 는 10-16 에도 못 봤다 — 그래서 10-17 · 18 문서 커밋은
  메시지 끝에 `[skip render]` 를 넣는다. 10-16 에 그 뒤로 올린 문서 커밋 10개(19:4x 검증 커밋 포함)도 모두 넣었다.
- **10-17 — 동결을 한 번 풀었다.** 웹사이트를 다시 점검하다 공개 서버 결과 화면의 도면 미리보기에서 한글이 전부 □ 인 것을 찾았고([P37](../문제점/P37-미리보기한글깨짐.md)),
  박지완이 동결을 풀기로 정했다. 같이 찾은 화면 고침과 묶어 배포했는데, 첫 커밋 `cf77311` 은 메시지 본문의 건너뛰기 표시 글자 때문에 건너뛰어져([P38](../문제점/P38-배포건너뜀표시.md))
  `7446422` 로 다시 걸었다(21:08:50 반영). **10-18 평가 때 도는 것은 이 배포다.** 위 규칙의 "코드는 10-16 저녁에 멈춘다"는 이 한 번을 빼고 그대로다 — 10-18 · 19 는 다시 문서만.
- **10-18 새벽 — 화면만 한 번 더 배포했다.** 박지완이 어두운 화면에서 페이지가 한눈에 안 들어오고 글이 잘 안 읽힌다며 효과 · 움직임과 같이 고치라고 했고,
  10-18 계획의 "코드는 건드리지 않는다"와 달리 새벽에 검증한 뒤 한 번 배포하기로 정했다(평가는 10-18 까지의 프로덕트로 한다). `72b28bf` 01:18:10 반영 —
  파이썬은 그대로, `static/` 만. **10-18 평가 때 도는 것은 이 배포다.** 되돌릴 곳은 `7446422`. 아침 김승준 점검이 이 화면을 본다([10-18 메모](10-18_일/계획.md#메모)).
- **10-18 아침 — 화면을 한 번 더 배포했다.** 박지완이 공개 사이트를 보고 마우스 좌표 · 계속 도는 빛 · 머리 문구 · 촌스러운 장식을 없애고,
  밝은 화면 위쪽 바와 '이렇게 나와요'를 고치라고 했고, 08:06 에 다시 물어 "검증 후 바로 배포"로 정했다. `459f6ed` 08:36:00 반영 —
  서버 코드는 그대로(시험 하나 추가), `static/` 만. **새벽 배포 대신 이것이 10-18 평가 때 돈다.** 되돌릴 곳은 `72b28bf`.
  배포 직후 `/api/health` 첫 응답 39.8초 — [P40](../문제점/P40-배포직후첫응답느림.md). 오늘 또 배포하면 그 직후에도 같을 수 있다.
- **10-16 — 윤리 쪽에서 둘을 찾았다.** 공개 서버 Gemini 는 무료 등급이라 보낸 그림을 Google 이 제품 개선에 쓴다([P33](../문제점/P33-무료AI와학습문구.md) — 화면 · 정책 · README 를 사실대로 고침),
  같은 약관이 18세 미만을 대상으로 하거나 18세 미만이 쓸 가능성이 큰 서비스에는 API 를 못 쓰게 한다([P35](../문제점/P35-제미나이18세조항.md) — 채점기는 10-19 뒤에 정함).
