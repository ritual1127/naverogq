# 주간 계획

본선 8주 코칭(2026-08-18 ~ 10-12) 동안 무엇을 언제 하는지 주 단위로 적어 두는 폴더입니다.

무엇을 왜 하는지에 대한 큰 그림은 [발전 계획](../docs/roadmap.md)에 있습니다. 이 폴더는
그 계획에서 **이번 주에 실제로 손댈 것만** 잘라 온 것입니다.

## 규칙

- 파일 하나가 한 주입니다. 이름은 `2026-08-4주차.md`처럼 적습니다.
- 한 주에 할 일은 **날짜별로 하나씩**만 적습니다. 여러 개를 적으면 아무것도 안 끝납니다.
- 할 일마다 `왜`와 `끝난 기준`을 같이 적습니다. 끝난 기준이 없으면 끝났는지 알 수 없습니다.
- 끝나면 `- [ ]`를 `- [x]`로 바꾸고, 결과 숫자나 문서 링크를 그 자리에 남깁니다.
- 커밋은 할 일 하나를 다시 잘게 나눠서 따로따로 합니다. 되돌릴 때 그 단위로 되돌립니다.
