## 할 일

### 1. 팀 밖 기기로 처음부터 끝까지 — **장우영**  ·  예상 1시간

- **심사위원은 링크 하나만 눌러 본다.** 팀원이 아닌 사람의 휴대폰 1대와, 아무 컴퓨터의 시크릿 창 하나로 한다.
- 항목마다 ✅ / ❌ 와 숫자를 메모에 —

  | 항목 | 어떻게 |
  |---|---|
  | 첫 응답 | 링크를 누르고 첫 화면이 뜰 때까지 몇 초 |
  | 첫 화면 | 결과 미리보기가 보이는지 · 시크릿 창에서는 지난 검사 목록이 **안** 보이는지 |
  | 예제 | `예제로 먼저 보기` → 결과까지 몇 초 |
  | 내 도면 | DWG 하나 · DXF 하나 · zip 하나 |
  | Inventor 원본 | `.ipt` 를 올리면 무엇을 하라는 안내가 뜨는지 |
  | 네 언어 | 한국어 · English · 日本語 · 中文 |
  | 밝은 · 어두운 화면 | 글자가 다 읽히는지 |
  | 공식 채점이 아니라는 안내 | 결과 화면에 계속 보이는지 |
- 이 점검은 공개 서버에 검사로 세인다 — 한 일과 시각을 [계획표의 기록](../../10-19까지.md#팀이-공개-사이트를-연-기록)에 적는다.

**이렇게 되면 끝** — 표가 다 찼다. ❌ 는 그날 박지완에게

**흔한 실수** — 팀원 휴대폰으로 하는 것. 이미 열어 본 기기는 처음 온 사람과 다르다

### 2. README 만 보고 팀 밖 사람이 실행 — **안대열**  ·  예상 1시간

- W3 · W8 자가 점검 "README 만 보고 외부인이 실행할 수 있다"가 지금 🔺 다 — 실행 방법을 10-03 에 넣었지만 따라 해 본
  사람이 없다.
- 팀원이 아닌 사람이 [README](../../../README.md) 의 "내 컴퓨터에서 실행하기"를 그대로 따라 한다. 안대열은 **옆에서 보기만**
  한다. 막힌 곳 · 걸린 시간 · 그 사람이 한 말을 메모에 적는다.
- 막힌 곳은 README 를 고칠 곳이다 → 박지완(문서라 동결 뒤에도 고칠 수 있다).

**이렇게 되면 끝** — 그 사람 컴퓨터에서 첫 화면이 떴다. 또는 어디서 막혔는지 적혔다

**흔한 실수** — 막히자마자 대신 쳐 주는 것. 그러면 README 가 아니라 안대열이 실행한 것이다

### 3. 실기 준비반 관찰 기록지 — **박지완**  ·  예상 40분

- 내일 실기반에서 쓸 한 장. W5 "옆에서 지켜보며 어디서 멈추는지 사람별로 적는다".
- 사람마다 한 줄 — 몇 번째 사람(이름은 안 쓴다) · 쓰는 프로그램(AutoCAD · Inventor) · 올린 파일 형식 · **멈춘 화면과 그때
  한 말** · 결과를 보고 한 말 · 고쳐서 다시 올렸나.
- 끝나고 물을 것 셋 — 10-08 질문과 같게(그 뒤 그린 도면을 올렸나 / 안 올렸다면 왜 / 다시 쓰려면 무엇이).
- **머릿수 칸** — 실습실은 인터넷 주소를 같이 써 서버는 여러 명을 한 명으로 센다. 들어가기 전과 나온 뒤
  `/api/stats` 의 `total.checks` · `total.samples` 를 적는 칸을 둔다.
- 칠판에 적을 주소 한 줄 — `naverogq.onrender.com`.
- `docs/beta.md` 에 양식으로 만든다 — 인쇄해서 들고 가고, 다녀와서 같은 파일에 옮긴다.

**이렇게 되면 끝** — 인쇄할 수 있는 한 장이 있다

**흔한 실수** — 칸을 많이 만드는 것. 15분 동안 사람을 보면서 채울 수 있어야 한다

### 4. 실명 기록(P13)을 어떻게 할지 정하기 — **박지완**  ·  예상 30분

- 윤리 · 안전은 **통과/탈락**이다. 인터뷰 대상자 2명(미성년자 포함)의 실명이 08-25 ~ 29 커밋 기록에 남아 있다
  ([P13](../../문제점/P13-실명공개.md) · [W8 준비](../W8_준비.md#탈락-위험--하나라도-남으면-감점-또는-제외) 2번).
- 두 길 — ① 기록을 다시 써서 지운다(강제 푸시 · 팀원 셋이 다시 받아야 함 · 커밋 해시가 바뀜) ② 그대로 두고 P13 에 이유를 적는다.
- 정한 길과 이유를 P13 에 적는다. ①이면 하는 날을 따로 잡는다 — 10-16 동결 전에.

**이렇게 되면 끝** — P13 에 정한 길과 이유가 있다

**흔한 실수** — 평가가 끝날 때까지 미루는 것. 심사위원이 커밋을 열어 볼 수 있다
