세 사람 각각 **다섯 개**입니다. 다섯 번째는 강의가 반드시 넣으라고 한 질문이라 빼지 않습니다.
꼬리 질문은 상대가 한 줄로 끝낼 때만 씁니다. 질문 수에는 넣지 않습니다.

## 묻기 전에 외울 것

- **읽는 문장은 굵은 줄 하나뿐입니다.** 나머지는 상대가 짧게 답할 때 꺼내는 예비입니다.
  다섯 줄을 한 번에 쏟으면 상대가 마지막 것만 답합니다.
- **답이 끊기면 3초를 셉니다.** 침묵을 우리가 먼저 깨면 상대는 생각하다 만 것을 안 말합니다.
- **"보통"이라고 답하면 실패입니다.** "보통 그냥 확인해요" → "그러면 **지난번**엔 어떻게 했어요?"로
  되물어 한 번의 사건으로 끌어내립니다. 우리가 필요한 건 습관이 아니라 사건입니다.
- **숫자는 그 자리에서 받아 냅니다.** 몇 분 · 몇 번 · 몇 점. "좀 오래"는 기록이 안 됩니다.
- **우리 서비스 얘기를 먼저 꺼내지 않습니다.** 꺼내는 순간 인터뷰가 아이디어 회의가 됩니다.
  상대가 먼저 물으면 "끝나고 보여 줄게"라고 미룹니다.
- 받아 적을 것 — **직접 인용 3개** · 지금 쓰는 대안 · 강한 신호 유무 · 숫자.

## 박주호 (기계과 학생)

| | |
|---|---|
| 학년 | |
| 실기 준비 중인가 | |
| 언제 · 어디서 | |
| 도면 파일 받았나 | |

### 1. 지난번에 도면 그려서 낸 게 언제야? 그때 빠뜨리거나 틀린 거 있었어?

- 못 떠올리면 — "이번 학기에 낸 도면 중에 제일 최근 거 아무거나."
- "별로 없었어" 하면 — "점수 깎인 건 있었어? 뭘로 깎였어?"
- 뭘 틀렸는지 **이름으로** 말하게 한다 — 표제란 · 척도 · 치수 · 선 굵기 · 투상도 배열 · 중심선.
- 여러 개 나오면 **제일 최근 것 하나**를 골라 2~4번을 그거 하나로 끝까지 따라간다.
- 받아 적을 것 — 항목 이름, 언제(날짜나 "지난주"), 어떤 과제였는지.

### 2. 그거 언제 알았어? 네가 봤어, 아니면 누가 말해 줬어?

- 그리는 중 / 내기 전 / 낸 뒤 / 점수 나온 뒤 — 넷 중 어디인지 반드시 고르게 한다.
- 남이 봤으면 — "누가? 그 사람이 뭐라고 했어?" (그 말을 그대로 적는다)
- 점수 나온 뒤였으면 — "그날부터 알기까지 며칠 걸린 거야?"
- **여기가 제일 중요한 질문이다.** 늦게 알수록 우리가 벌어 줄 시간이 크다.

### 3. 알고 나서 그때 어떻게 했어?

- "다시 그렸어" → "처음부터? 그 부분만? **몇 분 걸렸어?**"
- "그냥 냈어" → "왜? 시간이 없었어, 아니면 고쳐도 소용없다고 봤어?"
- "선생님한테 갔어" → "가서 뭐라고 물었어? 뭐라고 하셨어?"
- 받아 적을 것 — **분 단위 시간**, 점수를 깎였으면 몇 점.

### 4. 지금은 내기 전에 뭘로 확인해?

- **이게 지금 쓰는 대안이다. 구체적으로 못 들으면 이 인터뷰는 반쯤 실패다.**
- "그냥 봐" → "어디부터 봐? 순서가 있어?"
- 적어 둔 게 있으면 — "그거 지금 보여 줄 수 있어?" (사진 한 장이면 충분하다)
- 사람한테 보여 주면 — "누구한테? 몇 번이나 그랬어? 걔가 뭘 잡아 줬어?"
- 아무것도 안 하면 그것도 답이다. **없는 걸 있다고 만들어 내게 하지 않는다.**

### 5. (필수) 그거 안 틀리려고 돈이나 시간 써 본 적 있어?

- 강의가 반드시 넣으라고 한 질문이다. 문장을 바꾸지 않는다.
- 예 — 체크리스트를 직접 만들었다 / 인강을 샀다 / 학원 / 남는 시간에 따로 연습 / 친구한테 밥 사고 봐 달라 했다.
- "있어" 하면 — "얼마나? 언제부터?" **숫자가 여기서 나온다.**
- "없어, 근데 나오면 써 볼게" = **신호 없음**. 그렇게 적는다. 좋게 적지 않는다.

> **끝내면서** — "이 얘기 해 줄 만한 사람 또 있어?" · "그때 그린 도면 파일 줄 수 있어? 이름은 지우고."

박주호와 같은 것을 묻되, **두 사람 답이 어긋나는 데를 찾는 게 목적**입니다.
같은 말만 나오면 같은 수업 얘기만 들은 것이고, 그건 대상을 잘못 골랐다는 신호입니다.
**박주호가 뭐라고 했는지 먼저 말하지 않습니다.** 말하는 순간 그 답을 따라갑니다.

### 1. 너는 마지막으로 도면 그리다 뭘 틀렸어? 언제였어?

- 박주호와 같은 항목이 나와도 "너도 그거야?"라고 되묻지 않는다. 끝까지 스스로 말하게 둔다.
- 다른 항목이 나오면 **그게 오늘 제일 값진 줄이다.** 그대로 받아 적는다.
- "안 틀려" 하면 — "그럼 제일 오래 걸리는 건 뭐야?" 로 돌린다. 시간도 문제 크기다.

### 2. 그거 언제 알았어?

- 그리는 중 / 내기 전 / 낸 뒤 / 점수 나온 뒤.
- 박주호와 시점이 다르면 왜 다른지 캔다 — "너는 내기 전에 보는 습관이 있어?"

### 3. 알고 나서 그때 어떻게 했어?

- "다시 그렸어" → **몇 분**.
- "그냥 냈어" → 왜.
- 점수를 깎였으면 몇 점인지.

### 4. 지금은 내기 전에 뭘로 확인해?

- 확인을 아예 안 한다고 하면 그것도 답이다. **억지로 뭘 만들어 내게 하지 않는다.**
- 한다고 하면 — 도구 이름까지. 종이 · 휴대폰 메모 · 캐드 화면 확대 · 친구.
- 박주호와 방법이 다르면 — "그 방법은 어쩌다 하게 됐어?"

### 5. (필수) 그거 안 틀리려고 돈이나 시간 써 본 적 있어?

- 문장을 바꾸지 않는다.
- "있어" 하면 얼마나, 언제부터.

> **끝내면서** — "기계과에서 이 얘기 해 줄 만한 애 누구야?" — **여기서 나온 이름을
> [대상표](인터뷰대상표.md)에 넣는다.** · 도면 파일 요청.

## 손선생님 (기계제도 담당)

| | |
|---|---|
| 언제 · 어디서 | |

**학생 인터뷰와 목적이 다릅니다.** 학생은 한 사람의 사건을 말하고,
선생님은 **여러 해 동안 여러 명을 본 사람**입니다. 그래서 "제일 많이 나오는 것"과
"채점 기준"을 물을 수 있는 유일한 대상입니다.

- 존댓말로 묻습니다. 문장은 굵은 줄 그대로 읽어도 됩니다.
- **우리 검사 항목을 먼저 보여 드리지 않습니다.** 보여 드리면 그 목록 안에서만 답하십니다.
  먼저 다 들은 뒤에 마지막에 대조합니다(08-28 항목).
- 받아 적을 것 — 직접 인용 3개 · 지금 학생들을 어떻게 봐 주시는지 · 한 반 채점에 걸리는 시간.

### 1. 요즘 학생들 도면에서 제일 자주 나오는 실수가 뭐예요? 최근에 본 걸로요.

- "많죠" 하시면 — "지난번 수행평가 때 제일 여러 명한테 적으신 게 뭐였어요?"
- **순서를 여쭙는다** — "많은 순으로 셋만 꼽으신다면요?"
- 학생 인터뷰에서 나온 항목과 다르면 그 차이가 이번 주 제일 큰 발견이다.
- 받아 적을 것 — 항목 이름 셋, 대략 몇 명 중 몇 명인지.

### 2. 그거 학생 본인은 언제 알게 되나요? 내기 전에 스스로 잡는 애가 있나요?

- 스스로 잡는 학생이 있다면 — "그 학생은 뭘 다르게 하나요?"
- 대부분 못 잡는다면 — "왜 못 잡는다고 보세요?"
- 받아 적을 것 — 스스로 잡는 비율 감각(몇 명 중 몇 명), 선생님이 보시는 이유.

### 3. 한 반 도면을 다 봐 주시는 데 시간이 얼마나 걸리세요?

- **선생님 쪽 문제 크기를 재는 질문이다.** 학생 시간만 재면 절반만 본 것이다.
- 한 장에 몇 분, 한 반이 몇 명, 언제 보시는지(수업 중 · 퇴근 후).
- "다 못 봐요" 하시면 그게 더 중요한 답이다. 못 보시는 게 몇 명분인지 여쭙는다.

### 4. 지금은 학생들한테 뭘로 확인하라고 하세요?

- 나눠 주시는 종이나 목록이 있으면 — "그거 한 장 받을 수 있을까요?"
- 그 목록이 **우리 검사 24개의 기준**이 된다. 08-28에 대조할 원본이다.
- 목록이 없으면 — "말로 알려 주시는 순서가 있나요?"

### 5. (필수) 그거 줄여 보려고 따로 시간이나 돈을 써 보신 적 있으세요?

- 강의가 반드시 넣으라고 한 질문이다. 선생님께도 그대로 여쭙는다.
- 예 — 채점표를 직접 만드셨다 / 프로그램을 찾아보셨다 / 방과 후에 따로 봐 주신다 / 조교를 쓰신다.
- 있으시면 = **강한 신호**. 무엇을 얼마나 쓰셨는지 숫자로 받아 적는다.
