각자 다섯 개씩입니다. 다섯 번째는 강의가 반드시 넣으라고 한 질문이라 빼지 않습니다.
꼬리 질문은 상대가 짧게 답할 때만 씁니다. 질문 수에는 넣지 않습니다.

**둘 다 친구라면 강의 기준으로는 제외 대상입니다.** 강의는 가족과 친한 친구를 뺐습니다.
같은 반 아는 사이 정도면 셉니다. 다섯 건을 전부 친한 친구로 채우면 산출물에서 깎이니,
나머지 세 건은 다른 반·다른 학년·선생님으로 채웁니다.

## 박주호

| | |
|---|---|
| 학년 | |
| 실기 준비 중인가 | |
| 언제 · 어디서 | |
| 도면 파일 받았나 | |

1. **지난번 도면 그릴 때 빠뜨린 거 있었어? 마지막으로 그런 게 언제야?**
   - 꼬리 — 뭘 빠뜨렸는지 이름으로 말해 달라고 한다 (표제란 · 척도 · 치수 · 선 굵기 · 투상도 배열)

2. **그걸 언제 알았어? 네가 봤어, 아니면 누가 말해 줬어?**
   - 꼬리 — 내기 전이었는지, 점수 나온 뒤였는지

3. **알고 나서 그때 어떻게 했어?**
   - 꼬리 — 다시 그렸는지, 그냥 냈는지. 시간이 얼마나 더 들었는지 **분 단위로** 받아 낸다

4. **지금은 내기 전에 뭘로 확인해?**
   - 꼬리 — 눈으로만 보는지, 적어 둔 목록이 있는지, 누구한테 보여 주는지
   - **이게 지금 쓰는 대안이다.** 구체적으로 못 들으면 이 인터뷰는 반쯤 실패다

5. **(필수) 그거 안 틀리려고 돈이나 시간 써 본 적 있어?**
   - 쓴 적 있음 = **강한 신호**. "나오면 써 볼게"는 신호 아님

> 끝내면서 — "이 얘기 더 해 줄 만한 사람 있어?" · "그때 그린 도면 파일 줄 수 있어? 이름은 지우고."

## 박신후

박주호와 같은 다섯 개를 묻되, **두 사람 답이 어긋나는 데를 찾습니다.**
같은 말만 나오면 같은 수업 얘기만 들은 것이고, 그건 대상을 잘못 고른 신호입니다.

1. **너는 마지막으로 도면 그리다 뭘 틀렸어? 언제야?**
   - 꼬리 — 박주호가 말한 항목이 나오면 "너도 그거야?"라고 되묻지 않는다. 먼저 말하게 둔다

2. **그거 언제 알았어?**
   - 꼬리 — 그리는 중 · 내기 전 · 점수 나온 뒤 중 어디였는지

3. **알고 나서 그때 어떻게 했어?**
   - 꼬리 — 다시 그린 시간, 점수를 깎였는지

4. **지금은 내기 전에 뭘로 확인해?**
   - 꼬리 — 확인을 아예 안 한다고 하면 그것도 답이다. 억지로 뭘 만들어 내게 하지 않는다

5. **(필수) 그거 안 틀리려고 돈이나 시간 써 본 적 있어?**
