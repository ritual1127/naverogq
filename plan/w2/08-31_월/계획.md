## 메모

**2번은 못 했다. 도면이 0장이라 잴 것이 없다.** `실제도면/labels.json` 이 `{}` 그대로여서
`python bench.py 실제도면/labels.json` 이 `FAIL: 실제도면/labels.json 에 도면이 한 장도 없다.
0장으로는 정확도를 잴 수 없다.` 로 끝났다. 08-26 에 막아 둔 [P09](../../문제점/P09-빈측정100.md)
덕에 0장에 100% 가 찍히지는 않았다. 계획의 "몇 장이라도 재고 표본 N장이라고 적는다"는 대안도
N=0 이라 쓸 수 없다. [P04](../../문제점/P04-표본도면.md) 에 적었다. `docs/accuracy.md` 는
새 숫자가 없어 안 고쳤다. 시험 20개는 그대로 통과.

**3번은 했다.** W3 산출물 넷을 강의 페이지에서 확인했다 — ① MVP 범위표(핵심 행동 한 문장 ·
이번에 만들 것 · **지운 기능 목록**) ② 아키텍처 1장(화면 · 서버 · 데이터 · 외부 AI API 를
상자와 화살표로, **손그림 사진도 인정**) ③ AI · 라이선스(쓴 모델명 · 오픈소스 패키지와
라이선스 · 이미지와 폰트 출처를 **README 에 반영**) ④ 보안 점검(코드에 남은 키나 비밀번호가
없음을 확인한 결과). 미리 적어 둔 [W3 README](../../w3/README.md) 와 항목은 같고, 강의가
따로 요구하는 세 가지(지운 기능 목록 · 손그림 인정 · README 반영)를 그 문서에 더했다.
마감은 **이번 주 1:1 멘토링 세션 전까지 전담 멘토에게 공유**다.

**1번은 사람 몫이라 하지 않았다.** 대신 멘토에게 그대로 보낼 수 있게 W2 산출물을 한 편의
