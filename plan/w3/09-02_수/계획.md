## 할 일

### 1. README mermaid 그림을 제출용 1장으로 다듬기 — **박지완**  ·  예상 1시간 30분

- 지금 그림: 도면 파일 → 웹 화면 → 서버 → 도면 읽기 → 규칙 60점 / AI 30점 → 결과 화면.
- 빠진 것 — DWG → DXF 변환 경로(LibreDWG → CloudConvert → ODA), 캐시(`aicache`), AI 제공자 대체 경로(Gemini → Cloudflare → Groq → Mistral).
- 한 장을 넘기지 않는다. 넘치면 그림이 아니라 문서다.

**이렇게 되면 끝** — 그림 한 장에 화면부터 결과까지 다 들어갔다

**흔한 실수** — 박스를 너무 많이 그리는 것. 한 장을 넘기면 그림이 아니라 문서다

### 2. 도면 파일이 어디에 얼마나 남는지 그림에 적기 — **김승준**  ·  예상 40분

- 업로드 도면은 최대 1시간 뒤 삭제.
- AI 채점에는 **도면 그림이 Gemini로 나간다.** 이건 화면에도 이미 적어 뒀다.
- `aicache`에 무엇이 남는지도 적는다. 저장소에 올라가는 폴더라 심사에서 볼 수 있다.
- 개인정보 흐름을 그림에 넣어 두면 W3 AI 윤리 항목과 공개 고지가 한 번에 정리된다.

**이렇게 되면 끝** — 도면이 어디에 얼마나 남는지 그림에서 보인다

**흔한 실수** — Gemini로 그림이 나간다는 사실을 그림에서 빼는 것. 숨기면 나중에 더 문제다
