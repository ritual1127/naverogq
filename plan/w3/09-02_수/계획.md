### 1. README mermaid 그림을 제출용 1장으로 다듬기 — 박지완

- 지금 그림: 도면 파일 → 웹 화면 → 서버 → 도면 읽기 → 규칙 60점 / AI 30점 → 결과 화면.

### 2. 도면 파일이 어디에 얼마나 남는지 그림에 적기 — 박지완

- 업로드 도면은 최대 1시간 뒤 삭제.
- AI 채점에는 **도면 그림이 Gemini로 나간다.** 이건 화면에도 이미 적어 뒀다.
- `aicache`에 무엇이 남는지도 적는다. 저장소에 올라가는 폴더라 심사에서 볼 수 있다.
- 개인정보 흐름을 그림에 넣어 두면 W3 AI 윤리 항목과 공개 고지가 한 번에 정리된다.
