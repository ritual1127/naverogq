## 할 일

### 1. 어디에 어떤 AI를 왜 썼는지 정리 — 김승준

- 프로덕트 안 — Gemini(투상도 30점 채점), 대체 제공자 세 곳.
- 개발 도구 — Claude Code, GPT. 코드 작성과 오류 점검.
- **둘을 섞어 적지 않는다.** 심사에서 보는 건 프로덕트 안의 AI다.

### 2. 모델 선택 근거 쓰기 — 박지완

- 심사 피드백 원문: "각 모델을 선택한 구체적인 이유와 해당 모델이 프로젝트의 어떤 부분에서 가장 큰 기여를 했는지".
- 지금 README에는 무엇을 썼는지만 있고 **왜 골랐는지가 없다.**
- 적을 것 — 왜 멀티모달이어야 했는지(도면을 그림으로 봐야 함), 왜 무료 티어가 중요한지(학생 프로젝트, 서버 비용), 대체 제공자를 왜 넣었는지(할당량이 마르면 30점이 멈춤).

### 3. `vendor/` 라이브러리 라이선스 확인 — 박지완

- MIT와 충돌하는 게 없는지. LibreDWG는 GPL 계열이라 **어떻게 쓰고 있는지**가 중요하다 (별도 실행 파일 호출인지 코드에 링크인지).
- 확인한 결과를 `NOTICE.md`에 적는다.
