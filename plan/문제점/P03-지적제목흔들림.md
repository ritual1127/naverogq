# P03 · 같은 판정인데 지적 제목이 매번 다르게 적힌다

| | |
|---|---|
| 상태 | **해결** (2026-08-25) |
| 처음 본 날 | 2026-08-22 |
| 무엇에 영향을 주나 | 수험생이 보는 화면 · 재검사 비교 |
| 맡은 사람 | 박지완 |
| 목록 | [문제점 전체](README.md) |
## 증상

같은 판정에 대해 제목이 매번 달라진다.

- "투상도 전체 누락"
- "투상도 완전 누락"
- "투상도 전체 누락 및 형상 표현 불가"
- "기계 부품 투상도 미작성 및 투상 뷰 부재"

뜻은 같지만 **수험생에게는 다른 지적으로 보인다.**

## 왜 문제인가

CADLens의 핵심 흐름은 `검사 -> 고치기 -> 재검사`다. 재검사에서 지난번과 비교해 주는데,
제목이 매번 달라지면 **비교가 성립하지 않는다.** 북극성 지표(주간 재검사 사용자 수)와 직결된다.

## 조치 (2026-08-25)

**제목을 AI에게서 뺐다.** AI는 이제 제목을 쓰지 않고 `kind` 를 여섯 개 중에서 고르기만 한다.
제목은 `ai_review.PROJECTION_KINDS` 에 언어별로 박혀 있고 코드가 붙인다.

| kind | 제목 |
|---|---|
| `FRONT_VIEW` | 정면도 선택 부적절 |
| `VIEW_MISSING` | 투상도 누락 |
| `VIEW_EXTRA` | 불필요한 투상도 |
| `THIRD_ANGLE` | 제3각법 배치 위반 |
| `SECTION_DETAIL` | 단면도·상세도 표기 미흡 |
| `LAYOUT` | 투상도 배치 불균형 |

- 응답 스키마에서 `title` 을 빼고 `kind` enum 을 넣었다. 모델이 목록 밖의 값을 못 준다.
- 번역도 제목을 받지 않는다. en·ja·zh 제목이 표에 이미 있어서 번역할 것이 하나 줄었다.
- **지적 코드는 `AI_PROJECTION` 하나로 그대로 뒀다.** 화면(`static/index.html`)의 묶음·라벨 표가
  이 코드를 키로 쓰고 있어서, 코드를 쪼개면 그 표까지 다 고쳐야 한다. 재검사 비교에 필요한 것은
  제목이 고정되는 것이라 여기서 멈췄다.
- **옛 캐시(`aicache`)에는 `kind` 가 없다.** 그때 화면에 뜬 제목을 그대로 두게 했다.
  지난 판의 제목을 바꿔 버리면 그 판으로 잰 편차 기록과 대조가 안 된다.

같이 고친 것 — **`verdict` 가 "FAIL" 한 낱말로 오는 일이 있었다.** 지시문에 verdict 형식이
아예 없었다. 08-25 배포 서버 확인 때 `sample_plate.dxf` 는 한 문장, `sample_autocad.dxf` 는
`FAIL` 이 왔다. 지시문에 "한국어 한 문장으로 쓰고 낱말만 적지 말라"를 넣었다.

## 확인

- `test_ai_title_is_fixed_by_kind` — 같은 `kind` 에 서로 다른 문장을 넣어도 제목이
  `투상도 누락` / `Missing views` 로 같은지, 스키마에 `title` 이 없고 enum 이 여섯 개인지,
  `kind` 없는 옛 캐시가 그대로 보존되는지. `python -m pytest test_rules.py -q` → **17개 통과**.
- 로컬에서 실제 호출 1회 — `samples/sample_plate.dxf` 결과가
  제목 `투상도 누락`, en `Missing views`, ja `投影図の欠落`, zh `视图缺失`.
  verdict 도 한 문장으로 왔다.
- **배포 서버에서도 확인했다** (2026-08-25, 배포 뒤). 예제 두 장을 `POST /api/analyze-sample`
  로 돌렸고 나온 제목이 전부 표 안의 것이었다.

  | 도면 | 나온 제목 | 번역 |
  |---|---|---|
  | `sample_plate.dxf` | 투상도 누락 · 투상도 배치 불균형 | en·ja·zh 전부 |
  | `sample_autocad.dxf` | 투상도 누락 · 정면도 선택 부적절 · 투상도 배치 불균형 | en·ja·zh 전부, 후속 답변 ko 포함 4개 |

  `verdict` 도 둘 다 한 문장으로 왔다(13낱말 · 16낱말). 고치기 전 `sample_autocad.dxf` 는
  `FAIL` 한 낱말이었다.
