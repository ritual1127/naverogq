# P19 · 실격 검사 5개 중 3개가 DXF에서는 한 번도 뜰 수 없었다

| | |
|---|---|
| 상태 | ✅ **해결** — 2026-09-08 |
| 처음 본 날 | 2026-09-08 |
| 무엇에 영향을 주나 | 오작 판정 3가지(`DQ_PROJECTION` · `DQ_SHEET_SIZE` · `DQ_SCALE`) · "실격 조건 5가지를 본다"는 우리 설명 |
| 맡은 사람 | 박지완 |
| 목록 | [문제점 전체](README.md) |

## 증상

상업적으로 쓸 수 있는지 보려고 검사 항목을 코드에서 하나씩 되짚었더니,
`exam.py`가 읽는 값 셋이 **아무도 채우지 않는 값**이었다.

| 검사 | 읽는 값 | 그 값을 채우는 코드 |
|---|---|---|
| `DQ_SHEET_SIZE` (도면 크기 오작) | `sheet["width_cm"]` | **없음** |
| `DQ_PROJECTION` (제1각법 오작) | `facts["first_angle"]` | `None` 고정 |
| `DQ_SCALE` (비표준 척도 오작) | `view["scale"]` | `None` 고정 |

```
$ grep -rn "width_cm" *.py
exam.py:158:    sw, shh = sh.get("width_cm"), sh.get("height_cm")   ← 읽기만 한다
```

즉 **DXF·DWG를 올리는 모든 경로에서 이 세 검사는 한 번도 실행되지 않았다.**
README와 발표에는 "실격 조건 5가지를 확인한다"고 적어 뒀는데, 실제로 뜰 수 있는 것은
표면거칠기 없음과 기하공차 없음 **둘뿐**이었다.

## 원인

이 세 값은 Inventor 도면(`.idw`)을 직접 읽던 초기 구조에서 오던 것이다.
경로가 DXF 파싱(`facts_from_dxf`)으로 바뀌면서 값을 채우는 쪽이 사라졌는데,
읽는 쪽 코드는 남았다. 값이 없으면 검사가 조용히 넘어가기 때문에
**테스트도 벤치마크도 통과했다.** 합성 도면은 전부 정상 도면이라
"안 뜨는 것"과 "뜰 일이 없는 것"이 구분되지 않았다.

## 조치

DXF에서 세 값을 실제로 읽도록 만들었다. 실기 도면은 표제란 칸마다 문자가 따로
놓이므로(`척도` 옆에 `1:1`, `각법` 옆에 `3각법`) 라벨과 값을 좌표로 짝지어 읽는다.

- `dwg._title_fields()` — 표제란 라벨-값 짝 (척도 · 각법 · 재질 · 질량)
- `dwg._first_angle()` — `제3각법` / `제1각법` / 칸에 숫자만 있는 도면틀까지
- `dwg._sheet_size()` — 윤곽선 → (없으면) 도면 한계·범위로 A0~A4 판별
- `dwg._view_scales()` — `단면도 A-A (2:1)` 같은 뷰 이름표의 척도

여기에 더해, 값을 읽을 수 있게 되자 그동안 검사 자체가 없던 항목도 붙일 수 있었다 —
재료 기호(`EX_NO_MATERIAL`), 표제란 척도 표기(`EX_NO_SHEET_SCALE`),
각법 표기(`EX_NO_PROJECTION_MARK`), 뷰별 척도 섞임(`EX_VIEW_SCALE_MIXED`),
3D 등각투상도 질량(`EX_NO_MASS`), 도면 영역 크기(`EX_SHEET_SIZE`).

**모르면 판정하지 않는다는 원칙은 그대로 뒀다.** 도면틀도 표제란도 없으면 크기를
재지 않고, 표준 크기에 안 맞으면 이름을 붙이지 않는다. 헤더의 도면 한계는 CAD가
넣어 둔 기본값(새 도면이면 A3)일 수 있어 윤곽선이 없을 때만 본다.

## 확인

```
python -m pytest -q                    → 38 passed
python bench.py 합성도면/labels.json   → 완전 일치 100/100 · 검출률 100% · 정확도 100%
```

실제 도면 5장에서 새 검사가 실제로 떴다.

| 도면 | 새로 뜬 것 |
|---|---|
| `1본체.dxf` | `EX_SHEET_SIZE`(A3로 제도, 요구는 A2) |
| `3축.dxf` | `EX_SHEET_SIZE` |
| `동력전달장치-4.dxf` | `EX_SHEET_SIZE` · `EX_NO_MATERIAL`(부품란 재질 칸 비어 있음) |
| `cylinder.dxf` · `vacuum.dxf` | 없음 — 도면틀이 없어 크기를 재지 않았다 |

새 검사가 헛지적을 만들지 않는지는 반대쪽으로도 확인했다. `3축.dxf`의 상세도
`C ( 5 : 1 )`은 척도가 달라도 맞는 것이라 `EX_VIEW_SCALE_MIXED`를 띄우지 않는다.

## 남은 것

- `DQ_SCALE`(비표준 척도)은 여전히 뷰 속성 척도를 못 읽는다. 지금은 뷰 이름표에
  적힌 척도만 본다. 이름표가 없는 뷰는 판정 못 한다.
- A2/A3 판정 기준은 공개문제 요구사항("A2 용지에 제도, A3로 출력")에서 왔다.
  회차 지시사항이 다를 수 있어 A3는 오작이 아니라 경고로 둔다.
