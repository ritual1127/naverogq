## 증상

10-17 저녁 웹사이트 디자인을 점검하며 로컬 서버(`CADLENS_STAT_DB` 임시 경로)에서 결과 화면을 찍었더니 도면 미리보기의 한글이 □ 로 나왔다.
로컬만의 일인지 보려고 20:23:59 에 공개 서버에서 예제 하나를 curl 로 돌려(UA 그대로 — 로봇 규칙으로 안 세인다, [계획표 기록](../10-19까지.md#팀이-공개-사이트를-연-기록))
받은 미리보기 SVG 를 그려 봤다.

| 무엇 | 공개 서버(마지막 배포 `39bc4df`) |
|---|---|
| `POST /api/analyze-sample` `{"name": "sample_body.dxf"}` | `200` · 1.05초 · SVG 85,525자 |
| 뷰 이름 넷(정면도 · 평면도 · 우측면도 · 단면도 A-A) | `□□□` · `□□□` · `□□□□` · `□□□ A-A (1:1)` |
| 주서 다섯 줄 | `1. □□□□ - □) □□□: KS B ISO 2768-m` 처럼 숫자 · 영문만 남음 |
| 부품표 · 표제란 | 품번 · 재질 기호(GC250 · SCM415)만 보이고 `□3□□` · `□□ 1:1` |

숫자와 영문은 제대로 나오고 한글만 빠진다. 같은 미리보기를 AI 채점 그림(PNG)도 같이 쓴다([`dwg.record`](../../dwg.py)).

## 원인

도면이 적어 둔 글꼴을 서버가 못 찾으면 ezdxf 는 **대신 글꼴**로 그린다. 그 차례가 `ArialUni.ttf` → `Arial Unicode.ttf` → `Arial.ttf` →
`DejaVuSansCondensed.ttf` → `DejaVuSans.ttf` …(ezdxf 1.4.4 `fonts/font_manager.py` 의 `DEFAULT_FONTS`)이고, 서버 이미지에서는 앞의 셋이 없어
DejaVu 글꼴(`fonts-dejavu-core`)이 걸린다. DejaVu 에는 한글 글자가 없어 글자마다 빈 네모(.notdef)가 그려졌다.

- 예제 `sample_body.dxf` 의 기본 문자 스타일 글꼴은 `txt` 다. 서버에는 없다.
- 실제 수험생 도면(저장소 밖, Inventor 에서 DXF 로 내보낸 35개)은 한글이 있는 25개 모두 한글을 `Gulim.ttf` 스타일로 적었다. 굴림도 서버에 없어 같은 길로 간다.
- [Dockerfile](../../Dockerfile) 은 07-31(`a560694`)부터 `fonts-nanum` 을 깔고 있었다. 나눔고딕은 서버에 있었지만 위 대신 글꼴 차례에 없어서 한 번도 쓰이지 않았다.
- 이 PC 에서 안 드러난 까닭 — `Gulim.ttf` 는 Arial Unicode(한글 있음)로 대신 찾는다. `txt` 는 이 PC 에서도 `txt_____.ttf`(한글 없음)라 로컬 예제에서도 □ 였다.

언제부터 공개 화면이 이랬는지는 재지 않았다.

## 조치

**10-17 — 그릴 때만 한글 글꼴로 바꾼다**([`dwg.render_context`](../../dwg.py)).

- 미리보기 · AI 그림이 쓰는 `RenderContext` 를 한곳에서 만들고, 문자 스타일마다 ezdxf 가 고른 글꼴에 한글(`가`, U+AC00)이 없으면
  `NanumGothic.ttf`(서버) · `malgun.ttf`(Windows)로 바꾼다. 도면 파일과 검사는 건드리지 않는다 — 검사는 도면을 읽지 그림을 읽지 않는다.
- AI 채점 캐시 열쇠는 그림이 아니라 도면 파일 내용이라([`ai_review._cache_key`](../../ai_review.py)) 저장소에 넣어 둔 예제 채점(`aicache/`)은 그대로 맞는다.
- 서버 이미지에 나눔고딕이 없으면 이미지 만들기가 멈추게 했다([Dockerfile](../../Dockerfile) 맨 아래 확인 줄). 그러면 Render 는 지난 배포를 그대로 돌린다.
- 시험 하나 — `test_preview_draws_korean_text_with_a_hangul_font`(한글 글꼴이 없는 컴퓨터에서는 건너뛴다).

남는 것 — 문자 스타일 표에 없는 스타일 이름, MTEXT 안에서 `\f` 로 글꼴을 바꾼 글은 여전히 대신 글꼴로 간다.
기하공차를 GDT 전용 글꼴 기호(`%%v`)로 적은 줄은 글꼴과 상관없이 그대로 `%%v` 로 보인다.
