# P36 · 발표 도우미의 중계(Supabase) 주소가 없어져 기기끼리 같이 넘어가지 않는다 — `○ 끊김 — 이 기기만 넘어감`

| | |
|---|---|
| 상태 | ✅ **해결** — 2026-10-18. Supabase 프로젝트가 멈춰(`INACTIVE`) 있었고, 되살린 뒤 두 기기가 `● 연결 · 2대` 로 같이 넘어갔다 |
| 처음 본 날 | 2026-10-16 |
| 무엇에 영향을 주나 | 11-11 본선 발표(10분 + 질의응답) · 10-19 뒤 발표 연습 — 발표하는 기기와 대본을 보는 기기가 같이 넘어가는 것 |
| 맡은 사람 | 박지완 |

## 증상

10-16 계획 2번(제출물 다섯 다시 보기)에 "[발표 도우미](https://cadlens-presenter.vercel.app)를 열어 `● 연결` 이 뜨는지 본다"가 있다.
사람 확인(김승준)과 따로, 19:25 에 중계 주소부터 불러 봤다.

| 시각 | 무엇을 했나 | 결과 |
|---|---|---|
| 19:25 | `curl https://hgmshnoaipajahvmzcqw.supabase.co/rest/v1/` ([`presenter/index.html`](../../presenter/index.html) 의 `SUPABASE_URL`) | `Could not resolve host` — 응답 코드 없음 |
| 19:25 | `nslookup` — 집 공유기 · `1.1.1.1` · `8.8.8.8` 세 곳 | 세 곳 모두 `Non-existent domain` |
| 19:25 | `https://dns.google/resolve?name=hgmshnoaipajahvmzcqw.supabase.co&type=A` | `"Status":3`(이름 없음). 같은 때 `supabase.co` 자체는 풀렸다 |
| 19:26 | 헤드리스 Chrome 으로 `https://cadlens-presenter.vercel.app/` 를 열고 12초 기다림 | 위 띠 `○ 끊김 — 이 기기만 넘어감` |

발표 도우미 자체(Vercel)는 열린다(19:25 `200`). 설계대로 끊긴 기기는 혼자 넘어간다
([설계](../../docs/superpowers/specs/2026-10-04-presenter-design.md) 「끊김」) — 한 기기로 발표하는 것은 된다. 안 되는 것은 **두 기기 이상이 같이 넘어가는 것**이다.

## 원인

**프로젝트가 멈춰 있었다(10-18 확인).** 10-18 13:2x 에 Supabase 커넥터(박지완 계정)로 프로젝트 목록을 읽으니 `cadlens-presenter`(`hgmshnoaipajahvmzcqw`)의
상태가 `INACTIVE` 였다 — 지워진 것이 아니라 멈춘 것이다. 멈춘 프로젝트는 주소가 DNS 에서 빠져 위 표처럼 `Non-existent domain` 이 된다.
10-16 에 "AI 도구는 그 계정에 들어가지 못한다"고 적은 것은 이 커넥터를 쓰기 전 이야기다. **언제 멈췄는지는 여전히 모른다** — 아래 짐작은 그대로 둔다.

짐작은 하나 있다 — [W8 준비](../w8/W8_준비.md)에 "중계용 Supabase 무료 프로젝트(`cadlens-presenter`)는 7일 동안 안 쓰면 멈춘다"고 적어 두었다.
중계가 됐다고 적힌 마지막 기록은 **10-04** 다. 발표 도우미를 처음 올린 커밋 `a1fc171`(10-04 00:46)이 "배포 주소에서 브라우저 확인 15개 통과
(따라오는 데 145ms, 늦게 들어온 기기 · 동시 누르기 · 잠금 · 중계 차단)"를 적었고, 같은 커밋의 [발표 도우미 계획](../../docs/superpowers/plans/2026-10-04-presenter.md)
Task 5 에 "배포된 주소를 브라우저 두 탭(같은 방)으로 열어 넘기기 · 잠금 확인"이 체크돼 있다. 그 뒤로 `● 연결` 을 봤다는 기록은 없다 —
W8 준비의 "10-07 오후에 사이트를 열어 `● 연결` 이 뜨는지" 칸도 비어 있다. 10-04 뒤로 아무도 안 열었다면 7일 규칙으로 10-11 무렵 멈췄을 수 있지만,
10-07(데모데이 ②) · 10-08(10분판 리허설)에 열었는지는 적힌 것이 없다. 그래서 언제부터 끊겼는지, 정말 7일 규칙 때문인지는 원인 칸에 적지 않는다.

## 조치

10-18 13:3x — 박지완이 시켜 같은 커넥터로 프로젝트를 되살렸다(Restore). 몇 분 뒤 상태가 `ACTIVE_HEALTHY` 가 됐다.
주소 · 공개 키는 그대로라 `presenter/index.html` 과 Vercel 배포는 손대지 않았다.

**다시 멈추지 않게** — 무료 프로젝트는 오래 안 쓰면 멈춘다. 발표 · 리허설 전날에 프로젝트 상태를 보고(멈췄으면 되살리고) 두 기기로 열어 본다.
11-11 본선 전에도 같은 확인을 한다.
