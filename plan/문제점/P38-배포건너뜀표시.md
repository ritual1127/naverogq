## 증상

10-16 부터 문서 커밋은 메시지 끝에 Render 의 자동 배포 건너뛰기 표시(꺾쇠 안에 `skip render`)를 넣는다 — Build Filters 를 대시보드에서
못 봐서다([10-16 메모](../w9/10-16_금/계획.md#메모)). 10-17 저녁 화면 고침 여섯을 그 표시를 넣어 올린 뒤, 마지막에 표시를 뺀 커밋 `cf77311` 로
한 번에 배포하려 했다.

| 시각 | 무엇 | 결과 |
|---|---|---|
| 21:01:32 | `cf77311` 푸시 | GitHub Tests · Docker smoke 통과 |
| 21:01:40 ~ 21:07:28 | 공개 서버 `common.js?v=20261017` 에 새 문장(`statReset`)이 있는지 20초마다 curl | 18번 모두 옛 파일. 10-16 배포는 푸시 70초 뒤 반영됐다 |
| 21:07:44 | `cf77311` 메시지를 다시 읽음 | 메시지 다섯째 줄(본문)에 "그 사이 커밋은 모두 (표시 글자) 로 올렸고" — 표시 글자가 꺾쇠까지 그대로 들어 있었다 |

## 원인

Render 는 커밋 메시지에 그 표시 글자가 들어 있으면 자동 배포를 건너뛴다. 제목에는 없었지만 **본문에 지난 커밋들을 설명하면서 같은 글자를 적었다.**
표시 글자가 없는 빈 커밋 하나로 다시 걸자 곧바로 반영돼(아래 확인) 다른 원인은 남지 않는다. 대시보드(Render Events)는 보지 못했다.

## 조치

- 2026-10-17 21:07:52 — 바꾼 내용 없는 빈 커밋 `7446422` 를 표시 글자 없이 올렸다. 메시지에서는 그 표시를 "건너뛰기 표시"라고만 불렀다.
- 앞으로 — 배포 커밋 메시지에는 그 표시 글자를 꺾쇠째 쓰지 않는다. 설명해야 하면 "건너뛰기 표시"라고 쓴다. 문서 커밋은 지금처럼 끝에 넣는다.
